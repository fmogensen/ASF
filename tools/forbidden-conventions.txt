# Forbidden-convention patterns for tools/check_conventions.sh.
#
# One extended regex (grep -E) per line; blank lines and lines starting with `#` are ignored.
# A match in any `asf/**/*.py` outside the three documented exceptions (asf/conventions.py,
# asf/metrics/import_sessions.py and asf/hooks.py) fails the build: the code carries a convention
# that belongs in the product yaml. See the rule "Code carries no product convention".
#
# Unlike tools/forbidden-names.txt these are not names — check_generic.sh cannot see them. Each
# line below is a path, prefix, file name or id that one product happens to use and another does
# not; the generic form of each is a field of asf.conventions.Conventions.
#
# The path-shaped defaults themselves (`docs/specs`, `worker/`, `{reviews_dir}/{n}-{slug}.md`,
# …) are not listed here: tools/check_conventions.sh generates a pattern for each of them from
# asf.conventions at run time, so this file never has to be kept in step with that module.

# Branch prefixes → conventions.branch_prefixes (+ `legacy` for retired ones).
cloud/
worktree-m-
refs/heads/hb

# Document trees → conventions.specs_dir / plans_dir / reviews_dir / intake_dir.
docs/superpowers
\.sdd-input
goals\.txt
feature-matrix

# A hardcoded item id → conventions.default_bug_epic (an id in generated prose is data too).
\bE-[0-9]{4}\b

# Another repo's tooling called by path → an `asf` subcommand, or conventions.test_command.
tools/[A-Za-z0-9_-]+\.(py|sh|json)

# Operator state outside ~/.ASF → asf.env.state_dir(product) / asf.env.log_dir().
session-results\.jsonl
\.claude-workers
\.claude/
/tmp/

# Workflow and job names → conventions.ci_workflow / ci_dev_job / deploy_workflow
# (product yaml: ci.workflow, ci.dev_job, deploy_sha.workflow).
deploy-prod\.yml
\bci\.yml\b
deploy-dev

# The first product's migration sources → conventions.decisions_file / reports_dir /
# report_pattern. These name a report's *location*, which those three fields carry.
#
# `ci-diag-` is deliberately not a pattern here. The spec's own non-goal keeps the hotfix report
# *shape* — "only their locations move to conventions; the parsers stay as they are" — and
# `asf.tick.migrate.hotfix_bug_fields` reads the `ci-diag` prefix to pick a severity, not a file.
# No conventions field in this card carries that marker, so the pattern would condemn a parser
# with no legal fix and sit red for good. Making that parser generic needs a field nobody has
# specified yet.
hotfix-.*-report
