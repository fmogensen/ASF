# Forbidden-name patterns for tools/check_generic.sh.
#
# One extended regex (grep -E, case-insensitive) per line; blank lines and lines starting with
# `#` are ignored. This is the PUBLIC list: only generic patterns and the specific product/
# company/person/vendor/account/host words this repo's own history was found to contain. The
# operator may keep a second, private list (see check_generic.sh --extra) with anything specific
# to their own deployment; that list is never committed here.
#
# Generic patterns — catch a class of name, not one instance of it.
@[a-z]+\.ai\b
\bcom\.[a-z]+\.factory\b

# Specific words this repo's history was found to contain and had to remove (P0d migration).
# Note: generic public platform names that are legitimate config *values* (e.g. a deploy_sha
# provider choice) are deliberately NOT listed here — only names that were hardcoded as this
# operator's own private choice belong on this public list.
\bbotseon\b
\bnordio\b
\bhetzner\b
\bcontabo\b
\bfrank\b
\bniels\b
\bnina\b
\banette\b
\bjan\b

# Generic patterns added before the public release (the genericity audit's section B). They name
# a class of private detail, never one backend: name the interface (account_lock.*,
# operator.path_prefix), not the tool behind it on one operator's machine.
#
# An account manager's own name and its home directory (the interface is `account_lock.*`). Each
# pattern is written so it does not match its own line here (a bracketed letter).
\bc[u]x\b|~/\.c[u]x\b
# A private claude.ai link: an artifact, a chat or a project. (A cloud session URL is the runtime's
# own generic link template and is not matched.)
claude\.ai/(code/)?artifacts?/|claude\.ai/(chat|project)/
# A personal mailbox at a consumer email provider (the `.ai` domains are matched above).
@(gmail|googlemail|outlook|icloud|me|hotmail|live|yahoo|proton|protonmail)\.[a-z]+\b
# An operator's home directory. Allowed, because they are placeholders every fixture and doc uses:
# /Users/someone/, /Users/operator/, /Users/x/ (and the /home/ twins), and a relative
# `<tmp>/home/...` path.
(^|[^a-z0-9_.~>-])/(Users|home)/(?!(someone|operator|x)/)[a-z][a-z0-9_.-]*/
# A package manager's install prefix baked in as a path (the interface is operator.path_prefix,
# or shutil.which over PATH).
/opt/home[b]rew\b|linuxb[r]ew|/usr/local/Cel[l]ar\b
