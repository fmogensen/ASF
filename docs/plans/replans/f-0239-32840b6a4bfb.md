**Files**

- `asf/feeder/rows.py`:
  - `bug_rows` (`:797`) takes `adjudicated=None`, appended after `why`.
  - its `n > limit` (`:843`) and `n == limit` (`:847`) branches merge into one: `if n >= limit:`
    builds the STALEMATE row the cap builds today — `tier=tier` (`0 if sev == 'S1' else 1`,
    identical to today's), `kind=STALEMATE`, `action=LAUNCH`, `brief_kind='adjudicate'`,
    `branch=branch_for(product, 'fix', b['id'])`,
    `reason=f"{sev} open after {n} sessions: adjudicate, not another fix"` — then
    `out.append(row if n == limit else _capped(row, attempts, limit, product, adjudicated))`.
    At `n == limit` the appended row is byte for byte today's row; past it, `_capped` decides
    between carrying an uncarried ruling (`ruling_row`), parking (`PARKED adjudicated, card
    unchanged`, non-launching, `waits_on='operator'`), and relaunching one adjudicate session
    (a release or an operator ruling since the last adjudicate run). The `waits('operator', …)`
    call the old branch made is gone; `waits` keeps its other four call sites inside `bug_rows`.
  - the docstring's last clause (`:805`) is rewritten: past the attempt limit the row is one of
    `_capped`'s three outcomes — a ruling carried out by one session, a PARKED row when the card
    has not moved, or one adjudicate session on this card state (PD7).
  - `_candidates` (`:2545`) passes it: the call at `:2560` becomes
    `bug_rows(items, product, busy | spoken, attempts, held_by, adjudicated)`. Nothing else in
    `_candidates` changes — `rows += [r for r in bugs if r.launches]` (`:2561`) takes the
    launching outcomes, `bug_waits` (`:2562`) takes the non-launching PARKED one, the merge at
    `:2587` puts it exactly where `waits('operator', …)` used to sit, behind the `spoken_for` test.
    The second `_capped` application at `:2601-2602` never doubles up: `STALEMATE` is not in
    `CAPPED_KINDS` (`:213-214`).
- `tests/test_feeder.py` — `BugPastTheAttemptLimit`, new. For a decided, open S1 Bug with
  `attempts = limit + 1`: with no adjudicate run recorded, the row is `STALEMATE → ADJUDICATE`,
  `would launch`, `brief_kind == 'adjudicate'`, on the Bug's fix branch; with an ended adjudicate
  run on this same card, the row is `PARKED adjudicated, card unchanged`, does not launch, keeps
  `waits_on == 'operator'`, and its reason names `` `asf unpark B-0057` `` (already landed by
  T-0795); with an operator ruling or a release since that run (already landed by T-0794), it
  launches again; with the adjudicate session's own uncarried ruling, it is `brief_kind ==
  'correct'`, `ruling` True, and its `correction` quotes the ruling's text. At `n == limit` the
  row is the launching adjudicate row it is today, byte for byte. Also assert, off the same

  `tiers.WORKED` (`asf/feeder/tiers.py:34`), so it does — and that `test_bug_rows` (`:541`) stays
