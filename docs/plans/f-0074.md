### Shared contracts (the Tasks below code against these)

- `asf.conventions.forbidden_patterns() -> list[str]` — extended regexes, one per path-shaped
  string default, in a stable order (the four prefixes by kind name, then the module's `DEFAULT_*`
  in definition order). No file I/O, no imports beyond `re`.
- `python3 -m asf.conventions --forbidden` → those lines on stdout, one each, exit 0. Any other
  argv → `name = value` per default, exit 0.
- `bash tools/check_conventions.sh --print-patterns` → the merged list (file lines, then generated
  lines), exit 0, no scanning.
- `asf.conventions.Conventions` gains nine fields, every one defaulting to `None`: `briefs_dir`,
  `matrix_path`, `design_spec_name`, `decisions_file`, `reports_dir`, `report_pattern`,
  `ci_workflow`, `ci_dev_job`, `deploy_workflow`. `None` means *this product has no such thing*.
- `asf.evidence.evidence._cache_file(name, product)` →
  `os.path.join(env.state_dir(product), 'cache-' + name)`; a product with no name raises
  `ValueError`. Callers pass `'prs.json'` and `'evidence.json'`.
- `asf.briefs.preamble.conventions(product)` returns `product.conventions`, or `Conventions()`
  when `product is None` — still `.get()`-able, so every caller of it is unchanged.
- `asf.groom.inbox.process_inbox(root, canonical, date, default_bug_parent=None, intake_dir=None)`
  — `None` → `Conventions().intake_dir`.
- `asf.feeder.rows.branch_for(product, kind, item_id)` — no `default` parameter.
