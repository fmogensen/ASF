Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0257.md` (approved, re-anchored at
`91f796eb`). Branch: `plan/F-0257`.

Five Tasks, read off the spec's own *The design* — its six numbered sections, with §1 and §2
joined into one Task because §1's `partial_markers()` cannot run until §2 has registered the key
it reads (PD1):

1. **the grammar refuses it** — `asf/proves.py` and the `proves.partial_markers` tunable,
   Design §1 and §2.
2. **the briefs say whole or Not proved** — the three code templates, Design §6.
3. **the refusal travels with the evidence** — `evidence.landed_proves`, Design §3.
4. **the record reports it and ticks nothing** — `ingest.unproved_of` and the Story loop,
   Design §4.
5. **the pull request says it** — `lane.commits_note`, Design §5.

They run in **two waves**: Task 1 alone, then Tasks 2, 3, 4 and 5 together.

| wave | Tasks | runs after | why |

| 1 | Task 1 | — | nothing it needs exists yet |
| 2 | Task 2, Task 3, Task 4, Task 5 | Task 1 | each calls a name Task 1 creates, and no two of their four footprints intersect (PD1) |

## The fences

Every Task's Gate ends with these three — each walks the whole of `asf/**/*.py` or the whole
tracked tree, and every file any Task writes sits inside all of them:

```bash
bash tools/check_generic.sh
bash tools/check_conventions.sh
python3 tools/run_tests.py --touched origin/main --shards 2
```

The spec's own *The fences* adds three more, run once by the last Task to land and by any Task that
touches a record writer or a client:

```bash
bash tools/check_privacy.sh
bash tools/check_record_writers.sh
bash tools/check_clients.sh
```

and the whole-module sweep the spec names, which is the pull request's own check:

```bash
python3 -m unittest -v tests.test_proves tests.test_config_keys tests.test_evidence \
  tests.test_no_test_no_done tests.test_ingest tests.test_lane tests.test_briefs \
  tests.test_tick_steps tests.test_harvest
```

`tests/test_tick_steps.py` is in that list because it holds the one existing fixture whose text
carries a marker word (spec P5), and `tests/test_harvest.py` because the landing reads the claims.

The product's full suite (`python3 tools/run_tests.py`) is the pull request's, run by the external
CI on every PR these Tasks open — never skipped, only run off this host. Each Task's Gate runs its
own modules in the foreground first.

No product, company, person or machine path is named by any Task; a lane is `lane-N`.
