# Plan F-0342 — a move must move the floor the product actually runs

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0342.md` (approved, landed at
`7476744b9`). Branch: `plan/F-0342`.

Three Tasks, cut along the two seams the later work has to be able to call. **Task 1 is the
quiesce**: the kernel's own two argv shapes in `MOVE_PATTERN`, the kernel lock read in
`floor_busy`, and the new test module with the fixture every Story below shares. **Task 2 is the
scheduler's side**: `smoke` narrowed to the floor the move moved, a no-op form for each kernel
command, and `MoveOps.smoke` passing the clocks through. **Task 3 is the floor split itself**:
`KERNEL_CLOCKS`, `on_kernel`, the two-floor refusal, the two floor lines, the dry run's step list,
`MoveOps.install_floor` in place of `install_clocks`, and the one set difference that stops
`retire_candidates` naming the kernel's jobs.

Wave order: **1 → 2 → 3**. All three write `asf/upgrade.py` and the new
`tests/test_upgrade_kernel_floor.py`, so the record queues them in this order whatever `after:`
says (`PD6`) — and the order is real, not cosmetic: Task 3's `RetiredFloorTests` asserts the
retire gate Task 2 does not touch but whose module it shares, and both Task 2 and Task 3 edit the
same two `FakeOps` methods in `tests/test_upgrade.py` (`PD10`).

### Task 1: the quiesce — the kernel's two argv shapes, its lock, and the module every Story shares
stories: S-124905
writes: asf/kernel/loop.py, asf/upgrade.py, tests/test_upgrade_kernel_floor.py
