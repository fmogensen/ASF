## What no Task does

`hooks.GIT_HOOK_GLOBS` plus `hooks.RUNTIME_SETTINGS_GLOBS`, matched in `_classify_path` against a
`Write`/`Edit` target — a session editing a hook *file* is held by that recogniser, before and after.

refusal landing on sessions with no warning (C3). `--edit`/`-e`, `--remove-section` and

a set hidden in a command substitution inside a read-only simple command, since closing it means

`_read_only`, `_run_text` and `written_words` too (C9, PD5). Both pass today, so neither is a
regression; both are named in this session's report so the observation is not lost.
