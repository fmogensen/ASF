# B-0090 — plan: the plugin ships a hook carrying the operator's console rules

Item: B-0090 — The operator's console rules live in assistant memory, not code: the plugin ships
no hooks enforcing them. Epic: E-0002 — ASF 0.2 — self-improvement. Branch: `fix/B-0090`. No
spec exists; the Acceptance below is the record.

## Cause

The console rules an operator session runs under — delegate long or uncertain work instead of
doing it inline, act on a decision instead of asking, never block on a running task — lived only
in whatever an operator happened to paste into their own assistant memory. `asf plugin build`
generated skills and the plugin manifest, but no `hooks/` file, so a fresh console that installed
the plugin got none of this unless a person copied it in by hand.

## Task 1 — generate a SessionStart hook carrying the rules

writes: `asf/plugin_build.py` `plugin/README.md` `plugin/hooks/hooks.json` `tests/test_plugin.py`

- Step 1: in `asf/plugin_build.py`, add `CONSOLE_RULES`, a single-quoted-shell-safe string
  stating the console rules (delegate long work, act instead of asking, never block), sourced
  from `docs/CONSTITUTION.md` §5 and R-0113.
- Step 2: add `render_hooks_json()`, rendering a Claude Code plugin hooks file with one
  `SessionStart` hook whose command prints `CONSOLE_RULES` to stdout.
- Step 3: wire `render_hooks_json()` into `expected_files()` so `asf plugin build` writes
  `plugin/hooks/hooks.json`, and note the hook in `plugin/README.md`.
- Step 4: tests, in `tests/test_plugin.py`:
  - `test_b0090_plugin_ships_a_hook_for_the_console_rules` — `plugin/hooks/hooks.json` exists,
    its `SessionStart` hooks include a command mentioning "delegate", and `plugin_build.diff()`
    is empty (the checked-in file matches what the generator produces).

## Acceptance

- [x] `plugin/hooks/hooks.json` exists and defines a `SessionStart` hook.
- [x] That hook's command carries the operator's console rules (the word "delegate" is present,
      standing for the rule text).
- [x] `asf plugin build`'s output for `plugin/hooks/hooks.json` is byte-identical to what is
      checked in (`plugin_build.diff()` empty).

## Accepted costs

The rule text is paraphrased by hand from `docs/CONSTITUTION.md` §5 and R-0113 rather than
generated from them, so the two can drift; noted as an I-list follow-up, not blocking.
