# Plan F-0326 — the feeder says what it knows, then the doctor reads it back

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0326.md` (approved, landed in
`080cdf5a6`). Branch: `plan/F-0326`, cut from `origin/main` at `47c6d1754`.

Two Tasks, cut along the spec's own two files. Task 1 is **the feeder**: `LANDING_MIN_DEPENDANTS`,
the two typed `Row` fields, the marking of `pushed_rows`' catch-all arm, the gated
`surface_stale_landings` rule with its one call in `_candidates`, the `stalled_landings` reader
beside `orphaned_pushed`, and `TableTests.test_json`'s pin (S-91605, S-91606). Task 2 is **the
doctor**: `pushed_work_line`'s second, defaulted argument, the green text that gains "and an
owner", the red text that joins the two halves in one row, and the one line at the call site
(S-91607).

Wave order: **1 → 2**.

The two are serial and there is no parallelism to buy. Task 2's four cases call
`rows.stalled_landings` and Task 1's `landing_plan` / `landing_index` fixtures, so it needs Task 1
*landed*, not merely its files free — `after: Task 1` carries that. Their `writes:` also intersect
on `tests/test_pushed_work.py`, which both extend, so the record would serialise them in any case;
the intersection costs nothing that the real edge was not already going to cost (**PD1**).

The cut is **not** one Task per Story, and the reason is in the spec rather than in this plan:
S-91605's and S-91606's fenced cases are *one class* — `AnOwnerlessLandingNamesTheCommand`, "the
same class, no second one, which is why S-91606's acceptance command names it"
(`docs/specs/f-0326.md:705-706`) — and S-91605's rule guard reads the very fields S-91606 adds
(`r.ownerless and r.action.startswith(WAITS_LANDING) and r.pr`). Two Tasks over that pair could
only each half-write the other's class and the other's `Row` (**PD1**).

def nearer_pushed():
    """The incident's shape plus F-0001 (rank 1, one of its two Tasks landed, so nearer to done)

    idx = landing_index()
    idx['items']['F-0001'] = {'id': 'F-0001', 'type': 'feature', 'parent': 'E-0001', 'rank': 1,
                              'stage': 'building 1/2', 'state': 'Active', 'decided': True,

                              'state': 'Done', 'decided': True, 'writes': ['a2.py']}
