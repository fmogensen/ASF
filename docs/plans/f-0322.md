## Tasks

stories: S-99405

`asf retire` took a card off the board and the **Parked** row of `asf status` kept its relaunch-cap
park. The park is not stale — it is a true fact about a run that happened — but it no longer holds
anything back, and `parked_cell` is the one reader of these parks that asks the record nothing: it
folds the ledger, keeps every entry carrying `parked`, and prints it with
`` `asf unpark <item|branch|job>` releases one `` advice that, when the park's job has since been
reused by a run on another item, cannot even reach it. Every other reader already applies a record
rule — the feeder drops the row, health releases the correction, the wave never plans a row it has
not got. This Task gives that rule one name in the feeder and teaches the cell to obey it, so the
two tables can never disagree about the same park.

```python
class ARetiredCardsParkIsNotShown(_ParkedCell):
    """F-0322: ``asf retire B-1557`` took the card off the board and the Parked cell kept its

    park holds nothing back, and when the park's job has since been reused by a run on another

               'removed': 'retired: Superseded by B-1553 (landed af6c1a30b)'}

    def _park(self, item, job, reason, at='2026-10-07T20:48:47Z'):
        return {'job': job, 'item': item, 'kind': 'correct',
                'started': '2026-10-07T20:03:19Z', 'ended': '2026-10-07T20:40:00Z',
```
