Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0052.md` (approved). Branch:
`plan/F-0052`.

subtree sum §2.2 gives one owner joins the leaf, because three of the five Tasks call it. Task 1

`tests/test_views.py` — the only intersecting footprint in this plan, and free, because Task 4 is
`after: Task 1` already (P14).
