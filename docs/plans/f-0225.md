# Plan F-0225 — the supply learns what a runner can take, then the demand names it, then the ledger stops counting a run twice

Epic: E-0004 — Control plane — the factory's dashboard, served from the record. Spec:
`docs/specs/f-0225.md` (approved). Branch: `plan/F-0225`.

**Three Tasks, three waves, run 1 → 2 → 3.** One per Story, in the spec's own order. They
serialise by construction rather than by choice: all three write `asf/ci_queue.py` and
`tests/test_ci_queue.py`, so their `writes:` intersect and the queue would refuse to run them
together whatever the `after:` said.

1. **the supply** — `split_labels`, `fit_key`/`fit_asks`, `load_by_fit`/`free_by_fit` and
   `Queue.free(kind, keys)`. From here the queue *can* be asked "how many runners are free that
   carry `alpha-heavy`" and get 0 where it reads 2 today. Nothing asks yet: Task 1 alone is inert
   (PD4).
2. **the demand** — `peak_concurrent(split=…)`, `run_peaks`, `fit_caps`, `estimate`'s caps,
   `EXPECT_VERSION` **6 → 7** (PD2), the override's class collapse, `_pr_cap` per key, and the two
   call sites (`admit`, `live_line`) that pass the keys. **The card's first defect closes at the end
   of Task 2**, and the hold line starts naming the requirement it lacks.
3. **the ledger** — the `started` record carries what finds its run, `Queue._placed` nets its claim
   against the runners it already holds, a fully placed record is dropped, an unreadable host counts
   as today. The card's second defect closes here.

**Read PD2, PD3, PD4, PD5, PD6, PD7, PD8 and PD11 before writing a line of any Task.** Eight things
in the spec do not survive contact with this checkout: the version constant it bumps has already
been bumped, its baseline counts are nine tests stale, two of its helpers cannot take the argument
its design gives them, a second copy of the override logic it changes sits 1 500 lines away, the
fixtures its fences call do not have the parameters the fences pass, and one of its own fences
fails unless `split_labels` reads a narrower input than its prose names.

# tests/test_ci_queue.py
class TestStartedOnce(Base):
    def fit(self, minutes=0, **kw):
        p = product(pool=fit_pool())
        gh = FakeGh(pool=fit_pool(), labels=FIT_LABELS, history=fit_history(), **kw)
        return p, gh, self.queue(p, gh, minutes=minutes)

    def start(self):
        _p, _gh, q = self.fit()
        self.assertTrue(self.admit(q, 'pr:b', 'T-0500', branch='b').admitted)
        rec, = q.data['started']
        self.assertEqual((rec['key'], rec['branch'], rec['workflow']), ('pr:b', 'b', 'ci.yml'))
        self.assertEqual(rec['needs'], {'heavy': 2, 'heavy[alpha-heavy]': 2, 'light': 1})

    def test_a_started_run_whose_job_is_on_a_busy_runner_is_counted_once(self):
        self.start()
        # 2 min later — inside PICKUP_S — its two heavy jobs hold a1 and a2
        _p, _gh, q = self.fit(minutes=2, busy={'a1', 'a2'},
                              running=[(9, 'b', 'sha1', ['a1', 'a2'])])
        free = q.free(keys={'heavy', 'heavy[alpha-heavy]', 'light'})
        # today: heavy 0 — the two busy runners were subtracted twice (P8)
        self.assertEqual(free, {'heavy': 2, 'heavy[alpha-heavy]': 0, 'light': 1})
        rec, = q.data['started']
        self.assertEqual(rec['placed'], {'heavy': 2, 'heavy[alpha-heavy]': 2})

    def test_a_record_with_nothing_left_unplaced_is_dropped(self):
        self.start()
        _p, _gh, q = self.fit(minutes=2, busy={'a1', 'a2', 'l1'},
                              running=[(9, 'b', 'sha1', ['a1', 'a2', 'l1'])])
        # every job of the run holds a runner: the claim is the busy count, and nothing else
        self.assertEqual(q.free(keys={'heavy', 'light'}), {'heavy': 2, 'light': 0})
        self.assertEqual(q.data['started'], [])
        # and the drop is written by the pass, not only held in memory
        self.admit(q, 'pr:c', 'T-0341', branch='c')     # held: no alpha heavy is free
        self.assertEqual(ci_queue.load('p')['started'], [])

    def test_another_branchs_run_nets_nothing(self):
        self.start()
        _p, _gh, q = self.fit(minutes=2, busy={'a1', 'a2'},
                              running=[(9, 'other', 'sha9', ['a1', 'a2'])])
        self.assertEqual(q.free(keys={'heavy'})['heavy'], 0)   # still claimed: not its run

    def test_an_unreadable_busy_map_counts_as_today(self):
        self.start()
        with mock.patch.object(ci_queue.GitHubSource, 'busy_runners', return_value=None):
            _p, _gh, q = self.fit(minutes=2, busy={'a1', 'a2'},
                                  running=[(9, 'b', 'sha1', ['a1', 'a2'])])
            self.assertEqual(q.free(keys={'heavy'})['heavy'], 0)   # over-holds, never over-starts
            self.assertEqual(q.data['started'][0]['needs']['heavy'], 2)

    def test_an_empty_ledger_asks_the_host_for_nothing(self):
        _p, gh, q = self.fit()
        self.assertEqual(q.data['started'], [])
        q.free(keys={'heavy'})
        self.assertEqual([c for c in gh.calls if 'status=in_progress' in ' '.join(c)], [])

    def test_a_record_is_still_forgotten_at_the_pickup_window(self):
        self.start()
        _p, _gh, q = self.fit(minutes=4)                        # PICKUP_S = 180 s
        self.assertEqual(q.data['started'], [])
