# Plan F-0093 — a third model label, `cheap`, and a measure that argues for it

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0093.md` (approved). Branch: `plan/F-0093`.

Six Tasks, cut by module, because the spec's §2 is already cut that way and each module has its
own gate. Task 1 is everything inside `asf/briefs/` and `asf/workers/spawn.py`: the third label,
the fallback, and the two new brief kinds with their templates and goldens — the constants and the
documents every later Task's row names. Task 2 is the doctor row. Task 3 is the two example config
files. Task 4 is the answers-file half of the groom day, which touches neither the feeder nor the
briefs. Task 5 is the feeder: the groom day split into two rows, and the second spec run's row.
Task 6 is `asf improve`, and it is the one Task that waits on a Feature outside this plan.

Tasks 1–4 write disjoint files and need nothing from each other; they are wave 1. Task 5 needs
Task 1's `KINDS` — `normalize_kind` raises `BriefError` for a `brief_kind` the tuple does not
carry, so a `groom-clerk` row emitted before Task 1 lands kills the tick's wave step — and is
wave 2. Task 6 needs no code in this plan and is held on F-0091 instead (P6).

Wave order: **(1, 2, 3, 4) → 5**, with Task 6 outside the waves, blocked on F-0091.
