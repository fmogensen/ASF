# Plan F-0269 — one Task: a red module rolls again before the job calls the product broken

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0269.md` (approved).
Branch: `plan/F-0269`.

**One Task, four Stories.** The spec's own footprint is one file for the behaviour
(`tools/run_tests.py`) and two for the proof (`tests/test_run_tests.py`,
`tests/test_flaky.py`), and every Story writes into that same one file's one function —
S-67254 (the retry pass), S-67255 (the flaky block) and S-67257 (never hiding a real red) are
three readings of the same `run()` rewrite, and S-67256 (the bound and the switch) is two
constants and two flags on the function the first three already touch. No boundary separates
`run()` growing a third phase from `run()` growing the flags that gate it; splitting them would
be two sessions serialised on one function, not two sessions in parallel (same shape as
`docs/plans/f-0199.md` PD1).

   ```python
   def flaky_rows(module, rc, output):
       own_file = f'tests/{module.replace(".", "/")}.py'
       heads = list(FAIL_HEAD_RE.finditer(output or ''))
       if not heads:
           return [(own_file, 1, f'{module}: no summary (rc {rc})')]
       rows = []
       for i, head in enumerate(heads):
           end = heads[i + 1].start() if i + 1 < len(heads) else len(output)
           block = output[head.end():end]
           title = '.'.join(head.group(1).split('.')[-2:])
           file_, line = own_file, 1
           for frame in FRAME_RE.finditer(block):
               path = frame.group(1).replace(os.sep, '/')
               if path == own_file or path.endswith('/' + own_file):
                   line = int(frame.group(2))
                   break
           rows.append((file_, line, title))
       return rows
   ```
