# Plan F-0125 — adopting the in-flight queue: two conventions, one reader, one lane bit, one command, two rows, one page

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0125.md` (approved). Branch: `plan/F-0125`.

Seven Tasks, cut the way the spec's `## The design` is sectioned — by the module that gains the
surface. Task 1 is `asf/conventions.py`: the two keys, `branch_patterns` promoted from an extra to a
declared field and `legacy_review` declared for the first time, both shape-checked, both documented
in the operator's two config pages. Task 2 is `asf/evidence/review.py`: one more argument and no new
reading path, so a product's own review form can be read when — and only when — the caller says so.
Task 3 is `asf/harvest/lane.py`: the one bit on the run that says no factory session wrote these
commits, the predicate that carries it, and the two places a BACK is written. Task 4 is the command,
`asf/adoptpr.py` and its two registrations. Task 5 is the card's own end-to-end test — an adopted PR
with a legacy `(APPROVED)` review and green checks merging through native landing — which needs no
production code at all, and that is the Story (PD7). Task 6 is the `Adopted` status row and the
doctor's advisory row about `steps.batch`. Task 7 is the guide's new onboarding step.

The chain is near enough linear because each layer reads the one below it: the reader reads the
convention, the lane calls the reader, the command calls the lane, the rows count what the command
wrote, the page describes what the rows say. Only Task 6 could run beside Task 4, and it does not,
because both write `tests/test_adopt_pr.py` (PD4).

Wave order: **1 → 2 → 3 → 4 → 5 ‖ 7, with 6 queued behind 4** — in `after:` terms, 1; 2 after 1;
3 after 2; 4 after 3; 5 after 4; 6 after 3 (queued behind 4 and 5 by its footprint); 7 after 4 and 6.

§Acceptance tests' last fence — the whole suite as the pull request's CI runs it — binds every Task,
so every Gate below runs `python3 tools/run_tests.py` beside its own.

### Task 1: the two conventions keys — `branch_patterns` declared, `legacy_review` declared
stories: S-33650, S-33653
writes: asf/conventions.py, tests/test_conventions.py, tests/test_retention.py, docs/products.example.yaml, docs/guide/product-config.md
after: none

The spec's third and fourth **In** bullets and `## The design` §1's and §2's conventions halves. Two
keys move from "kept verbatim in `Conventions.extra`" to declared, documented, shape-checked fields,
and the operator's two config pages gain them. No reader changes in this Task: retention keeps
reading `branch_patterns` exactly as it does today, and nothing reads `legacy_review` yet.

**Files**

- `asf/conventions.py` — `DEFAULT_BRANCH_PATTERNS`, `PLACEHOLDER_RE`; the two dataclass fields
  `branch_patterns` and `legacy_review`; two blocks in `validate_mapping`
- `tests/test_conventions.py` — the shape cases for both keys
- `tests/test_retention.py` — one case pinning `owned_patterns` over a pattern carrying placeholders
- `docs/products.example.yaml` — the `legacy_review` block beside `review_pattern` (`:49`), and a
  `branch_patterns` block beside it
- `docs/guide/product-config.md` — both keys in the conventions table (`:71-72`) and a paragraph each

**Steps**

1. `DEFAULT_BRANCH_PATTERNS = {}` and `PLACEHOLDER_RE = re.compile(r'<(id|slug)>')` with the spec's
   comment byte for byte (`## The design` §1). The default is a **plain empty dict**, not a path
   string: `python3 -m asf.conventions --forbidden` generates one pattern per path-shaped default and
   a default that looked like a glob would forbid its own text across `asf/**/*.py` (PD15, D7).
2. `branch_patterns: dict = field(default_factory=lambda: dict(DEFAULT_BRANCH_PATTERNS))` beside

3. `validate_mapping` (`:438`) gains `branch_patterns`: not a map → one problem; a value that is not
   a non-empty string → one problem naming the entry; a value carrying more than one `<id>` or more
   than one `<slug>` → one problem; a value that does not compile once its placeholders are replaced
   → one problem. The docstring's list of checked keys grows both new names.
4. `validate_mapping` gains `legacy_review`: not a map → one problem (today `{'legacy_review':
   'nope'}` returns `[]`, measured — P14); a key that is not `glob` or `verdict_regex` → one problem
   naming it; either value missing, not a string, or empty → one problem; `verdict_regex` that does
   not compile → one problem carrying the `re.error`; a `glob` with no `{slug}` → one problem, since
   a glob without it reads one item's review as every item's (§2).
5. Nothing is added to `asf/env.py`: `env.validate_product_text` already routes the whole
   `conventions:` map through `validate_mapping` and reports each problem as `conventions.<key>` with

   style is **not** added here; instead the Gate runs `tests.test_env` and `tests.test_sample_product`

6. `tests/test_conventions.py`: `branch_patterns` survives `from_mapping` as a declared field and not

7. `tests/test_retention.py`: the existing fixture at `:88-93` already declares

   `{'hotfix': 'hotfix/<slug>', 'feature': 'feature/<id>-<slug>'}` gets globs `hotfix/*` and
   `feature/*-*` out of `owned_patterns`, so the declared field and the `<…>` → `*` substitution at

8. `docs/products.example.yaml`: the `legacy_review` block exactly as §2 writes it, beside

9. `docs/guide/product-config.md`: two rows in the conventions table at `:71-72` — `branch_patterns`

### Task 2: the one review reader learns the product's own form, and reads it only when asked
stories: S-33653
writes: asf/evidence/review.py, tests/test_review_reader.py
after: Task 1

The spec's fourth **In** bullet and `## The design` §2's reader table. One compiled pattern, one more
source of rounds, one more branch in `read`, and one argument threaded through `review_at`. The
default path — every call site that exists today — is byte for byte what P10 does now, so no branch
the factory pushed changes its reading.

**Files**

- `asf/evidence/review.py` — `legacy_rx(conv, slug)`; `rounds(conv, paths, slug, legacy_prefixes=(),
  legacy=False)`; `read(text, legacy=False, required=(), conv=None)`;
  `review_at(repo, conv, ref, item, required=(), legacy=False)`
- `tests/test_review_reader.py` — the reader's cases for the new form and for the default path

**Steps**

1. `legacy_rx(conv, slug)`: `None` when `conv.get('legacy_review')` is not a map with a non-empty
   `glob`; else `pattern_rx`'s body (`:107-115`) over that glob — `re.escape` the literal, then
   substitute `{reviews_dir}` with `_dir_of(conv)`, `{slug}` with the lower-cased slug and `{n}` with
   `(?P<n>\d+)`, compiled `re.I`. The three placeholders are `review_pattern`'s, so the operator
   learns one substitution and not two (D7). A glob with no `{n}` is legal and matches at round `1`.
2. `rounds` grows `legacy=False`. With `legacy` false it is unchanged, line for line. With it true and
