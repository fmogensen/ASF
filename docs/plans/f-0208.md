# Plan F-0208 — one map of what every open ref books, and three readers of it

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0208.md` (approved). Branch:
`plan/F-0208`.

Four Tasks, cut so that **the map is built and provable before anything reads it**:

1. **`asf/reservations.py`, whole** — the three booking readers, the merge, the rank and holder
   rule, the refusal's words, the next-free answer, and the snapshot's writer, reader and words.
   One new module and one new test module, and nothing else in the tree moves. Every other Task
   is a caller of this one.
2. **the lane holds the newcomer, and the landing declines it** — `lifecycle.RESERVED` joining
   `MECHANICAL`, the clash as `f['refusal']`, the snapshot written once per pass, and
   `land_spec.adopt` adopting nothing for a clashing carrier.
3. **the planner is told before it books** — the snapshot read into `repo_facts`, carried through
   `preamble.collect`, and one untrimmable line in `state_lines`.
4. **one definition of "open lane branch", and the config key** — `asf reserve` onto
   `reservations.open_refs` and the merged holdings, `conventions.reservations` typed and
   validated, and both keys documented in the example config.

They run **1 → (2 | 3 | 4)**. Tasks 2, 3 and 4 each need Task 1's landed module and nothing of
each other, and their `writes:` are disjoint — `asf/harvest/*` + `asf/tick/*` + `asf/workers/*`,
`asf/briefs/*`, `asf/reserve.py` + `asf/conventions.py` + `docs/` — so they are one wave, not a
queue. Task 1 alone is serialising, and it has to be: three call sites agreeing on one predicate
is the whole argument of C1, and a predicate written three times in parallel is the defect this
card exists to close.

**Read PD1, PD4, PD5 and PD11 before writing a line.** Each is a place where following the spec's
design literally ships a red module or a silent no-op the spec's own fences would not catch:
`preamble.collect` never carries the key (PD1), `reserve.reserve` has no `items` to pass (PD4),
the two callers hold PR facts in different shapes (PD5), and a `snapshot` call inside
`reserve.reserve` escapes the seam the existing tests patch (PD11).

The fences of §*The fences, and the suite* bind every Task, so every Gate and Acceptance block
below carries them beside its own.
