# Plan F-0288 — three Tasks: the fourth ruling field, the brief that asks for it, and the tick that carries it out

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0288.md` (approved).
Branch: `plan/F-0288`.

**Three Tasks, four Stories, two waves.** The spec's design is three sections over three
non-overlapping footprints: the parser field (`asf/workers/report.py`), the ask
(`asf/briefs/*`, the report-shape skill), and the mechanism (`asf/tick/strike.py` new,
`asf/tick/step_health.py`, `asf/record/undeliver.py`). Only one edge is real: the strike reads
`report.ruling_fields(...)['undelivers']`, so Task 3 waits on Task 1. The brief's tail is prose
the parser never reads, so Task 2 waits on nothing and runs beside Task 1.

S-75406 (the tick carries it out) and S-75407 (the struck member builds on its own) are one Task
and not two: S-75407's last two acceptance lines require the strike's **own output line** to name
the cascade it caused, so the Story cannot be satisfied by a test module alone — it writes into
`asf/tick/strike.py`, which is S-75406's file. Splitting them would serialise two sessions on one
new module for no parallelism (same shape as `docs/plans/f-0269.md`'s one-Task argument).

Wave order: **wave 1 — Task 1 and Task 2** in parallel, both `after: none`; **wave 2 — Task 3**,
`after: Task 1`. Task 3 does not need Task 2.

**Every precondition and every choice below was measured in this worktree at `8f243eaa9`, on the
real code, by throwaway probes under the scratchpad (six scripts, deleted before this commit; the
branch's diff is `docs/plans/f-0288.md` alone).** The probes found two things the spec could not:
one defect in the spec's own chosen design, which this plan corrects before a coder meets it
(PD1), and one acceptance line that names two edit sites where there are three (PD2). Both are
corrections inside the spec's scope, not widenings. A third finding (PD4) confirms a
contradiction the spec already names between C6 and S-75407, and carries it to a person.
