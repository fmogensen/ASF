# Plan F-0101 — the model follows the need, and the spend says so

Epic: E-0002 — ASF 0.2 — self-improvement. Spec: `docs/specs/f-0101.md` (approved). Branch: `plan/F-0101`.

Seven Tasks, cut by the module that changes. Task 1 is the vocabulary and the table — `HEAVY`,
`LIGHT`, `DEFAULT_MODELS`, `models:` and `heavy_share_pct` as typed conventions, with
`briefs.build` importing them and keeping no copy. Task 2 is the cause vocabulary in
`lifecycle` — the seven constants, `mechanical()`, and harvest/health/step_health passing the
constants where they pass literals today. Task 3 joins the two: `need_key`, `model_for(…, row)`,
and the feeder row carrying the cause the ledger recorded. Task 4 is the other two launch paths —
the cold retry resolving its own model, `spawn` writing `model_label`, `pr_hygiene` printing a
resolved label and no vendor name. Task 5 is the stream and the rollup: the schema key, the kinds,
`spend_by_kind_model`, `heavy_share`, the new section and the waste row. Task 6 is the threshold
that files a Bug. Task 7 is the doctor row.

Tasks 1 and 3 both write `asf/briefs/build.py` and `tests/test_briefs.py`, so they run one after
the other — which is also their dependency order, since Task 3's `need_key` reads Task 1's table
and Task 2's `mechanical`. Tasks 2, 4 and 7 write nothing each other or Task 3 and Task 5 write,
and run together in the second wave. Task 5 needs Task 4's `model_label` on the launch record
before it can carry it into the stream; Task 6 needs Task 5's `heavy_share`.

Wave order: **1 → (2 ∥ 4 ∥ 7) → (3 ∥ 5) → 6**.

### Task 1: the labels, the table and the threshold are conventions with one owner
stories: S-16200
writes: asf/conventions.py, asf/briefs/build.py, tests/test_conventions.py, tests/test_briefs.py

§2.1, **as landed, narrower than fenced (P18)**. `HEAVY` and `LIGHT` move out of
`asf/briefs/build.py` into `asf/conventions.py`, where every other documented default lives, and
`heavy_share_pct` becomes a typed field with `DEFAULT_HEAVY_SHARE_PCT = 50`. `DEFAULT_MODELS` and
