# Plan F-0236 — the deadline the lane's own docstring already promised, and the two ways out of it

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0236.md` (approved). Branch:
`plan/F-0236`.

Three Tasks, cut so that **no Task leaves the factory with a clock that has nowhere to tick**:

1. **the clock, and the one way out that costs nothing** — `overdue_s`, the `next_state` block that
   reads it, the `PUSHED` check removed, and the send-back (`BACK kind=stalled`) wired end to end:
   the kind, its routing, its text, and the one line of `advance` without which a `BACK` branch can
   never be sent back at all (PD4). Every open state is bounded the moment this lands, and every
   overdue branch goes back to a session.
2. **the reap, for the branch that cannot land** — `f['unlandable']`, the `REAPED` arm, `archive()`
   serving both terminal states, `REAPS_PER_PASS`, and `pr_hygiene`'s two new lanes. `REAPED` gets
   its first writer in the product's history.
3. **the churn cap** — `stalled_holds`, `stalled_park`, `STALLED_CAP`, and the two call sites that
   consult it, so the reaper cannot become the inflow it was built to drain.

They run **1 → 2 → 3**, one at a time. The footprints force it — all three write
`asf/harvest/lane.py` and `tests/test_lane.py` — but the order is the card's own argument too:
Task 1 is the only one of the three that is safe to land alone, because it is the only cut at which
every overdue branch has somewhere to go. Task 2 is why the number falls; Task 3 is why it stays
fallen.

**Read PD1 through PD6 before writing a line of Task 1.** The spec's design is sound and its
preconditions all hold — re-measured here, every one — but four of its snippets are incomplete in
ways that are silent rather than loud: a constant that cannot live where it is written (PD2), a
deferred push that would write the wrong terminal state (PD5), a send-back that `advance` swallows
before `enter` is ever called (PD4), and a helper the snippets call three times that does not exist
(PD3). None of them changes the design. All four turn into a session debugging the factory on the
trunk if they are met for the first time while coding.

## What was measured here, and what it cost the design

Everything below was run in this worktree at `bf45bb402`. The spec's own sha, `cf6e21404`, is an
ancestor of it, and `git diff --stat cf6e21404 HEAD` over every file the spec names is **empty** —
so every line anchor in the spec is still exact, and the ones in this plan are the same ones. The
trunk has moved three commits past this branch point (`80659380f`) and all three are documents:
no code the Tasks below touch has moved on the trunk either.

**The spec's A0 is real, and it passes as written.** The four assertions were written as a probe
module and run: `Ran 5 tests` / `OK` (the fifth is PD6's). The sinks are sinks —

```
  PUSHED       -> STALE        'unmoved in PUSHED past lane.stale_after'
  PR_OPEN      -> REVIEW       'round 1 wanted: no ASF review yet'
  REVIEW       -> REVIEW       'round 1 wanted: no ASF review yet'
  GATE         -> GATE         ''
  WAITING_CI   -> WAITING_CI   ''
  WAITING      -> WAITING      ''
  BACK + pending correction -> BACK 'kind=review'
  transitions into REAPED from a non-REAPED state: []
```

— and the exempt three leave their state for reasons of their own (`PARKED → PR_OPEN` on a PR that
is not a draft, `MERGING → GATE`, `QUEUED → WAITING`), none of them `STALE`.

**The blast radius of the deadline is one assertion.** The minimal change — `overdue_s`, the
`next_state` block, the `PUSHED` check removed — was applied here and the whole targeted gate run
against it: `Ran 589 tests`, `FAILED (failures=1)`, the single failure being
`tests/test_lane.py:150` (`'BACK' != 'STALE'`), which is the one the spec already names. Then
reverted. That number is small for one reason worth knowing before touching a fixture: `rec()`
stamps `at='2027-01-15T08:00:00Z'`, `facts()` stamps `now=1_800_000_000.0`, and those are **the
same instant** — so every record the existing table builds is zero seconds old and nothing in it
is overdue by accident (PD6).
