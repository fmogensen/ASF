# Plan F-0106 — three Tasks, two waves: the module and its mint, the `after:` that is never dropped, then the seat

Epic: E-0002 — ASF 0.2 — self-improvement. Spec: `docs/specs/f-0106.md` (approved). Branch:
`plan/F-0106`.

**Three Tasks, one per Story, in two waves.** Story 2 (`plan_order` + the feeder + the plan brief)
shares no file with Story 1 and needs nothing from it, so it starts at once. Story 3's preflight
calls `trunk_check.satisfied_on_trunk` and `trunk_check.close_by_trunk` — the module Story 1
creates — so it waits.

1. **Task 1 — the module, the mint, and the typed sha that finally closes.**
   `asf/record/trunk_check.py` (new), the mint's close in `asf/record/plan_tasks.py`, `landed=`
   into `asf/record/ingest.py`'s task loop, and `tests/test_trunk_check.py` (new) with its first
   four classes. `after: none`.
2. **Task 2 — an `after:` the record cannot answer comes back to the plan session.**
   `asf/record/plan_order.py`, `asf/feeder/rows.py`, `asf/briefs/templates/plan.md`, and
   `tests/test_unminted_after.py` (new). `after: none`.
3. **Task 3 — the wave asks the trunk again, at the seat.** `asf/tick/step_wave.py` and the
   `WavePreflight` class appended to the file Task 1 created. `after: Task 1`.

Wave order: **(1, 2)** → **3**. Tasks 1 and 3 intersect on `tests/test_trunk_check.py`
deliberately — the `after:` edge already serialises them, so the shared file costs nothing.

**Read PD1 before writing a single line of Task 1 or Task 3.** It is the one finding in this plan
that changes what the card should do: measured over 121 plan Task sections at each plan's own
landing commit, the spec's §1 predicate mints **16** of them Closed, and the ones inspected are
real work. A `NEEDS OPERATOR` line at the end of this document asks for the ruling. Everything
else in this plan is sound and is written to be built.

Read **PD3 before choosing where `trunk_preflight` goes in `launch`** — the spec's code sample and
the spec's own prose disagree, and the sample's placement prints a false `no seat left` line.
**PD4 before wrapping anything in `stage.guarded`.** **PD9 before writing `UNMINTED_AFTER_RECUT`'s
sentence** — the reshape brief has no mode that reads it, so the sentence is the whole message.

### Task 1: the trunk is asked before a Task is minted, and a typed `landed:` finally closes one
stories: S-37250

The spec's `## The design` §1 and §2 in full, and nothing else. After this lands there is one
