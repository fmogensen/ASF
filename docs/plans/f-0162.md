# Plan F-0162 — the marker is written for a commit nobody has

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0162.md` (approved). Branch: `plan/F-0162`.

Three Tasks, cut so that **the resolver lands before the gate that consults it**:

1. **the resolver** — `_NWO`, `_out`'s `any_rc`, `known_ref` and `resolve_target`, with their two test
   classes. Every line is new and nothing calls it: `install()` is untouched, so the factory's
   behaviour is byte-identical when this lands. The three-valued answer is live, tested and idle.
2. **the gate** — `install()`'s head rewritten over `resolve_target`: the refusal before
   `other_ticks`, before `refuses`, before `write_pending`, before `drain` and before `pipx`, and
   with it the short sha the guide has always promised. This is the card's whole fix.
3. **the prose** — the module docstring's marker paragraph and `docs/guide/upgrading.md`, each with
   an assertion, saying what a refused ref costs: nothing is pending and no tick is parked.

They run **1 → 2 → 3**, one at a time. The order is not a convenience and the footprints do not
leave a choice: all three write `asf/upgrade.py`, and Tasks 1 and 2 both write
`tests/test_install.py`. Beyond the queue, Task 2 cannot be written before Task 1 — `install()`'s new
head is a call to a function Task 1 creates — and Task 3 describes a refusal that does not exist
until Task 2 lands.

**Read PD1 and PD2 before writing a line of a test.** The spec's acceptance fixtures are wrong in two
places that both land *green-looking*: one case in §S-35883 cannot pass as written (its fixture
contradicts the guard the spec itself introduces), and the `any_rc` keyword that the entire 422 read
depends on is invisible to `FakeRun` and would ship with no test that fails without it.

The spec's regression fence and its two tree fences bind every Task, so every Gate and Acceptance
block below carries them beside its own.

### Task 2: the gate — a ref the install source does not have writes no marker and exits 2
stories: S-35882, S-35883
writes: asf/upgrade.py, tests/test_install.py
after: Task 1

The spec's third and fourth **In** bullets and `## The design` §`install()`'s head. One call to Task
1's `resolve_target` at the top of `install`, one refusal line, one `return 2` — and with it the
card's whole fix: the marker is never written for a commit nobody has, and the short sha
`docs/guide/upgrading.md:30` has always promised installs.

It waits on Task 1 because its one new line calls a function Task 1 creates, and because both write
`asf/upgrade.py` and `tests/test_install.py`.

**Read PD2 before writing `ShortShaTests`** — the spec's fixture for its first case contradicts
`known_ref`'s own guard and the case cannot pass as written. Read **PD3** (blank `ls-remote` or the
probe is never reached), **PD5** (why no existing test moves, so a red here is this Task's own),
**PD9** (the marker this refusal deliberately does *not* clear) and **PD4** (`install`'s body is
twelve lines below where the spec cites it).

**Files**

- `asf/upgrade.py` — the head of `install`, `:537-547` (PD4 — the spec's `:525-534`/`:535`)
- `tests/test_install.py` — `UnknownRefTests` and `ShortShaTests`, beside `PendingUpgradeTest`
  (`:770`)

**Steps**

1. `install()`'s head (`:537-546`) becomes the spec's block byte for byte: `marked = None`,
   `pin = ref`, `url = repo_url(run) if ref else None`, then `if ref:` →
   `ref, refusal = resolve_target(url, ref, run)` and, on a refusal,
   `out(f'upgrade: refused — {refusal}; no upgrade is pending and no tick is parked')` and
   `return 2`. The exit code is 2, never `DEFERRED` — 75 means *due again next tick*, which would
   make a tick retry a typo forever (D6, P12).
2. `others = other_ticks(run)` moves from `:537` to **below** that block, and `if others and (owner
   or wait_s):` (`:547`) opens with `url = url or repo_url(run)` instead of `url = repo_url(run)`.
   A refused ref now costs no `pgrep`. Nothing else in `install` moves: `pin` still carries what the
   operator typed, the `refuses`/`write_pending` branch is untouched, `drain` is untouched, and
   `rc = _install(ref, run, out, pin=pin) if pin != ref else _install(ref, run, out)` is untouched —
