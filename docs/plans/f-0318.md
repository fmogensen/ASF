# Plan F-0318 — the pass, then its place in the tick, and the briefs that ask for the form it mints

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0318.md` (approved). Branch:
`plan/F-0318`.

Three Tasks, cut along the spec's own five design sections and along what each one's acceptance
fence can turn green.

Task 1 is the **pass**: `asf/record/spec_stories.py` (§1) — the collection pass that admits a
Feature whose spec alone is on the trunk, the one batched read, the minting loop and its two
skips — together with §2's three additive functions in `asf/record/plan_tasks.py` that §1 imports
(`spec_ref`, `own_doc`, `doc_alias`) and the test that pins the plan path's deliberately
unchanged half (S-91005, S-91006, S-91007, S-95555).

Task 2 is the **place**: §3's call inside `run_record_fast`'s `if product.repo_dir:` block
between the ingest and the landed-plan pass, with the hoisted `evidence.load`, and §4's entry in
`stage.WRITERS` — plus the two test classes that can only go green once those land, which are
what make the gate clear in the tick the spec lands (S-91008, S-91009).

Task 3 is the **briefs** (§5): the spec template's item 5 asking for both forms, and
`STORIES_FIRST`'s corrected landing (S-91010).

Wave order: **1 ∥ 3 → 2**.

Task 1 and Task 3 start at once — their `writes:` are disjoint and neither needs the other.
Task 2 declares `after: Task 1` because its two test classes drive `mint_spec_stories`, which
does not exist until Task 1 lands. Task 1 and Task 2 also intersect on
`tests/test_spec_stories.py`, so the record would queue them even without the edge; the edge
costs nothing and states the real reason (**PD6**).

**The deadlock is not broken until Task 2 lands.** Task 1 writes a pass nothing calls; Task 2 is
the line that calls it. The one-off backfill the spec measures — 126 Story cards across 23
Features (P13), taking the standing `story … has no Task listing it in stories:` class from 152
findings to 238 (P14) — fires on the first tick after **Task 2**, not Task 1 (**PD3**).
