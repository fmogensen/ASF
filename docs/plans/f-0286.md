# Plan F-0286 — the watch is written; this plan makes it visible and makes its cancels finish

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0286.md` (approved). Branch:
`plan/F-0286`.

Three Tasks, one per Story, run **one after another**. The spec's `## The design` cuts itself into
three sections and the record's three Stories were minted off them, each with its own fenced
acceptance command — so the cut is the spec's own and this plan adds nothing to it. The three
sections touch different functions of the same module: `watch`/`load`/`save` plus
`asf/state/registry.py` for the first, a new `doctor_rows` plus `asf/doctor.py`,
`asf/config_keys.py` and `docs/config.example.yaml` for the second, `_advance` and the prune for
the third. That is three diffs, not one — but all three write `asf/ci_stall.py` and
`tests/test_ci_stall.py`, so their `writes:` intersect and the footprint gate queues them. The
queue is accepted rather than designed away: there is a real dependency under it (the row reads
the `pass` block the first Task writes, and the retry uses the constants the second declares,
PD8), so a wave of three would have been serialised by correctness even if the footprint had
allowed it.

What the code half of this card already does is **out** of all three Tasks: `judge`, the measured
max, the claim-before-cancel and the single re-run are landed and green (P1–P5, re-measured at
this head in PD1). This plan builds only the half the spec says is missing — the pass stamps
itself and survives the reaper, `asf doctor` names which watcher acts, and a cancel this watch
made is finished in either mode.

Wave order: **1** → **2** → **3**.
