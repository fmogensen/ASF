# Plan F-0323 — the fact and the rule, the lane's belt, and the refusal that names the route

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0323.md` (approved). Branch:
`plan/F-0323`.

Three Tasks, one per Story, cut along the spec's own section boundaries. Task 1 is the
**derivation** — the `refix` fact in `id_evidence` (§1), the `refixing` rule in `closing.RULES`
(§2) and ingest writing the state, the line and the dropped stamp (§3), which is the whole of the
record side and the only half that makes a second fix legal (S-93155). Task 2 is the **belt** —
`builds_on_landing` beside `superseded_by` and the three done-card reads in `Lane.branch_facts`
and `Lane.orphan_facts` that close the window between a card the record has not yet moved and a
PR the lane is about to shut (S-93156). Task 3 is the **route** — `asf reopen`'s refusal gaining
the second line that says where a second fix goes (S-93157).

Wave order: **1 ‖ 2 → 3**.

Task 1 and Task 2 share nothing. The belt reads the card's `landing.sha` against the branch head
with `git merge-base`; it never reads `refix`, never constructs an `Ev` and never imports the
evidence rules, so it needs no part of Task 1 landed and declares `after: none`. Task 3 does need
Task 1: its first case reopens a `Closed` Bug *through the `refixing` rule*, so without
`Ev.refix` and the rule row the fixture cannot even build its evidence — `after: Task 1`. All
three footprints are disjoint, so nothing queues on `writes:` and the only ordering is Task 3's
real edge (**PD9**).
