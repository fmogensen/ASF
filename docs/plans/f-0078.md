# Plan F-0078 — The tick ends with two tables: in flight, and done since the last tick

Binding: the approved spec `docs/specs/f-0078.md`. Nothing here adds scope it does not carry.

The change is small and its shape is fixed by the spec: one new module `asf/tick/summary.py` that
folds the session ledger into two padded-column blocks, one new test file, three lines of wiring in
`asf/tick/tick.py`, and the exact-output tick tests taught that a tick's stdout now ends with those
two blocks. No step line moves, nothing new is written to the record, and the tick's exit code is
the steps' and the commit's as before.

Two Tasks, two waves. Wave 1 builds the module alone — unused by anything, so the whole suite stays
green the moment it lands. Wave 2 calls it from `_run_steps` and carries the tables into every
assertion that pins a tick's stdout. Wave 2's footprint names `asf/tick/summary.py` as a file its
diff may touch, so the feeder queues it behind wave 1 (`asf.feeder.footprint`) rather than launching
both at once against a module that does not exist yet.

## Decisions

| # | the question the spec leaves open | the plan's answer |
| --- | --- | --- |
| 1 | The spec's §2 names `tests/test_tick.py` as the file whose exact-output assertions must be updated. `tests/test_tick_steps.py` has two more (`OrderedTickTests.test_a_failing_step_never_stops_the_rest_and_exits_1` pins `lines[-1]`; `test_command_steps_alone_do_not_clone_the_record_to_log` pins the whole of stdout). | Both are in scope. S-7104's own acceptance is `python3 -m unittest discover -s tests`, which cannot be green while they are red — naming them is reading the spec's gate, not widening it. Task 2 lists them. |
| 2 | `age()` on a run whose `ended` precedes its `started` (a clock that stepped back between the launch line and the health line). | `?`, the same as an unparseable stamp. A negative duration is not a duration, and `?` says so; the spec fixes only the four positive buckets. |
| 3 | How `titles()` reads `index.json`. | Through `asf.views.index_reader.load(record_dir(product))`, the repo's one reader of an index, wrapped in the `except` that returns `{}`. A second `json.load` of the same file would be the second reader the spec refuses for the ledger, in the other file. One consequence to accept: `index_reader.load` drops items typed `removed`, so a removed item's `what` is `—`. That is within "a snapshot, good enough for a title". |
| 4 | Where `now` comes from when the caller passes none. | `asf.workers.pool.now_iso()` — the function the ledger's own `started`/`ended` stamps are written by. The window is compared as strings (the spec's choice), and that is only total if `now` is minted in exactly the ledger's format and zone. |
| 5 | Whether `clock()` re-implements the scheduler's slug. | No: `scheduler.steps_slug(chosen)` when `chosen`, `'all'` otherwise. `ClockTests.test_clock_slug_matches_the_schedulers` asserts the two agree; delegating makes that true by construction, and `asf.scheduler` imports only `asf.env`, so there is no cycle. |
| 6 | Where the helper that strips the summary off a step-log assertion lives, given two test files need it. | Module-level `steps_only(out)` in `tests/test_tick.py`; `tests/test_tick_steps.py` imports it from there, as it already imports `TickTestCase, _git`. |
| 7 | How broad the `except` in `run()` may be. | `except Exception as e:  # noqa: BLE001`, the idiom `tick.run_asf_step` already uses for the same reason: best-effort output whose failure must never reach the tick's rc. The line carries `str(e)`'s first line. |

The spec is not wrong anywhere this plan found.

### Task 1: the summary module — the window, the rows, the two tables
stories: S-7101, S-7102, S-7103, S-7105
writes: asf/tick/summary.py, tests/test_tick_summary.py

**Files**

- `asf/tick/summary.py` — new. The whole module; nothing imports it yet.
- `tests/test_tick_summary.py` — new. The spec's block, verbatim.

**Steps**

1. Write `asf/tick/summary.py` with a module docstring saying what it is: the two tables the tick
   ends with, folded out of the session ledger through `asf.workers.lifecycle` and titled from the
   record clone's `index.json`; best-effort console output that writes nothing to the record and
   never changes a tick's exit code. Imports: `datetime`, `os`, `from asf import env, scheduler`,
   `from asf.tick import shadow`, `from asf.views import index_reader`,
   `from asf.views.sessions import pid_alive`, `from asf.workers import lifecycle, pool`.
   `lifecycle` and `pool` are module attributes, not `from … import runs` — `FailureTests` patches
   `summary.lifecycle.runs`, and a name bound at import time would not see it.

2. The clock and its stamp:
   - `clock(chosen)` → `scheduler.steps_slug(chosen) if chosen else 'all'`. `chosen` arrives from
     `steps.parse_steps` already in manifest order (`asf/tick/steps.py:69`), so the slug pairs with
     the scheduler's log name (`asf/scheduler.py:104`).
   - `stamp_path(product, clock)` → `os.path.join(env.state_dir(product), f'summary-{clock}.stamp')`.
     `env.state_dir` makes the directory; `daily.stamp` is its neighbour and the names do not meet.
   - `read_stamp(product, clock)` → the file's stripped contents, or `None` when it is absent,
     unreadable or empty. `write_stamp(product, clock, now_iso)` writes `now_iso + '\n'`.
   - `window_start(stamp, now)` → `stamp` when there is one, else `now` minus 24 h rendered in the
     ledger's format (`'%Y-%m-%dT%H:%M:%SZ'`).

3. `age(start_iso, end_iso)`: parse both (`datetime.datetime.strptime(s, '%Y-%m-%dT%H:%M:%SZ')`);
   on a missing or unparseable stamp, or a negative delta, return `'?'`. Else, on the total seconds:
   under 60 → `'<1m'`; under an hour → `f'{m}m'`; under a day → `f'{h}h{m:02d}m'`; else
   `f'{d}d{h:02d}h'`. `ClockTests.test_age_buckets` is the whole specification of this function.

4. `titles(product)`: `index_reader.load(shadow.record_dir(product))` → `{id: item['title'] or ''}`;
   `{}` on `OSError`, `json.JSONDecodeError`, `KeyError` or `TypeError` — a missing or malformed
   index is a `—` in a column, never a failed summary. Never calls `ctx.record_root()`: a clock that
   does not run `record` must not clone the record to print a title (the spec's choice), and the
   `FailureTests` fixture hands `run` a context whose `has_record` is False.

5. The rows, both through `lifecycle`:
   - `inflight_rows(product, alive)` → `pool.live_sessions(product)` (which is
     `lifecycle.is_live` over `lifecycle.latest`), each run copied with
     `status = 'working' if alive(run.get('pid')) else 'dead pid'`, sorted by `started`, oldest
     first, missing `started` sorting last.
   - `done_rows(product, since, now)` → every run of every job,
     `[r for rs in lifecycle.runs(pool.sessions_path(product)).values() for r in rs]`, kept when
     `r.get('ended')` and `since < r['ended'] <= now`, sorted by `ended`, oldest first. It is
     `lifecycle.runs` and never `pool.load_sessions`: the latter is `lifecycle.latest`, one run per
     job, and would drop the ended run of a job relaunched inside the window — the run no later tick
     could ever report, because the window has moved past it (B-0041).

6. `render(inflight, done, titles, since, now, first)`, pure — no clock, no disk, no `print`.
   Returns a string that opens with a blank line and carries no trailing newline, so that
   `print(render(...))` after the commit line reads as the spec's example.
   - One private `_block(title, columns, rows)` builds both. With no rows it is one line,
     `f'{title} — none'`. With rows: the header line, then the column-name line, then one line per
     row. A cell is `str(value)` or `—` when the value is missing or empty. Every column but the
     last is padded to the widest cell **including its own column name** — `ShapeTests
     .test_columns_pad_to_the_widest_cell` reads the row cells at the offset it found in the header
     line — and cells are joined by two spaces; the last column (`what`) is never padded.
   - The count in a header is `none`, `1 session` or `f'{n} sessions'`.
   - IN FLIGHT: title `IN FLIGHT`, columns `job item kind feature account model status since what`,
     `since` = `age(run['started'], now)`, `what` = `titles.get(run['item'])`.
   - DONE: title `f'DONE since {since}'` plus `' (first tick on this clock)'` when `first`, columns
     `job item kind result took what`, `result` = the ledger's `end_reason` never re-worded, with
     `f', landed {run["harvested"][:7]}'` appended when `lifecycle.landed(run)`, `took` =
     `age(run['started'], run['ended'])`.
   - The two blocks are joined so that a blank line precedes each.

7. `run(ctx, chosen, out=print, now=None, alive=pid_alive)`: `now = now or pool.now_iso()`, then in
   one `try` — resolve the clock, read the stamp, compute `since = window_start(stamp, now)`, build
   both row lists and the titles, `out(render(inflight, done, titles, since, now, stamp is None))`,
   and only then `write_stamp(product, clock, now)`. `except Exception as e:  # noqa: BLE001` →
   `out(f'tick: summary not rendered ({detail})')` where `detail` is `str(e)`'s first stripped line,
   falling back to `type(e).__name__`. Returns `None` always and raises nothing. `render` is called
   through the module global so a test can patch `summary.render`; the stamp is written after the
   `out`, so a render failure leaves the old window standing and the next tick still covers it.

8. Add `tests/test_tick_summary.py` exactly as the spec's Acceptance block below. Do not soften an
   assertion to fit the code: where they disagree the code is wrong.

9. Nothing in `asf/tick/tick.py` is touched by this Task. The module lands unused, and the suite is
   green because of it.

# tests/test_tick_summary.py
"""asf.tick.summary — the two tables the tick ends with, over the ledger and the index."""
import json
import os
import shutil
import tempfile
import unittest
from unittest import mock

from asf import env
from asf.tick import shadow, summary
from asf.workers import pool as pool_mod

NOW = '2026-09-22T12:00:00Z'
INDEX = {'generated': '', 'items': {
    'F-0001': {'id': 'F-0001', 'type': 'feature', 'title': 'a feature', 'folder': 'features',
               'state': 'New', 'decided': True, 'rank': 1},
    'B-0002': {'id': 'B-0002', 'type': 'bug', 'title': 'a bug', 'folder': 'bugs',
               'state': 'New', 'decided': True, 'rank': 1, 'parent': 'F-0001'},
}}


class SummaryTestCase(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.mkdtemp(prefix='summary_test_')
        self._home = env.ASF_HOME
        env.ASF_HOME = os.path.join(self.tmp, 'home')
        os.makedirs(env.ASF_HOME)
        self.addCleanup(self._restore)
        self.product = env.Product('p', {'repo_dir': self.tmp, 'main': 'main',
                                         'ci': {'provider': 'none'}, 'deploy_sha': 'none'})
        os.makedirs(shadow.record_dir(self.product))
        with open(os.path.join(shadow.record_dir(self.product), 'index.json'), 'w') as f:
            json.dump(INDEX, f)

    def _restore(self):
        env.ASF_HOME = self._home
        shutil.rmtree(self.tmp, ignore_errors=True)

    def launch(self, job, item='F-0001', kind='spec', started='2026-09-22T11:48:00Z', **extra):
        pool_mod.append_session(self.product, dict(
            job=job, item=item, kind=kind, feature='F-0001', account='acct-a', model='opus',
            pid=101, branch=f'{kind}/{item}', started=started, **extra))

    def render(self, chosen=None, alive=lambda pid: True, lines=None):
        lines = [] if lines is None else lines
        summary.run(_ctx(self.product), chosen, out=lines.append, now=NOW, alive=alive)
        return '\n'.join(lines)


class _ctx:
    def __init__(self, product):
        self.product = product
        self.has_record = False


class ShapeTests(SummaryTestCase):
    def test_empty_ledger_prints_two_none_headers(self):
        text = self.render()
        self.assertEqual(text.split('\n'), [
            '', 'IN FLIGHT — none', '',
            'DONE since 2026-09-21T12:00:00Z — none (first tick on this clock)'])

    def test_in_flight_row_carries_the_title_and_the_age(self):
        self.launch('spec-f-0001')
        text = self.render()
        self.assertIn('IN FLIGHT — 1 session', text)
        self.assertIn('job', text.split('\n')[2])           # the column line follows the header
        row = [ln for ln in text.split('\n') if ln.startswith('spec-f-0001')][0]
        for cell in ('F-0001', 'spec', 'acct-a', 'opus', 'working', '12m'):
            self.assertIn(cell, row)
        self.assertTrue(row.endswith('  a feature'), row)   # what is last, never padded

    def test_dead_pid_is_named_in_flight(self):
        self.launch('spec-f-0001')
        text = self.render(alive=lambda pid: False)
        row = [ln for ln in text.split('\n') if ln.startswith('spec-f-0001')][0]
        self.assertIn('dead pid', row)

    def test_columns_pad_to_the_widest_cell(self):
        self.launch('spec-f-0001')
        self.launch('fix-b-0002-a-long-job-name', item='B-0002', kind='fix-bug',
                    started='2026-09-22T09:00:00Z')
        lines = [ln for ln in self.render().split('\n') if ln.startswith(('job', 'spec-', 'fix-'))]
        off = lines[0].index('item')                          # the header's column offset
        self.assertEqual([ln[off:off + 6] for ln in lines[1:]], ['B-0002', 'F-0001'])
        self.assertEqual(lines[1].split()[0], 'fix-b-0002-a-long-job-name')  # oldest first

    def test_unknown_item_and_missing_index_render_a_dash(self):
        self.launch('task-t-0009', item='T-0009', kind='task')
        row = [ln for ln in self.render().split('\n') if ln.startswith('task-t-0009')][0]
        self.assertTrue(row.endswith('  —'), row)
        os.remove(os.path.join(shadow.record_dir(self.product), 'index.json'))
        row = [ln for ln in self.render().split('\n') if ln.startswith('task-t-0009')][0]
        self.assertTrue(row.endswith('  —'), row)


class DoneTests(SummaryTestCase):
    def test_ended_in_the_window_is_done_with_result_and_took(self):
        self.launch('fix-b-0002', item='B-0002', kind='fix-bug', started='2026-09-22T11:00:00Z')
        pool_mod.update_session(self.product, 'fix-b-0002', ended='2026-09-22T11:41:00Z',
                                end_reason='finished', rc=0)
        pool_mod.update_session(self.product, 'fix-b-0002', harvested='d9a1df0abcdef')
        text = self.render()
        self.assertIn('IN FLIGHT — none', text)
        self.assertIn('DONE since 2026-09-21T12:00:00Z — 1 session', text)
        row = [ln for ln in text.split('\n') if ln.startswith('fix-b-0002')][0]
        self.assertIn('finished, landed d9a1df0', row)
        self.assertIn('  41m  ', row)
        self.assertTrue(row.endswith('  a bug'), row)

    def test_failed_and_dead_results_are_the_ledgers_words(self):
        self.launch('a', started='2026-09-22T11:00:00Z')
        self.launch('b', started='2026-09-22T11:00:00Z')
        pool_mod.update_session(self.product, 'a', ended='2026-09-22T11:30:00Z',
                                end_reason='failed: rate-limit')
        pool_mod.update_session(self.product, 'b', ended='2026-09-22T11:31:00Z', end_reason='dead pid')
        text = self.render()
        self.assertIn('failed: rate-limit', text)
        self.assertIn('dead pid', text)
        self.assertNotIn('landed', text)

    def test_window_is_since_the_previous_stamp_half_open(self):
        summary.write_stamp(self.product, 'all', '2026-09-22T11:30:00Z')
        for job, ended in (('old', '2026-09-22T11:30:00Z'), ('edge', '2026-09-22T11:30:01Z'),
                           ('new', '2026-09-22T11:59:00Z'), ('now', NOW)):
            self.launch(job, started='2026-09-22T11:00:00Z')
            pool_mod.update_session(self.product, job, ended=ended, end_reason='finished')
        text = self.render()
        self.assertIn('DONE since 2026-09-22T11:30:00Z — 3 sessions', text)
        self.assertNotIn('(first tick', text)
        jobs = [ln.split()[0] for ln in text.split('\n') if ln.startswith(('old', 'edge', 'new', 'now'))]
        self.assertEqual(jobs, ['edge', 'new', 'now'])         # oldest first, `old` excluded

    def test_a_relaunched_job_reports_its_ended_run_and_stays_in_flight(self):
        # B-0041: a launch line opens a NEW run; the ended run before it is still a session that
        # finished in this window. `pool.load_sessions` is `lifecycle.latest` and would drop it.
        self.launch('spec-f-0001', started='2026-09-22T11:00:00Z')
        pool_mod.update_session(self.product, 'spec-f-0001', ended='2026-09-22T11:20:00Z',
                                end_reason='failed: rate-limit')
        self.launch('spec-f-0001', started='2026-09-22T11:48:00Z')   # relaunched, still running
        text = self.render()
        self.assertIn('IN FLIGHT — 1 session', text)
        self.assertIn('DONE since 2026-09-21T12:00:00Z — 1 session', text)
        done = text.split('DONE')[1]
        self.assertIn('failed: rate-limit', done)
        self.assertIn('  20m  ', done)
        inflight = text.split('DONE')[0]
        self.assertIn('working', inflight)
        self.assertNotIn('failed', inflight)      # the ended run is not in flight

    def test_stamp_is_written_as_now_after_the_tables(self):
        self.render(chosen=['record'])
        self.assertEqual(summary.read_stamp(self.product, 'record'), NOW)
        self.assertIsNone(summary.read_stamp(self.product, 'all'))
        with open(summary.stamp_path(self.product, 'record')) as f:
            self.assertEqual(f.read(), NOW + '\n')

    def test_each_clock_has_its_own_window(self):
        self.launch('a', started='2026-09-22T11:00:00Z')
        pool_mod.update_session(self.product, 'a', ended='2026-09-22T11:50:00Z', end_reason='finished')
        self.assertIn('— 1 session', self.render(chosen=['record']).split('DONE')[1])
        self.assertIn('— 1 session', self.render(chosen=['health', 'wave']).split('DONE')[1])
        self.assertIn('— none', self.render(chosen=['record']).split('DONE')[1])


class ClockTests(unittest.TestCase):
    def test_clock_slug_matches_the_schedulers(self):
        from asf import scheduler
        self.assertEqual(summary.clock(None), 'all')
        self.assertEqual(summary.clock(['health', 'wave']), scheduler.steps_slug(['health', 'wave']))
        self.assertEqual(summary.clock(['daily']), 'daily')

    def test_age_buckets(self):
        self.assertEqual(summary.age('2026-09-22T11:59:30Z', NOW), '<1m')
        self.assertEqual(summary.age('2026-09-22T11:48:00Z', NOW), '12m')
        self.assertEqual(summary.age('2026-09-22T10:57:00Z', NOW), '1h03m')
        self.assertEqual(summary.age('2026-09-20T08:00:00Z', NOW), '2d04h')
        self.assertEqual(summary.age(None, NOW), '?')
        self.assertEqual(summary.age('yesterday', NOW), '?')


class FailureTests(SummaryTestCase):
    def test_a_render_failure_is_one_line_and_the_stamp_is_kept(self):
        summary.write_stamp(self.product, 'all', '2026-09-22T11:30:00Z')
        # NOT a directory in place of the ledger: `lifecycle.read_lines` returns [] for a path
        # that is not a file, so that renders two empty tables and is no failure at all.
        lines = []
        with mock.patch.object(summary, 'render', side_effect=ValueError('boom')):
            summary.run(_ctx(self.product), None, out=lines.append, now=NOW)
        self.assertEqual(len(lines), 1, lines)
        self.assertEqual(lines[0], 'tick: summary not rendered (boom)')
        self.assertEqual(summary.read_stamp(self.product, 'all'), '2026-09-22T11:30:00Z')

    def test_an_unreadable_ledger_is_survived_not_raised(self):
        with mock.patch.object(summary.lifecycle, 'runs', side_effect=OSError('nope')):
            lines = []
            summary.run(_ctx(self.product), None, out=lines.append, now=NOW)
        self.assertEqual(len(lines), 1, lines)
        self.assertTrue(lines[0].startswith('tick: summary not rendered ('), lines[0])

from asf.tick import summary   # joins the file's imports


class SummaryTests(TickTestCase):
    def test_every_tick_ends_with_the_two_tables(self):
        rc, out = self.run_tick(steps='record')
        self.assertEqual(rc, 0)
        lines = out.rstrip('\n').split('\n')
        self.assertEqual(lines[0], f'tick: state committed and pushed ({self.record_path()})')
        self.assertEqual(lines[1:3], ['', 'IN FLIGHT — none'])
        self.assertTrue(lines[-1].startswith('DONE since '), lines[-1])
        self.assertTrue(lines[-1].endswith('— none (first tick on this clock)'), lines[-1])
        self.assertTrue(os.path.exists(summary.stamp_path(env.load_product('sample'), 'record')))

    def test_a_tick_with_every_step_off_still_prints_the_tables(self):
        self.write_product('steps:\n  batch: off\n')
        rc, out = self.run_tick(steps='batch')
        self.assertEqual(rc, 0)
        self.assertEqual(out.split('\n')[0], 'tick: step batch off (another job runs it)')
        self.assertIn('\nIN FLIGHT — none\n', out)
        self.assertIn('\nDONE since ', out)

        self.assertNotIn('IN FLIGHT', out)
