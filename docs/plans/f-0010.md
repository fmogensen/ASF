# Plan F-0010 — the evidence pass reads a provider, not a vendor

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0010.md` (approved). Branch: `plan/F-0010`.

Seven Tasks, cut by the direction of the seam. Task 1 is the three interfaces and their
implementations in one new module, called by nothing (§2.1, §2.2). Task 2 threads them through
`asf/evidence/evidence.py` and changes no returned value (§2.3) — the whole of the existing
`tests/test_evidence.py` passing without a single `mock.patch.object` of a private name is the
proof. Task 3 adds `mergeable` (§2.4), Task 4 adds `opened`, the migration that seeds it and the
S1 clock that reads it (§2.5). Task 5 moves the other two deployed-sha readers onto the provider
(D16). Tasks 6 and 7 are the two fixtures: the sample's no-host shape, which regenerates offline,
and the redacted live snapshot, which does not (§2.6).

Tasks 2 and 5 write disjoint sets and both need only Task 1, so they run together. Tasks 3 and 4
both write `_ingest_fields` and `MACHINE_KEY_ORDER`, so they queue (PD11). Tasks 6 and 7 write
disjoint sets and both need Task 4's two keys landed, so they run together.

Wave order: **1 → (2 ‖ 5) → 3 → 4 → (6 ‖ 7)**.

§3.8's gate binds every Task, so every Gate and every Acceptance below carries it beside its own
fence.

**Steps**

1. `Sources = collections.namedtuple('Sources', 'git host deploy')`, then the three bases exactly as

3. `LocalGit(product, run=subprocess.run)`: `run(args, timeout=120, cwd=None)` is `sh`'s body in
   argv form (`asf/evidence/evidence.py:80`) — `cwd` defaults to `product.repo_dir`, `''` on any
   exception, never a raise; `cat_file(kind, requests)` is `_batch`'s position-keyed parser verbatim
   (`:92`–`:123`), its "the answers arrive in request order, and a missing object still costs one
   line" comment moved with it because it is the parser's whole correctness argument; `fetch()` is
   `git fetch --prune -q origin`. The one alternate root is `record_since`'s (`:806`, §2.3's last
   row) — hence `cwd=`.
4. `GitHubHost(product, run=subprocess.run)`: the only `gh` strings left in the evidence half —

   `api repos/<slug>/actions/runs/<id>/jobs?per_page=60`. `pr_list`'s `PR_TTL` cache file (`:203`,
   `_cache_file`) moves here whole, so a provider needing no cache carries none.
5. `NoHost()`: `prs`, `runs`, `run_jobs` answer `[]` and start no process — the `run` it is handed
   is never called (D4).
6. `WorkflowDeploy(product, host)`: `deployment(env)` is the newest `success` of
   `deploy_sha.<env>.workflow` through `host.runs(...)` — the one place two interfaces compose —
   with `dev` reading `ci.workflow`'s newest trunk run whose `ci.dev_job` succeeded through
   `host.run_jobs` (§3.7). An environment the product names no workflow for is `(None, None)`.
   `NoDeploy().deployment(...)` is `(None, None)` for every environment.
7. `Recorded(snapshot)` satisfies all three from a directory of `git.json` / `host.json` /
   `deploy.json`, keyed `<interface>.<method>` plus the arguments joined by `:` — never a command
   line (D7). `blob` answers are base64 because a blob is bytes. An unrecorded key raises
   `KeyError("evidence fixture: no answer for host.runs:ci.yml:main")` (D8).
8. `for_product(product, git=None, host=None, deploy=None)`: `LocalGit`; `NoHost` when
   `ci_provider(product) is None`, else `GitHubHost`; the deploy dispatch of PD14. Each argument
   overrides its default.
9. `_deploy_problems` gains the `provider` row (PD14): `github-deployments | fly | vercel | script |
   none`, anything else `must be one of …`.
10. The tests, per §3.1 and §3.7: every base method raises `NotImplementedError` or returns its
    documented default; `LocalGitTests` over a `tests/gitfixture.py` `Template` copy —
    `run(['rev-parse', 'origin/main'])` is the clone's trunk sha, `run(['no-such-subcommand'])` is
    `''` with no traceback, `cat_file('check', …)` answers in request order with `None` for a missing
    object, `cat_file('blob', …)` returns bytes and deduplicates nothing the caller did not;
    `RecordedTests` — a recorded key answers, an unrecorded one raises `KeyError` naming the call, a
    `blob` round-trips through base64; `ForProductTests` — `NoHost` for `ci: {provider: none}`,
    `GitHubHost` for `gh-actions`, `NoDeploy` for a product naming no deploy workflow, each of the
    three overrides honoured, and `NoHost` constructed with a `run` that raises still answering
    empty from every method; `DeployTests` — §3.7's four cases through a `Recorded` host.
