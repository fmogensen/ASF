# Plan F-0293 — the last four four-digit readers, the guard pattern outside the scan, and the ratchet that empties

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0293.md` (approved). Branch:
`plan/F-0293`.

**One Task.** The spec's whole change is five one-line expressions, four import lines, one scan
extension and four assertions. The cut is not a judgement call here — it is measured. The ratchet's
`test_the_allow_list_holds_only_live_sites` fails the moment a product site is swapped while its
`ALLOWED` entry stands, so every swap must delete its own entry in the same landing. Applied in
this worktree, the four swaps alone turn `tests/test_id_pattern.py` red and name all four entries
(**PD2**). A split therefore puts `tests/test_id_pattern.py` in every Task's `writes:` — the Tasks
queue one after another, buy no parallelism, and each intermediate landing is red. The spec says
the same thing in its own voice: *"Any one of them alone leaves `ALLOWED`'s product half
non-empty."*

Wave order: **Task 1** — one wave, one Task, `after: none`, starts at once.

Nothing in the spec's `## Out` is touched: the reshape half is not re-implemented (its test enters
Acceptance as a guard), the six test-only `ALLOWED` entries stay with their reasons, the ingest
reader grows digits and not vocabulary, the lane reading a date as an id is left downstream, and no
Story card is minted here — the record already holds all four (**PD1**).

The three things this plan adds to the spec are a test the spec's own acceptance requires but its
design section omits (**PD3**), a Gate wide enough to match what the pre-push gate actually selects
(**PD4**), and a measurement in place of the spec's by-construction safety claim (**PD5**). None of
them widens the card.

defect is that the minter has issued five-digit ids for a while and five readers were still built

five-digit one. The last edit is what keeps it fixed: the ratchet's allow list loses its product
half, and its scan learns to read the one guard that is not a Python file.

so what moves is which rows the existing writers produce. A lane head named `<prefix>/<id>` with
five digits whose card is done or removed lands in the branch census's `settled` class instead of

reach `due` under the `archive`/`legacy` rules it was always subject to. A removed Task whose
