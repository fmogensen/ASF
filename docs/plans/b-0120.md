# B-0120 — plan: I10 refused a write to features/F-0095.md

Item: B-0120 — Invariant I10 refused a write to features/F-0095.md. Epic: E-0001 — ASF 0.1 — a
working factory. Branch: `fix/B-0120`. No spec exists; the Acceptance below is the record.

## Cause

`check_i10` (`asf/invariants.py`) exists to stop a writer from landing a Feature that still has
open Tasks — a merged docs PR, closing no Task, must never land a Feature that has any. Its
exemption for an already-landed Feature was over-narrow: it skipped the refusal only when the
Feature was landed *and* had unclosed Tasks *before this writer ran*
(`_landed(before) and _unclosed_tasks(_before_record(ctx), fid)`). F-0095 landed with zero open
Tasks, so that second clause was false; when T-0085 was later minted under it and an unrelated
write touched `features/F-0095.md`, I10 refused it — even though this writer did not land the
Feature and has no landing to answer for.

## Task 1 — I10 does not re-litigate a Feature already landed

writes: `asf/invariants.py` `tests/test_record_stage.py`

- Step 1: in `asf/invariants.py:check_i10`, drop the `_unclosed_tasks(_before_record(ctx), fid)`
  clause from the exemption at line 280, so any Feature already landed before this writer ran is
  out of scope for I10, full stop — the check answers only for a landing this writer performs.
- Step 2: test, in `tests/test_record_stage.py`:
  `test_i10_a_task_opened_under_an_already_landed_feature_never_refuses_its_write` — a Feature
  already `Resolved`/landed, then in one writer a new open Task is minted under it and an
  unrelated byte is appended to the Feature's own card; asserts `findings == []` and the
  Feature's `state` stays `Resolved`.

## Accepted costs

Once landed, `check_i10` never re-examines a Feature's Tasks again, by design. If a Feature's
`state`/`stage` is ever hand-edited back to landed after being un-landed with Tasks still open,
I10 would not catch it on the next write — a deliberate trade (the check answers for a landing
this writer performs, not for state it inherits), not an oversight.
