# Plan F-0023 — The grill: a request is interrogated before it is spent on

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0023.md` (approved). Branch:
`plan/F-0023`.

Seven Tasks in three waves. The cut is by module, because the spec's design section is already
written per module and each module has its own test file — so a Task's gate is its own. The two
places the cut is *not* clean are named below and queued on purpose: `tests/test_idea.py` carries
five classes the spec assigns to three different Tasks, and `asf/conventions.py` carries three new
blocks written by three different Tasks.

This plan adds no scope the spec does not carry. Where the spec left a signature, a key name or a
call order unstated, the decision below names it and says it is a decision.

### Task 1: the tree grammar, the record-first filter, and `asf idea apply`
stories: S-14700, S-14701, S-14702

- `tests/test_cli.py` — `idea` in the subcommand list (`refine-check` is Task 7's half).
- `tests/test_conventions.py` — the `idea:` block and its default.

**Steps**

1. `tree.parse_tree(text) -> Tree(ask, nodes)`. Blocks are separated by a `---` line; the first
   block is `# The ask` and its paragraph. A node block's header is
   `^##\s+(Epic|Feature|Story)\s+(\w+)(?:\s+under\s+(\w+))?:\s*(.+)$`; `### Acceptance` and
   `### Assumptions` are its bullet sections, everything else its description.
   `Node(type, key, parent_key, title, description, acceptance, assumptions)`.
2. Every rule of the spec's table raises `TreeError` with the message that table gives, verbatim
   and naming the line: not a node header; a key already used (naming both lines); `under` naming
   no key defined above; an Epic with `under` or a Feature/Story without; a Feature whose parent is
   not an Epic or a Story whose parent is not a Feature; an Epic with fewer than two Feature
   children; a Story with no acceptance item; a `### Questions` section. The size sentences in the
   last three come from `asf.groom.shape.SIZE`, quoted — never restated.
3. `answered.answer_from_record(node, canonical, overlap=DEFAULT_ANSWER_OVERLAP) -> Answered | None`.
   An **open** item of the same type whose title tokens share ≥ `overlap` with the node's, by
   `asf.record.core`'s `jaccard` / `tokenize` — never a second tokeniser. `Answered.text` reads
   `F-0031 — Approvals as code (feature, Active)`. Highest overlap wins; ties by id.
4. `apply.apply_tree(root, tree, canonical, intake_dir, stamp) -> Applied(filed, answered,
   report_path)`. Nodes in tree order; `answer_from_record` first, and an answered node takes its
   whole subtree with it (recorded `answered by <id>`, filed for nobody).
5. Each filed node renders one intake file, `<intake_dir>/idea-<stamp>-<nn>-<type>-<slug>.md`,
   `<nn>` the node's 1-based index zero-padded to two, so a parent always sorts before its
   children. The body is the title as `# <title>`, then `parent:` (an `inbox:<file name>` when the
   parent is another node of this tree, the record id itself when it is a record id), then the
   description, then `## Assumptions` and `## Acceptance` as the node has them. An Epic node
   carries no `parent:` and a `## Features` section of its children's titles — the shape `derive`
   reads as `features-list` (`asf/groom/shape.py:84`).
6. Every node is rendered into memory before any file is written; one failure writes nothing
   (D11).
7. The report, `<intake_dir>/done/idea-<stamp>.md`: the ask verbatim, one line per node (`filed
   <file>` or `answered by <id> — <title>`), then the tree's text as it was parsed.
8. `<tree>.applied` is written last, JSON: `{"stamp", "filed": [...], "answered": [{"node", "id"}],
   "report"}`. Its existence refuses a second `apply` with exit 2 and `already applied` unless
   `--force` (D12).
9. `cmd_idea` for `apply`: `asf idea apply --tree FILE [--force] [--product P] [--json]`, resolving
   the record as `asf inbox` does (`resolve_record`, the `record:` line on stderr). Exit 0 when the
   tree is applied — including when every node was answered by the record, which is printed as the
   result it is; exit 2 for a missing tree, a tree that does not parse (the parser's own line on
   stderr), or an already-applied tree. The printed form is the spec's, byte for byte.
10. The convention and its yaml spelling, through the `_BLOCK_KEYS` table of PD3. No new
    `forbidden_patterns()` entry: a float default is not path-shaped.

7. `asf idea --enrich <ID>` refuses a tree of more than one node (exit 2, `--enrich takes one node`)
