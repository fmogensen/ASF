# Plan F-0153 — the sha diagnosis, the memo, the route and the row: four Tasks for a refused reword remembered by its tip

Epic: E-0003 — ASF 0.3 — autonomous delivery. Spec: `docs/specs/f-0153.md` (approved). Branch:
`plan/F-0153`.

The spec is unusually solid: `asf/` is **byte-identical** to the sha it was measured at, so every one
of its twelve preconditions holds at the line it cites, and P4 and P5 were re-measured here rather
than read (PD1). Four changes to one method, four Stories, four Tasks.

**Read PD2, PD3, PD4 and PD7 before writing a line of any Task.** They are the four places a coder
who copies the spec's fences verbatim ends with a red suite:

- **PD2** — A0 asserts *two* pushes and A1 asserts *one*, over the same scenario, in the same class.
  A0 is a pre-edit reproduction and **is not committed**. Its measurement is already taken, below.
- **PD3** — A3 does `assertIn(self.B, corr)`; `lifecycle.corrections` is keyed by **item**, never by
  branch. The fence fails as written.
- **PD4** — A4 calls `lane.reword_refused_line(self.product())` without patching `env.state_dir`, so
  it reads the operator's real state directory instead of the fixture's.
- **PD7** — one existing test the routing breaks, which the spec's §Out of scope never names:
  `NamingRewordNeverCostsASession.test_a_remote_refusal_defers_with_its_reason`.

Four Tasks, run **1 → 2 → 3 → 4**, one at a time. They serialise by construction: all four write
`asf/harvest/lane.py` and `tests/test_lane.py` (PD10), and the order is the dependency order —

```python
class ARefusedRewordIsRememberedByItsTip(LaneFixture):
    """F-0153: 144 log lines in a day — three heads, 48 each, two a tick. The repair kept no
    memory of a refusal, so every tick re-read, re-reworded, re-pushed and re-logged an
    unchanging tip; and a 'lease' diagnosed from the word non-fast-forward pushed a second time
    over a sha the pass had just proved unmoved."""

    B, AUTHOR = NamingRepair.B, NamingRepair.AUTHOR
    tip, push_commits, log, sessions = (NamingRepair.tip, NamingRepair.push_commits,
                                        NamingRepair.log, NamingRepair.sessions)

    def setUp(self):
        super().setUp()
        self.lines = []

    def refusing_remote(self, text):
        """A server-side hook in the bare origin. --no-verify cannot skip it, so this is the one
        way to stand in for a protected ref; it must go in after the setup pushes."""
        hook = os.path.join(self.origin, 'hooks', 'pre-receive')
        with open(hook, 'w', encoding='utf-8') as fh:
            fh.write('#!/bin/sh\necho "' + text + '" >&2\nexit 1\n')
        os.chmod(hook, 0o755)

    def counted_pass(self):
        """One lane pass; the pushes it made."""
        pushes, real = [], gitpush.push

        def counting(args, cwd, **kw):
            r = real(args, cwd, **kw)
            pushes.append(list(args))
            return r
        with mock.patch.object(gitpush, 'push', side_effect=counting):
            lane.lane_pass(self.product(), self.state_dir, out=self.lines.append)
        return pushes
```
