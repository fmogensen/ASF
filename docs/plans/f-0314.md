# Plan F-0314 — the leftover on the factory floor, closed against the trunk or handed to a person

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0314.md` (approved). Branch:
`plan/F-0314`.

Four Tasks. Task 1 is the card's own two acceptance lines: the predicate that asks the trunk
whether an item's work landed, the `closed` fact it decides on the run-held branch path, and the
archive the lane already performs — it closes `#766` and `#1082` on its own. Task 2 is the guard:
a `Closed` card the trunk cannot account for keeps its PR, and the fact is written once as
`decide` instead of printed every tick. Task 3 is the view, `CLOSED → DECIDE` in `pr_hygiene`,
which reads the lane registry and nothing else — the one Task with no file in common with the
others, so it runs beside Task 1. Task 4 is the pin: the `stray` line stops for the archived
branch, and the orphan path still closes what it closes today.

Wave order: **{1, 3} → 2 → 4**.

Tasks 1, 2 and 4 all write `tests/test_closed_item_prs.py`, and 1 and 2 also write
`asf/harvest/lane.py`, so the footprint gate queues them whatever their `after:` lines said
(`PD1`). The `after:` lines therefore cost nothing and buy the spec's own ordering. Task 3's
footprint is disjoint from all three.

## Decisions

Five of these rows correct the approved spec. Two of them are defects a coder following the
spec's fences literally would land:

* **`PD5`** — the spec's §2 fence reads `f['closed']` before anything assigns it on the path it
  is hoisted onto, and the landed assignment two blocks below would clobber the fact it sets.
  Written as the spec has it, the whole change is a no-op on `#766`.
* **`PD7`** — `trunk_landing` as the spec fences it **raises `FileNotFoundError`** on a repo path
  that is not there, which is the one case its own acceptance bullet says must never raise.

**`PD6`** names the second empty short-circuit the spec does not mention, and the hole it leaves
in §4. **`PD8`** drops `tests.test_workers` from every Gate: it is red at this base through no
fault of this card, and `PD20` carries the operator's ruling on it. **`PD12`** is the trap that
would rewrite this plan's own citations under its feet at the mint — silently, never as a
refusal — and it is followed throughout: measured here, `decisions.normalise` changes **not one
character** of this file. None of them widens the card: each is the spec's own **In** and **The
choices** carried out on the tree as it stands.
