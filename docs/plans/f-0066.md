# Plan F-0066 — a progress heartbeat: no progress for twenty minutes is a stall, not only silence

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0066.md` (approved). Branch: `plan/F-0066`.

Six Tasks, cut by the module that owns the new surface — which is how the spec's own §2 is
sectioned. Task 1 is the leaf `asf/progress.py` (§2.1–§2.3 and §2.5's `result_record`): the store,
the incremental scan, the worktree probe, the pure judge, the evidence line and the limit grammar.
Task 2 is `report.needs_input` (§2.6), which needs nothing from the leaf and starts beside it.
Task 3 is `stall.py`'s fifth rung and its `INPUT` walk (§2.5, first half) — the row the card's
first acceptance names, and the Task whose fixture is the card's second. Task 4 is the tick acting
on the two rows (§2.5, second half) plus `runtime.failure_reason`'s one clause. Task 5 is the
sampler process end to end (§2.4, §2.8): `watch`, `start`, the spawner's three lines and the
`asf workers progress` verb. Task 6 is the class in the `sessions` stream (§2.7) and the
`progress_min` key in the two product files (§1.1).

Tasks 1 and 2 write disjoint sets and start at once. Task 3 needs both landed — it calls
`progress.judge`/`progress.sample`/`progress.progress_min` and `report.needs_input`. Tasks 4, 5 and
6 all need Task 3's rows and write three disjoint sets, so they run together: Task 4 owns
`step_health.py` + `runtime.py` + `tests/test_tick_steps.py`, Task 5 owns `progress.py` +
`spawn.py` + `workers/__init__.py` + `tests/test_progress.py` + `tests/test_workers.py` +
`tests/test_path_resolution.py`, Task 6 owns `metrics.py` + the two yamls + `tests/test_metrics.py`.
Tasks 1, 3 and 5 all write `asf/progress.py` and `tests/test_progress.py`, and Tasks 3 and 5 both
write `tests/test_workers.py` — every one of those pairs is already ordered by `after:`, so the
intersection costs no wall clock.

Wave order: **1 ‖ 2 → 3 → 4 ‖ 5 ‖ 6**.

§3's rule that the whole suite stays green binds every Task, so every Gate below runs
`python3 tools/run_tests.py` beside its own fence, and every Task that adds a line to `asf/**`
runs the two whole-tree fences — the one-classifier AST fence and `check_conventions.sh` — because
`asf/progress.py` is a **new** module and a new module is inside both (P16, PD5).

### Task 1: `asf/progress.py` — the leaf: a sample, a store, a judge
stories: S-32200, S-32201
writes: asf/progress.py, tests/test_progress.py
after: none

§2.1, §2.2, §2.3 and §2.5's `result_record`: the whole measuring half of the Feature, with no
caller. `watch` and `start` are Task 5's — they are the sampler *process*, and every other function
here is pure or one file read away from pure, which is what makes T1 and T2 hermetic with no
fixture but a tmpdir and a git repo.

**Files**

- `asf/progress.py` — new. The §2.1 docstring verbatim; `DEFAULT_PROGRESS_MIN`, `SAMPLE_EVERY_S`,
  `WINDOW_MIN`, `RING`, `KEEP_SAMPLES`, `KEEP_DAYS`, `WATCH_MAX_H`, `NO_PROGRESS`; `MOVING`,
  `STUCK`, `UNKNOWN`, `BLOCKED`; `SIGNALS`; `Verdict`; `store_dir`, `store_path`, `read`, `append`,
  `sweep`; `scan`, `window_classes`, `probe`, `sample`; `signals`, `judge`, `evidence_line`;
  `minutes_of`, `progress_min`; `result_record`
- `tests/test_progress.py` — new. `ScanTests`, `ProbeTests`, `SampleTests`, `JudgeTests`,
  `WindowTests`, `LimitTests`, `StoreTests`, `ResultRecordTests`, `LeafImportTests`

**Steps**

1. The module docstring of §2.1, byte for byte, and the constants with §2.1's doc comments. The
   imports are the licence and nothing more: `collections`, `hashlib`, `json`, `os`,
   `subprocess`, `time` from the stdlib, and `from asf import env` (PD13).
2. The store. `store_dir(product)` is `os.path.join(env.state_dir(product), 'progress')`, made on
   demand — `env.state_dir` already makes its own (P22, `asf/env.py:807-811`). `store_path` joins
   the job name. `read` returns the samples oldest first, dropping a line that does not parse,
   `[]` for no file, never raising. `append` writes one JSON line and, past `2 * keep` lines,
   rewrites the file to its newest `keep` (a ring — D2: a week-long run cannot grow one).
   `sweep(product, days=KEEP_DAYS)` removes files whose mtime is older than `days` and returns the
   job names.
3. `scan(log, prev=None)` → `(bytes, calls, novel, classes, seen, ring, result)`, §2.2's contract
   exactly. Opens binary, seeks to `prev['bytes']` (0 with no `prev`), reads to EOF, and keeps only
   up to the last `\n` — the partial tail is left for the next pass, so `bytes` is the offset of
   that newline + 1 and a record is never parsed half-written. Per line: an `assistant` record's
   `message.content` blocks of `type == 'tool_use'` are one call each; the class is
   `str(block.get('name') or '?')[:40]`; `_digest(name, input)` is a short hex of
   `json.dumps((name, input), sort_keys=True, default=str)`; the call is novel unless its digest is
   already in `ring`, and the newest `RING` digests are kept either way. `classes` is the size of
   the union of `prev['seen']`-carried classes with this pass's; `seen` is this pass's own, in
   first-seen order. A `result` record sets `result` True. A `system`/`init` record resets every
   counter, the ring and the seen set (B-0028: the log now holds a second run). Any `OSError` /
   `ValueError` returns `prev`'s values unchanged.
4. `window_classes(samples, now, minutes=WINDOW_MIN)`: the union of `seen` over the samples whose
   `at` is at or after `now - minutes`, in first-seen order.
5. `probe(worktree)` → `(commit, files, digest)`: `git rev-parse --short HEAD` and
   `git status --porcelain`, each `subprocess.run(..., cwd=worktree, capture_output=True,
   text=True)`; `files` is the non-empty line count and `digest` the first 8 hex of a hash of the
   porcelain text. `('', 0, '')` on a non-zero return code, a missing directory or an `OSError` —
   a probe that cannot read says nothing (§2.2).
6. `sample(product, run, now=None, prev=None)`: `prev` defaults to the store's newest; `scan` over
   `run['log']` from it; `probe` over `run['worktree']`; the flat dict of §2.1's shape with `at` as
   `%Y-%m-%dT%H:%M:%SZ` of `now`; `last_call_at` is this sample's `at` when `calls` grew, else
   `prev`'s `last_call_at` (so "the last tool call time" survives a restart of the sampler);
   `append`ed and returned.
7. `signals(sample)` and `judge(samples, now, limit)` — §2.3's contract, pure, no clock, no git, no
   file. `UNKNOWN` on fewer than two samples, on a newest sample older than `limit` minutes, and
   when no sample is at or before `now - limit` (D6). Otherwise the newest's `signals` against
   those of the newest sample at or before `now - limit`: equal → `STUCK`, different → `MOVING`.
   `minutes` is the span between the two samples compared, `evidence` the string of step 8.
8. `evidence_line(samples, verdict, now)` — the commit or `no commit`, the changed-file count, the
   `WINDOW_MIN` classes with their count, whether `novel` moved, and how long ago the last tool
   call was, rendered as §2.3's one line and never wrapped here (PD14).
9. `minutes_of(value, default)`: the grammar `silent_minutes` holds today, lifted whole — an
   `int`/`float` is minutes, `^\s*(\d+(?:\.\d+)?)\s*([smhd]?)\s*$` is converted by
   `{'s': 1/60, 'm': 1, '': 1, 'h': 60, 'd': 1440}`, anything else is `default`. `bool` is not a
   number here. `progress_min(product)` is `minutes_of((product.stage_limits or {}).get(
   'progress_min', DEFAULT_PROGRESS_MIN), DEFAULT_PROGRESS_MIN)`.
10. `result_record(kind, minutes, evidence, at)` exactly as §2.5 types it — the twin of
    `tokens.cap_result` (`asf/tokens.py:203-216`): `is_error`, `subtype: error`, the human text, and
    the structured `asf.no_progress` object. No `usage`, no `duration_ms`, no `total_cost_usd`:
    nothing measured either.
11. `tests/test_progress.py`. `ScanTests`: one call per `tool_use` block; the class named; a repeat
    inside `RING` not novel and a call whose `input` changed novel; a `system`/`init` boundary
    resetting everything; a file ending mid-line stopping at the last complete one; and the
    incremental property — three appends scanned one at a time, carrying `prev` forward, equal to
    one scan of the whole file. `ProbeTests`: the short head, the changed-file count, a digest that
    moves when a file changes and not when the clock does, and `('', 0, '')` with no raise for a
    worktree that is gone. `SampleTests`: one line appended, and `last_call_at` holding its
    previous value across a sample in which `calls` did not grow. `JudgeTests`: two samples twenty
    minutes apart with identical signals → `stuck`, `minutes == 20`; each one of the four differing
    → `moving`; one sample, a nineteen-minute span, and a newest sample twenty-one minutes old →
    `unknown`; and a sample whose probe failed (`commit == ''`) never turning a `moving` run
    `stuck` on its own. `WindowTests`: the union over the last ten minutes, first-seen order,
    samples outside dropped. `LimitTests`: `20`, `'20m'`, `'90s'`, `'1h'`, `'1d'` and nonsense;
    `progress_min` defaulting to 20 and `0` read as 0. `StoreTests`: the ring at `2 * keep`, a
    malformed line dropped by `read`, `[]` for no file, and `sweep` removing only what is older
    than `days`. `ResultRecordTests`: the record's shape and that `asf.no_progress` is a dict.
    `LeafImportTests`: PD13's assertion — no `asf.` import but `asf.env`.
