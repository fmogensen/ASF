# Plan F-0090 — adjudication is the last resort: the cheap causes are ruled out first

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0090.md` (approved). Branch: `plan/F-0090`.

Seven Tasks, cut by module, because the spec's §2 is already cut that way and each module has its
own gate. Task 1 is the triage itself (`asf/feeder/triage.py` plus the three producers in
`rows.py`) — pure, caller-fed, and the only place the *order* of the three causes is decided.
Task 2 is the round history and the files on a correction (`lifecycle`). Task 3 is the brief's two
halves: the digest that makes "stale" a fact, and the three typed ruling fields the tail asks for
and `report` reads back. Task 4 is the weekly measure. Task 5 is the gate that names its files and
the foreign red that costs no round (`harvest`, on Task 2's `hold(..., files=…)`). Task 6 is the
tick — the facts it supplies, the digest it writes at launch, and the two lines it prints. Task 7
is the ruling landing on the card through `setfield.apply`.

Tasks 1–4 write disjoint files and need nothing from each other; they are wave 1. Task 5 needs
Task 2's `hold` signature and Task 6 needs Tasks 1, 2 and 3 (the Row fields, `round_log`,
`card_digest`); they are wave 2 and write disjoint files. Task 7 needs Task 3's `ruling_fields`
and shares `tests/test_tick_steps.py` with Task 6, so it is last.

Wave order: **(1, 2, 3, 4) → (5, 6) → 7**.

### Task 1: triage — the three cheap causes, in the card's order, and the rows they produce
stories: S-15600, S-15601, S-15602, S-15604
writes: asf/feeder/triage.py, asf/feeder/rows.py, tests/test_feeder.py

§2.1 and §2.2: one pure module with one entry point, and the three producers of an adjudicate row
asking it before they produce one. A count is not a disagreement — this Task is where that stops
being a sentence.

**Files**

- `asf/feeder/triage.py` — new. `Cause`, `HOLD`/`RERUN`, `PREDECESSOR`/`STALE_BRIEF`/`FOREIGN_GATE`,
  `_predecessor`, `_stale_brief`, `_foreign_gate`, and `cause(item, items, facts)` as their ordered
  `or` chain. Imports `asf.feeder.footprint` and nothing else from the package.
- `asf/feeder/rows.py` — `Row` gains `cause`, `between`, `common` (all defaulted); the three
  adjudicate producers (`bug_rows:209-215`, `correction_rows:240-245`, `feature_rows:298-304`) each
  call `triage.cause` and branch three ways; `hold_unlanded` passes a row that already carries a
  `cause` through untouched (P4); `candidates()` and `plan_rows()` take `stale_briefs=None,
  rounds=None` and default both to `{}`.
- `tests/test_feeder.py` — `TriagePredecessorTests`, `TriageStaleBriefTests`,
  `TriageForeignGateTests`, `TriageOrderTests`.

**Steps**

1. `triage.Cause = collections.namedtuple('Cause', 'name action reason brief_kind waits_on')`, with
   the two actions and the three names as module constants, exactly as §2.1 fences them.
2. `_predecessor(item, items)`: the ids of `item['after']` whose card is not `Resolved`/`Closed`,
   then any id in `item['blocked_by_open']` (P5). Non-empty →
   `Cause(PREDECESSOR, HOLD, 'after: <id> has not landed — waiting, not disputed', '', '<id>')`.
   An id the index does not hold counts as unlanded — a predecessor nobody can see has certainly
   not landed.
3. `_stale_brief(item, facts)`: `facts['stale_briefs'].get(item['id'])` →
   `Cause(STALE_BRIEF, RERUN, "the brief predates the card's last change — rebuilt, not disputed",
   <that kind>, '')`. The kind is the caller's; triage never guesses one.
4. `_foreign_gate(item, facts)`: the item's newest correction, and only when `kind == 'gate'`,
   `item['writes']` is non-empty **and** `correction['files']` is non-empty and
   `footprint.overlaps(writes, files)` is `None` →
   `Cause(FOREIGN_GATE, HOLD, 'gate red outside writes: <first file> — not this item\'s', '', 'gate')`.
   Either fact missing: no cause (D9).
5. `cause(item, items, facts)` returns the first of the three that fires, `None` otherwise, and
   computes nothing for a cause it never reaches (D2). `facts` is read with `.get`, so a caller
   that passes `{}` gets `None` and the rows it gets today.
6. `Row` gains `cause: str = ''`, `between: tuple = ()`, `common: str = ''`. Every existing
   construction is positional-safe because all three are defaulted and appended after
   `open_questions`.
7. Each of the three producers builds its `between` pair first (from `facts['rounds']` for the
   branch and Bug producers, from `conventions.review_path(slug, n-1)` / `(slug, n)` for the review
   producer, per §2.2's table) and `common` as the first path in `round_a.files ∩ round_b.files`,
   then wraps its row in the three-way branch §2.2 fences: `None` → the adjudicate row, now
   carrying `between`, `common` and the `<a> ↔ <b>: the same file, two rounds — adjudicate` reason;
   `HOLD` → a row with `action=f'WAITS ON {c.waits_on}'`, `brief_kind=''`, `cause=c.name`,
   `reason=c.reason`, `waits_on=c.waits_on`, which `Row.launches` already makes non-launching;
   `RERUN` → `action=LAUNCH`, `brief_kind=c.brief_kind`, `cause=c.name`, `reason=c.reason`. The row
   is always emitted: a held item that produced no row would be invisible.
8. `hold_unlanded`: `if pending and not r.cause and …` — a row triage already spoke for keeps the
   reason triage gave it (P4). B-0080's `NoRowLaunchesBehindAnUnlandedPredecessor` stays green
   unchanged: the action and `waits_on` it asserts are the same strings.
9. `candidates(index, product, inflight, attempts=None, corrections=None, busy=None,
   groom_state=None, stale_briefs=None, rounds=None)` builds `facts = {'corrections': corrections
   or {}, 'stale_briefs': stale_briefs or {}, 'rounds': rounds or {}}` once and hands it to every
   producer; `plan_rows` passes both through. No other signature moves.
10. Tests, in the module's existing idiom (a dict index, `product()`, no filesystem): the four
    classes of T1–T4, including the negative halves — `T-0001` `Closed` yields the adjudicate row;
    an overlapping file yields the adjudicate row; `writes: []` or `files: []` yields the
    adjudicate row; and, called with neither `stale_briefs` nor `rounds`, `candidates()` returns
    what it returns today for `RowsTest`, `CorrectionRowTest` and `AttemptOrderTest`.

### Task 5: the gate names its files, and a red outside the footprint costs no round
stories: S-15603
writes: asf/harvest/harvest.py, tests/test_harvest.py

§2.4, on Task 2's `hold(..., files=…)`. B-0082 put the "not this item's fault" test at the source
for a timed-out gate; this is the same shape for a red that names files the item never touched.

**Files**

- `asf/harvest/harvest.py` — `PATH_RE`, `DOTTED_RE`, `gate_files(text, cap=20)`; `product_gate` and
  `run_gate` return `(ok, line, files)`; `hold_with_correction` takes `files=()` and
  `item_writes=()` and returns `'foreign'` per D8; `land_ff` and `land_combined` pass both through.
- `tests/test_harvest.py` — `GateFilesTests`, `ForeignRedTests`.

**Steps**

1. `gate_files(text, cap=20)`: every repo-relative path-like token matched by `PATH_RE`
   (`.py|.md|.ts|.tsx|.js|.jsx|.sh|.ya?ml|.json|.toml`), plus each `DOTTED_RE` unittest id mapped
   to its module file (`tests.test_feeder.X` → `tests/test_feeder.py`), de-duplicated, first-seen
   order, capped at 20. No failure classification and no owner guessing — the In/Out table.
2. `product_gate(tmp, conv, asf_repo)` → `(ok, line, files)`: on red, `line` is
   `first_failing_line(out + '\n' + err)` as today and `files` is `gate_files` of that same whole
   output (P8). On a timeout, the timed-out line and `[]`. On green, `(True, None, [])`.
