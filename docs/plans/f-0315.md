# Plan F-0315 — the hold is a shared file: one intersection helper, then the rule, the line and the skip

Epic: E-0003 — ASF 0.3 — autonomous delivery. Spec: `docs/specs/f-0315.md` (approved). Branch:
`plan/F-0315`.

Two Tasks, cut along the spec's own file boundaries. Task 1 is the **witness**:
`footprint.first_intersection`, the narrow intersection test that returns the glob pair rather than
a boolean, and `invariants.unordered_overlaps` refactored onto it so the record has one owner for
"these two footprints share this path" (S-82204). Task 2 is the **pass**: the rule that replaces
`extra = [t for t in started …]`, the line that names each edge and the path behind it, the `skip`
thread that keeps an undelivered Task out of every delivery, and `undeliver.undelivered_from` —
the read-back of the one `## History` line that records the ruling (S-82205, S-82206, S-82207,
S-82208).

Wave order: **1 → 2**.

The two are serial and there is no parallelism to buy. Their `writes:` are disjoint — Task 1 writes
`asf/feeder/footprint.py`, `asf/invariants.py`, `tests/test_shared_paths.py` and
`tests/test_invariants.py`; Task 2 writes `asf/record/slice.py`, `asf/record/undeliver.py`,
`tests/test_feature_delivery.py` and `tests/test_retire.py` — so nothing queues them. What orders
them is the real edge: Task 2's rule calls `first_intersection`, so Task 2 declares
`after: Task 1` and waits for it to land (**PD9**).

The cut is **not** one Task per Story, and that is the one place this plan departs from the
approved spec's own text (**PD1**): the adjudication of 2026-10-08 19:30 on this card binds the
plan to two Tasks along the file boundaries instead, because the spec's design §2 and §3 are one
interleaved edit to the `deliveries` function that four Story-shaped Tasks could only make by
fighting over the same lines (**PD2**).

### Task 1: the witness — `footprint.first_intersection`, and the overlap invariant refactored onto it
stories: S-82204
writes: asf/feeder/footprint.py, asf/invariants.py, tests/test_shared_paths.py, tests/test_invariants.py
after: none

The spec's design §1 and its In rows 2 and 3 (D2, D3; P7). One new pure function beside
`footprint.overlaps`' wider one, returning the **glob pair** rather than a boolean because §3's
line has to name the path that caused the wait — and `invariants.unordered_overlaps` loses its
inlined double loop to it, so the record has one owner for "these two footprints share this path".
No caller outside the invariant changes in this Task; Task 2 is the second caller.

**Files**

- `asf/feeder/footprint.py` — `first_intersection(writes_a, writes_b, shared=())` added beside
  `overlaps` (`:105`), with the spec's docstring: the first `(glob_a, glob_b)` pair naming a common
  path by `core.writes_intersect` (already imported at `:16`), or `None`; a glob `is_shared(…,
  shared)` covers (`:94`) skipped on **either** side; the narrow test, and the docstring says why it
  is narrow where `overlaps` is wide — `globs_overlap` errs on waiting because "a false overlap
  costs one tick" (`:64-65`), and an `after:` edge costs a wave (F-0315 D2).
- `asf/invariants.py` — `unordered_overlaps`' inlined double loop (`:332-345`, the `glob = None`
  walk with its two `break`s) replaced by one `first_intersection(wa, wb, shared)` call. The
  function-local `from asf.feeder import footprint` at `:325` already brings it in; the
  `from asf.record.core import writes_intersect` at `:326` becomes unused and goes with the loop.
  Nothing else in the function moves: the Active-pair filter (`:328-330`), `ordered(edges, a, b)`,
  `has_pushed_work`'s owner tie-break and the `(owner, held, glob_owner, glob_held)` row shape are
  untouched, so `check_i3`'s rows are unchanged.
- `tests/test_shared_paths.py` — `FirstIntersectionTests` added beside `SharedGlobsTests` (`:17`),
  `IsSharedTests` (`:41`) and `RecordCheckTests` (`:70`). The module already imports
  `asf.feeder.footprint` (`:14`).
- `tests/test_invariants.py` — no new case is required: S-82204's last acceptance line is that this
  module passes **whole** with the invariant calling the helper, and `OrderedOverlapTests` (`:503`)
  and `OverlapYieldsToProgressTests` (`:618`) already cover the witness and the tie-break. The path
  is declared because a refactor that moves the witness may need one of its assertions re-anchored;
  if none does, the file is left alone and that is the result.

**Steps**

1. Write `first_intersection(writes_a, writes_b, shared=())`: walk `writes_a or []`, `continue` on
   `shared and is_shared(a, shared)`; inside, walk `writes_b or []` with the same skip; return
   `(a, b)` on the first `writes_intersect(a, b)`; `return None` at the end. The shape of
   `overlaps` (`:105-117`) with its one predicate swapped — `writes_intersect` for `globs_overlap`.
   An empty or absent footprint on either side falls out of the loop as `None` with no special case,
   which is S-82204's fourth acceptance line.
2. Write `FirstIntersectionTests`, one case per acceptance line: `(['a.py'], ['b.py'])` is `None`;
   `(['asf/record/slice.py'], ['asf/record/*.py'])` returns that pair **in that order**; a list
   whose second glob also matches returns the first pair and not the later one; `([], ['a.py'])`,
   `(None, ['a.py'])` and both sides empty are `None`; `shared=('uv.lock',)` skips the lockfile on
   either side, so two footprints whose only common glob is `uv.lock` are `None`; and
   `(['asf/record/'], ['asf/record/slice.py'])` is `None` where `footprint.globs_overlap` on the
   same pair is `True` — the one divergence D2 accepts, asserted against both functions in one case
   so a later widening of either cannot pass unnoticed. P7's table was re-run in this session and
   every row of it holds, so these are measurements, not guesses.
3. Replace the loop in `unordered_overlaps` with `glob = footprint.first_intersection(wa, wb,
   shared)` and drop the now-unused `writes_intersect` import from the function body. Keep the
   `if glob and not ordered(edges, a, b):` guard and everything after it exactly as it is.
4. Run `tests.test_invariants` whole and leave all 66 green. The helper applies the same test with
   the same skips and returns the same first pair, so `ordered` and every returned row are
   unchanged by construction; the module run whole is what says so.
