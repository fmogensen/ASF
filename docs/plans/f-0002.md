# F-0002 — plan: the card-evaluation pass for multi-product wording

Feature: F-0002 — P0b — the card-evaluation pass for multi-product wording. Epic: E-0001 — ASF 0.1
— a working factory. Branch: `plan/F-0002`.

Binding spec: `docs/specs/f-0002.md`. This plan adds no scope that the spec doesn't already carry.
Where the spec needed a narrower reading, a correction, or a detail it left out to be buildable,
the decisions below say so.

This Feature writes nothing in this repository. It is a content pass over the ASF **record** — the
separate repository `product:backlog_dir` names. The only file this plan's own session creates is
this plan.

## Decisions

- **P1 — The pass is one Task, and cannot be split.** Every acceptance block but T1 and T7 reads
  `groom/f-0002-card-evaluation.md` and asserts that its note set is *exactly* the 42 migrated ids
  (T2's `set(ids) != want`, and T3/T5 which iterate those notes). A Task boundary anywhere inside
  the pass leaves a partial notes file, so the first Task's own gate fails on the set it has not
  written yet. Splitting the cards into batches also gives every batch the same `record:features/**`
  footprint, so the feeder queues them one after another anyway (`asf/feeder/footprint.py`,
  `globs_overlap`) — all of the cost, none of the parallelism. Spec D10 ("one worker session")
  and the Task size class ("one session in one worktree with a writes: footprint",
  `asf/groom/shape.py` `SIZE['task']`) both land in the same place: one Task.
- **P2 — The `writes:` footprint is in the record, not in this repository, and says so.** Spec P3
  requires the plan to declare it. The globs carry a `record:` prefix so they can never be read as
  a path here and can never collide with another Task's `asf/…` or `docs/…`. The footprint gate is
  pure string matching over glob lists (`asf/feeder/footprint.py` — "no filesystem"), and
  `asf check`'s overlap test is the same one, so the prefix is inert to both. Nothing else in the
  record is in the footprint: the pass writes `features/`, `bugs/`, the one notes file and
  `index.json`, and nothing else.
- **P3 — `config:worker_pool.quota_guard.max_5h` and `…max_7d` are no longer existing keys. The
  pass must not name them bare.** Spec §2.3 lists them in its "Existing keys" column. T3 builds its
  `known` set from `docs/config.example.yaml`, and F-0082 moved that block out of the example file
  into a top-level `quota_guards:`. Checked on 2026-09-23: those two are the only keys of §2.3
  absent from T3's `known` set (the other 27 are all present). F-0082's plan D10 decided not to
  amend this spec line, on the ground that the old form is still *read* — true, and beside the
  point for T3, which judges by the example file, not by the reader. So: a card about a quota band
  names `config:quota_guards.stop` or `config:quota_guards.cooldown`. This corrects one stale cell
  of §2.3; it widens nothing.
- **P4 — Keys are checked against T3's `known` set before they are written, not after.** §2.3's
  key column is guidance; T3's `known` is the judge, and it is computable in ten lines, so step 0
  of the pass computes and prints it. Two traps it makes visible: `env.load_file` does not descend
  into an inline flow mapping, so `config:quota_guards.stop` is known while
  `config:quota_guards.stop.five_h` is **not**; and a key that is real in `asf/env.py` but absent
  from the example yamls is, to T3, not known. Any key not in the printed set is written with
  `(new key)` and listed under `## New keys`.
- **P5 — A re-word must never add or remove a mention of another card's id.** `asf index`
  (step 4 of §2.6) rewrites any card whose derived body changed, and backlinks are derived from a
  *mention of the id in another card's text* (`asf/record/core.py` `compute_derived` →
  `mention_re(iid)` over every other card). So a re-word of card A that newly names `F-00NN` makes
  `asf index` rewrite F-00NN's `## Backlinks`. If F-00NN is `product-bound`, T5 fails outright —
  its product-bound branch asserts the changed-line list is **empty**, and unlike the `clean`
  branch it allows no `## Backlinks` or `- [` line. Re-wording is prose about config keys, so this
  costs the pass nothing to obey; it just has to be obeyed deliberately. The notes file is safe by
  construction: `groom/` is not an item folder (`ITEM_FOLDERS` is epics, features, stories, tasks,
  bugs, decisions, rules), so its 42 id mentions create no backlinks at all.
- **P6 — The gate runs against the checkout `product:backlog_dir` names, which is not where the
  pass writes.** Every block resolves `rec = env.load_product(...).backlog_dir` — the operator's
  own record checkout. The factory's tick works in a clone at `~/.ASF/state/<product>/record/` and
  "never touches the operator's own backlog checkout" (`asf/tick/shadow.py`). A session working in
  a clone or worktree therefore cannot make T1–T6 read its own edits. This is not a defect to fix
  here: spec P5/D8 already put the acceptance on the operator's machine rather than in CI. The
  step the spec leaves out is the pull. So the pass commits and pushes as §2.6 step 6 says, and the
  seven blocks are run from this repository's root **once that checkout holds the pass's commit** —
  which needs the operator, and is raised as a `NEEDS OPERATOR` line by Task 1.
- **P7 — The three verdicts are decided per card by the rubric, not by the tripwire.** T4's regex
  is a floor, not the bar: checked on 2026-09-23 against the live 42, it hits exactly two cards,
  F-0038 and F-0059, both on "the product repository" — the two the spec predicted, and no others.
  Passing T4 is therefore nearly free and proves almost nothing. The verdict that matters comes
  from reading each card against §2.2 and §2.3. A card whose text survives T4 untouched is still
  `reworded` if it assumes one product, one CI provider, one runner pool or one path in words the
  regex does not carry.
- **P8 — `product-bound` is the narrow verdict.** D3 leaves such a card byte-for-byte untouched and
  spends an operator question on it. A card that merely *mentions* one product's arrangement is
  `reworded`; `product-bound` is for a card whose intent cannot survive being made
  product-agnostic. The pass prefers `reworded`, then `clean`, and reaches for `product-bound` last.
- **P9 — The selector, not §2.1's list, chooses the set — and today they agree.** Re-checked on
  2026-09-23 against the live record: the selector yields 42 ids, exactly F-0034–F-0070 plus
  B-0008–B-0012, with nothing missing and nothing extra. T1 pins the list, so a later divergence is
  visible rather than silent. (F-0059 carries `removed: groom 2026-09-23` in its frontmatter and is
  still selected — the selector reads the migration line, not the state. It is evaluated like the
  rest, and D7 forbids touching its frontmatter either way.)
- **P10 — No card ids in this plan.** The record mints Task ids from the `### Task N:` headings
  (`asf/record/plan_tasks.py`, `mint_id`); a session never mints one. The Story ids are the spec's
  own, from §"Stories".

## Tasks

### Task 1: The 42-card evaluation pass, its verdicts, its keys and its notes file
stories: S-5800, S-5801, S-5802, S-5803, S-5804, S-5805
writes: record:features/**, record:bugs/**, record:groom/f-0002-card-evaluation.md, record:index.json

**Files**

All paths are in the record (`product:backlog_dir`), not in this repository.

- `record:features/**` — the 37 migrated Features F-0034–F-0070: `## Description`,
  `## Acceptance`, `## Non-goals` and one appended `## History` line, within D7's limits. Also
  `features/F-0002.md`, for its own pass-run History line (§2.6 step 5).
- `record:bugs/**` — the 5 migrated Bugs B-0008–B-0012, on the same terms.
- `record:groom/f-0002-card-evaluation.md` — new. The header, the 42 note lines, `## New keys`.
- `record:index.json` — regenerated by `asf index`, not hand-edited.

Nothing under `asf/`, `tools/`, `plugin/`, `tests/`, `docs/` in this repository is touched — spec
§"Out" and the opening of §1.

**Steps**

1. **Record the base.** `git -C <record> rev-parse HEAD` → this is the notes file's `base:`. Write
   it down before the first edit; T5 diffs every `clean` and `product-bound` card against it, so a
   `base:` taken after an edit silently hides that edit.
2. **Compute T3's `known` set and print it** (P4). The ten lines are T3's own: `paths()` over
   `env.load_file('docs/products.example.yaml')` and `docs/config.example.yaml`, plus
   `product:conventions.<field>` for every field of `conventions.Conventions`, plus
   `product:product`. On 2026-09-23 it holds 132 keys. Every key the pass later writes is looked up
   here first; anything absent gets `(new key)`. Remember `config:quota_guards.stop` is in it and
   `config:quota_guards.stop.five_h` is not (P4), and that
   `config:worker_pool.quota_guard.max_5h`/`…max_7d` are not (P3).
3. **Run the selector** — an item under `features/` or `bugs/` whose text contains
   `migrated from the first product's backlog`. Expect 42. If the count differs from 42, do not
   improvise: evaluate what the selector yields, put the real count in `evaluated:`, and say so in
   the report, because T1 will then fail and the difference is the point.
4. **Evaluate each item, in id order** (§2.6 step 2). For each:
   - read `## Description`, `## Acceptance`, `## Non-goals` against the isolation table §2.2 and
     the five assumptions §2.3;
   - choose one verdict — `reworded`, `clean` or `product-bound` — preferring them in that order
     (P8), and judging by the rubric rather than by T4's regex (P7);
   - for `reworded`: change only the wording that assumes one of the five. Intent, acceptance
     meaning, rank and scope stay. Every key named in the note appears in the card's own body in
     backticks — T3 checks exactly this (`if key not in body`). Add **no** mention of another
     card's id, and remove none (P5). Never touch the frontmatter (D7);
   - append the History line, `- <date> F-0002: <verdict> — <keys or reason>`, to `reworded` and
     `clean` cards only. A `product-bound` card gets none and is left byte-for-byte untouched (D3);
   - write the note line into the notes file, in the §2.5 grammar;
   - print `F-0002: <ID> <verdict>` — the per-item progress line, and the session's heartbeat.
5. **Write `## New keys`** — one `` - `<key>` — <ID>[, <ID>…] — <what it holds> `` line per key any
   note marked `(new key)`, each exactly once (T3 rejects a duplicate). No yaml and no code in this
   repository is changed to add them; they are input for F-0004, F-0059 and F-0007 (spec §"Out").
6. **Complete the header** — `base:` from step 1, `evaluated: <n> items` with the selector's real
   count, and the `rubric:` line.
7. **Re-read the two cards T4 names** (P7): F-0038 ("Moving the scripts out of the product
   repository", in `## Non-goals`) and F-0059 ("the tooling moves into its own repository … out of
   the product repository", in `## Description`). Both are `reworded` unless the reading says
   otherwise; if either is judged `product-bound`, T4 passes by exclusion and the note carries the
   answer slot instead.
8. **Regenerate and validate** — `asf index`, then `asf check`, from the record. Both exit 0. If
   `asf index` rewrites a `product-bound` card, stop: that is P5's failure, and the mention that
   caused it has to come back out before the commit.
9. **Append F-0002's own History line** (§2.6 step 5), with the three counts and the notes path.
10. **Commit and push** in the record: `git commit -s`, subject
    `F-0002: card-evaluation pass — <r>/<c>/<p>`, on the job's branch.
11. **Raise the operator lines.** One per `product-bound` card, in §2.6 step 6's words. Plus, per
    P6, the one the spec leaves out:
    `NEEDS OPERATOR: the acceptance blocks read product:backlog_dir — pull the pass's commit into that checkout before running them — git -C <backlog_dir> pull`

**Gate**

```sh
# in the record the pass edited:
python3 -m asf.cli index
python3 -m asf.cli check

# from the root of this repository, once product:backlog_dir holds the pass's commit (P6):
bash tools/check_generic.sh
python3 -m unittest discover -s tests -t . 2>&1 | grep -E '^(Ran|OK|FAILED)'
```

Then each of the seven Acceptance blocks below, T1 through T7, in order, run from the root of this
repository. Each prints `ok` and exits non-zero on failure.

The `unittest discover` line is a regression guard only: this Task changes no file in this
repository, so the suite must read exactly as it did before the pass.

**Acceptance** (from the spec, byte for byte)

All blocks run from the root of this repository on the operator's machine (P5). Each block
resolves the record itself, exits non-zero on failure and prints `ok` on success. Set
`ASF_PRODUCT` if the ASF product's config file is not named `asf.yaml`.

**T1 — the evaluated set is the migrated set.**

```bash
python3 - <<'EOF'
import os, re, sys
from asf import env
rec = env.load_product(os.environ.get('ASF_PRODUCT', 'asf')).backlog_dir
want = {f'F-{n:04d}' for n in range(34, 71)} | {f'B-{n:04d}' for n in range(8, 13)}
got = set()
for kind in ('features', 'bugs'):
    for f in os.listdir(os.path.join(rec, kind)):
        if f.endswith('.md') and "migrated from the first product's backlog" in open(os.path.join(rec, kind, f)).read():
            got.add(f[:-3])
if got != want:
    sys.exit(f'set differs: missing {sorted(want - got)}, extra {sorted(got - want)}')
print('ok')
EOF
```

**T2 — one note per card, each with a verdict, and the header is complete.**

```bash
python3 - <<'EOF'
import os, re, sys
from asf import env
rec = env.load_product(os.environ.get('ASF_PRODUCT', 'asf')).backlog_dir
text = open(os.path.join(rec, 'groom', 'f-0002-card-evaluation.md')).read()
assert re.search(r'^base: [0-9a-f]{7,40}$', text, re.M), 'no base: sha'
notes = re.findall(r'^- ([FB]-\d{4}) .+? — (reworded|clean|product-bound) — (.*)$', text, re.M)
ids = [n[0] for n in notes]
want = {f'F-{n:04d}' for n in range(34, 71)} | {f'B-{n:04d}' for n in range(8, 13)}
if len(ids) != len(set(ids)): sys.exit('an item has more than one note')
if set(ids) != want: sys.exit(f'notes differ: missing {sorted(want - set(ids))}, extra {sorted(set(ids) - want)}')
m = re.search(r'^evaluated: (\d+) items', text, re.M)
assert m and int(m.group(1)) == len(want), 'evaluated: count wrong'
for iid, verdict, rest in notes:
    if verdict == 'reworded' and not re.match(r'`[a-z]+:[^`]+`', rest): sys.exit(f'{iid}: reworded note names no key')
    if verdict == 'product-bound' and not rest.rstrip().endswith('→ answer: ____'): sys.exit(f'{iid}: product-bound note has no answer slot')
print('ok')
EOF
```

**T3 — every named key is real or declared new, and a re-worded card carries its keys.**

```bash
python3 - <<'EOF'
import os, re, sys, dataclasses
from asf import env, conventions
rec = env.load_product(os.environ.get('ASF_PRODUCT', 'asf')).backlog_dir
def paths(d, pre=''):
    out = set()
    for k, v in (d or {}).items():
        out.add(pre + k)
        if isinstance(v, dict): out |= paths(v, pre + k + '.')
    return out
known = {'product:' + p for p in paths(env.load_file('docs/products.example.yaml'))}
known |= {'config:' + p for p in paths(env.load_file('docs/config.example.yaml'))}
known |= {'product:conventions.' + f.name for f in dataclasses.fields(conventions.Conventions)}
known |= {'product:product'}
text = open(os.path.join(rec, 'groom', 'f-0002-card-evaluation.md')).read()
notes_part, _, newkeys_part = text.partition('## New keys')
declared = re.findall(r'^- `([^`]+)` — ', newkeys_part, re.M)
if len(declared) != len(set(declared)): sys.exit('a new key is listed twice')
for iid, verdict, rest in re.findall(r'^- ([FB]-\d{4}) .+? — (reworded|clean|product-bound) — (.*)$', notes_part, re.M):
    if verdict != 'reworded': continue
    body = open(os.path.join(rec, 'features' if iid[0] == 'F' else 'bugs', iid + '.md')).read().split('## History')[0]
    for key, new in re.findall(r'`([a-z]+:[^`]+)`( \(new key\))?', rest):
        if key.startswith('state:'): continue
        if new and key not in declared: sys.exit(f'{iid}: {key} marked new but not under ## New keys')
        if not new and key not in known: sys.exit(f'{iid}: {key} is neither an existing key nor marked (new key)')
        if key not in body: sys.exit(f'{iid}: {key} named in the note but absent from the card')
print('ok')
EOF
```

**T4 — no single-product wording survives outside a `product-bound` card.**

```bash
python3 - <<'EOF'
import os, re, sys
from asf import env
rec = env.load_product(os.environ.get('ASF_PRODUCT', 'asf')).backlog_dir
text = open(os.path.join(rec, 'groom', 'f-0002-card-evaluation.md')).read()
bound = set(re.findall(r'^- ([FB]-\d{4}) .+? — product-bound — ', text, re.M))
trip = re.compile(r"--repo\b|\bthe product repo(sitory)?\b|self-hosted|\bGitHub Actions\b|~/|/tmp/|\bthe runner (pool|box(es)?)\b|\bthe worker accounts?\b", re.I)
bad = []
for iid in re.findall(r'^- ([FB]-\d{4}) ', text, re.M):
    if iid in bound: continue
    body = open(os.path.join(rec, 'features' if iid[0] == 'F' else 'bugs', iid + '.md')).read().split('## History')[0]
    body = re.sub(r'`[^`]*`', '', body)  # a key or a quoted literal in backticks is not an assumption
    bad += [f'{iid}: {m.group(0)}' for m in trip.finditer(body)]
if bad: sys.exit('single-product wording left:\n' + '\n'.join(bad))
print('ok')
EOF
```

**T5 — `clean` and `product-bound` cards were not reworded (D3, D9).**

```bash
python3 - <<'EOF'
import os, re, sys, subprocess
from asf import env
rec = env.load_product(os.environ.get('ASF_PRODUCT', 'asf')).backlog_dir
text = open(os.path.join(rec, 'groom', 'f-0002-card-evaluation.md')).read()
base = re.search(r'^base: ([0-9a-f]{7,40})$', text, re.M).group(1)
for iid, verdict in re.findall(r'^- ([FB]-\d{4}) .+? — (clean|product-bound) — ', text, re.M):
    rel = ('features/' if iid[0] == 'F' else 'bugs/') + iid + '.md'
    diff = subprocess.run(['git', '-C', rec, 'diff', '-U0', base, '--', rel], capture_output=True, text=True, check=True).stdout
    changed = [l for l in diff.splitlines() if l[:1] in '+-' and not l.startswith(('+++', '---'))]
    if verdict == 'product-bound' and changed: sys.exit(f'{iid}: product-bound card was changed')
    if verdict == 'clean':
        extra = [l for l in changed if not re.match(r'^\+- \d{4}-\d{2}-\d{2} F-0002: clean — ', l)
                 and not re.match(r'^[+-](updated|stage_since|## (Children|Backlinks)|- \[)', l)]
        if extra: sys.exit(f'{iid}: clean card changed beyond its History line: {extra[:3]}')
        if not any(re.match(r'^\+- \d{4}-\d{2}-\d{2} F-0002: clean — ', l) for l in changed): sys.exit(f'{iid}: no F-0002 History line')
for iid in re.findall(r'^- ([FB]-\d{4}) .+? — reworded — ', text, re.M):
    rel = ('features/' if iid[0] == 'F' else 'bugs/') + iid + '.md'
    if not re.search(r'^- \d{4}-\d{2}-\d{2} F-0002: reworded — ', open(os.path.join(rec, rel)).read(), re.M):
        sys.exit(f'{iid}: no F-0002 reworded History line')
print('ok')
EOF
```
