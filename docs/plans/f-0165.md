# Plan F-0165 — the number splits in two, every push takes the one its kind earns, and the seconds are on the line

Epic: E-0004 — Control plane — the factory's dashboard, served from the record. Spec:
`docs/specs/f-0165.md` (approved). Branch: `plan/F-0165`.

Two Tasks for the spec's three Stories, and the join is not a convenience — it is the one ordering
constraint the card has:

1. **the split** — `DEFAULT_PUSH_TIMEOUT_S = 900` and `DEFAULT_REF_PUSH_TIMEOUT_S = 120`, two yaml
   keys, `push_timeout(conv, refs_only)`, `conv=` on `gitpush.push`, all eleven call sites that
   resolved their own budget, and the `ast` fence that keeps them from doing it again. S-71404 and
   S-71405 land together because landing them apart puts the trunk, for the life of one pull
   request, in the state `e2a1803` was written to prevent (PD2).
2. **the evidence** — `seconds` on every process `push` returns, the branch push's seconds on the
   publish line, and the key to raise on the timed-out line. Nothing the factory *decides* changes
   here: it is the measurement C9 publishes instead of a percentile, and the sentence an operator
   reads at the moment the budget is not enough.

They run **1 → 2**, one at a time. Both write `asf/gitpush.py`, `asf/workers/lifecycle.py` and
`tests/test_gitpush.py`, so the `writes:` gate orders them even without the `after:` line, and
Task 2's `(raise git.ref_push_timeout_s)` needs a key that only Task 1 puts in `GIT_KEYS`.

**Read PD2 before deciding to split Task 1, PD3 before trusting `check_conventions.sh` to fence the
two numbers, and PD11 before writing a line of either Task.** PD3, PD4 and PD6 are three places
where the spec asserts something about this checkout that does not hold; PD5, PD7 and PD9 are three
places where a coder copying a spec snippet literally ships something that crashes, cannot be
repaired, or duplicates four tests.

```python
def test_no_call_site_resolves_its_own_push_budget(self):
    """The flag that skips the hook is the flag that sizes the clock: a caller that computes a
    timeout can hand a hooked number to a ref push, which is F-0165's bug."""
    resolvers, explicit = [], []
    for path in sorted(_py_files('asf')):
        tree = ast.parse(open(path, encoding='utf-8').read(), filename=path)
        for node in ast.walk(tree):
            if not isinstance(node, ast.Call):
                continue
            name = getattr(node.func, 'attr', None) or getattr(node.func, 'id', None)
            if name == 'push_timeout' and path != os.path.join('asf', 'gitpush.py'):
                resolvers.append(f'{path}:{node.lineno}')
            if name == 'push' and getattr(getattr(node.func, 'value', None), 'id', '') == 'gitpush':
                explicit += [f'{path}:{node.lineno}' for k in node.keywords if k.arg == 'timeout']
    self.assertEqual(resolvers, [], 'push_timeout is gitpush\'s own: pass conv= instead')
    self.assertEqual(len(explicit), 1, explicit)      # publish's documented push_timeout_s
    self.assertTrue(explicit[0].startswith(os.path.join('asf', 'workers', 'lifecycle.py')), explicit)
```
