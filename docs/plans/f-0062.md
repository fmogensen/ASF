# Plan F-0062 — eight Tasks: the table, the fence, the procedures, the command line, the two hooks, the caps, the scrub, the reading

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0062.md` (approved). Branch:
`plan/F-0062`.

Eight Tasks in six waves. The spec puts ten of its fifteen acceptance classes in one new module,
`tests/test_launch.py`, and three more in a second, `tests/test_worker_deny.py`, so most footprints
here intersect on a test file rather than on the code (PD1). Two pairs still come out disjoint and
run together: the fence and the procedures in wave 2, the scrub and the reading in wave 6.

**The wave order: 1 → (2, 3) → 4 → 5 → 6 → (7, 8).** Task 1 is the launch table, the capability
probe and the agents file — the three things every other Task reads. Task 2 is the per-role worker
settings file, its deny rules and all three doctor rows, landed early because T6 asserts a doctor
row names a flag the runtime lacks. Task 3 is `asf/procedures/`, landed before the launcher because
`spawn` passes `procedures.plugin_dir()`. Task 4 is `build_command`'s gated flags and everything
`spawn` now hands a launch, which needs all three. Task 5 is the two built-in hooks and the two
fixture sessions that are this Feature's real boundary. Task 6 is the per-kind turn cap. Task 7 is
the scrub of every durable copy of a session's own text. Task 8 is the briefs' shrink against a
recorded baseline, plus the two readings.

§3's preamble binds every Task — stdlib only, hermetic, no network, **no real runtime binary
invoked**, no real account settings file touched, every test pointing `ASF_HOME` and the accounts'
`config_dir` at a tmpdir — and so does §3's T15, the tree-wide guard that has no Story of its own.
Both are copied into every Task's **Acceptance** beside the Task's own fences, and every **Gate**
runs T15. The suite fence `python3 tools/run_tests.py` is copied into every Acceptance as §3 writes
it and is run by this product's external CI on the pull request, never on the session's host (the
standing rule; `approvals.full_suite_command`, `asf/approvals.py:374`).

Each Task's own **Acceptance** is the §3 fence its Story names, copied byte for byte.
