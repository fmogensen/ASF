# Plan F-0185 — one declaration per external service, and the five readers that stop guessing

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0185.md` (approved). Branch:
`plan/F-0185`.

Six Tasks, cut along the seam the card itself names: **one Task builds the declaration and every
pure function over it; each of the other five turns exactly one reader onto it.**

1. **the model, the catalogue, and every refusal** — `asf/connectors/__init__.py` whole (the
   `Connector` dataclass, `load`, `catalogue_entry`, `product_problems`, and all seven readers),
   the six shipped catalogue files, and `env.validate_product_text`'s call-out. Nothing in the
   factory reads it yet: every function is pure and every one lands with its own test.
2. **`asf connect`** — the one place the operator is told what to run.
3. **the doctor's rows** — `_CLI_TOOLS` shrinks to `git`, and the rows come from the declaration
   (or, for a product that declares none, from the catalogue's `legacy` entries).
4. **`actions:` as approval recognisers** — four lines inside `approvals.signals`.
5. **session inheritance** — the two carriers that already exist, plus the one edit that makes D8's
   redaction guarantee actually true (**PD2** — the spec's design does not deliver it).
6. **the status cells and the credential providers** — `provides:` read where the hand-set key is
   unset.

They run **1 → 2 → 3**, with **4, 5 and 6 all launching off Task 1**. Task 1 is the whole card's
bottleneck by construction and nothing can precede it. Task 3 waits on Task 2 for one narrow reason
named in **PD16**: the doctor's informational finding prints `asf connect --product <p>`, and a
factory that tells the operator to run a command that does not exist is worse than one that says
nothing. Tasks 4, 5 and 6 are independent of each other and of 2 and 3; they share
`tests/test_connectors.py`, so the queue will serialise them in some order, and each is green on its
own whichever order that is.

**Read PD1, PD2, PD3, PD4 and PD5 before writing a line of any Task.** Those five are places where
following the spec's `## The design` literally produces dead code, an unkept safety guarantee, a
carrier that never fires, a promise with no reader, and a failed acceptance test — in that order.
None of them is a scope change; each is the same design, corrected where the checkout contradicts
it.

The fences of **PD17** bind every Task, so every Gate block below carries them beside its own.

| PD1 | **`asf/connectors.py` and `asf/connectors/catalogue/*.yaml` cannot both exist — the spec's own file list is self-contradicting** | The spec's `## Records` adds *both* `asf/connectors.py` and `asf/connectors/catalogue/<service>.yaml`. A regular package always shadows a same-named module in the same parent, so `asf/connectors.py` would be **dead code that no import can reach**. Measured here, with a throwaway `pkg/` holding both: `from pkg import connectors` resolved to `pkg/connectors/__init__.py`, `hasattr(connectors,'X')` (the `.py`'s attribute) **False**, `hasattr(connectors,'Y')` (the package's) **True**. Worse, it is silent — no import error, no warning, just a module whose every function is unreachable. **Decided: the module is `asf/connectors/__init__.py`, and the catalogue is `asf/connectors/catalogue/*.yaml` beside it.** Every call site the spec's design writes (`from asf import connectors`, `connectors.load(product)`, `connectors.rows(product)`, `connectors.provided(...)`) is byte-for-byte unchanged — only the file the code is typed into moves. The precedents are both in the tree and both are packages with their data beside them: `asf/rules/rules.py` + `rules/`, `asf/briefs/build.py` + `asf/briefs/templates/*.md`, `asf/roles/*.md`. `asf/workers/__init__.py` is 249 lines of real code, so logic in an `__init__.py` needs no argument here. `pyproject.toml` gains `"asf.connectors" = ["catalogue/*.yaml"]` under `[tool.setuptools.package-data]`, beside the three that are there; `[tool.setuptools.packages.find]` is `include = ["asf", "asf.*"]` and picks the new package up with no edit **because it has an `__init__.py`** — a catalogue directory under a flat `connectors.py` would have shipped in no wheel at all. |
| PD2 | **D8's redaction guarantee is not delivered by the spec's design — the merge is in the wrong function** | This is the one finding that matters more than the rest put together, because D8 exists to prevent exactly the failure the spec's design would ship. The claim (`## Records`, *"What is never written down"*): *"for a `file:` secret carried into a session — that value is a redaction pattern, which is what D8 exists to guarantee."* Measured: `redact.patterns` appends `Pattern('secret', f'auth_env:{var_name}', …)` for each entry of `auth_env_secrets(cfg)` (`asf/redact.py:168-169`), and `auth_env_secrets` (`:183-203`) reads **exactly two sources** — `env.account_auth_env(account)` per pool account, and `env.product_auth_env(product)` per configured product. `env.product_auth_env` (`asf/env.py:409-420`) reads `product.conventions['auth_env']` and **nothing else**. The spec's design merges connector secrets into a **local variable** at the spawn sites (`product_auth_env = {**env.product_auth_env(product), **connectors.session_auth_env(product)}`). A local variable is invisible to `auth_env_secrets`. So under the spec as written, a connector's `file:` secret would be exported into the session's environment and **would not be a redaction pattern** — the value travelling through logs, reports and pushes with nothing scrubbing it, which the spec's own D8 calls *"the one failure this whole card must not introduce."* **Decided: the merge goes inside `env.product_auth_env` itself, and the spawn sites are not edited at all.** One function gains `{**conventions_auth_env, **connectors.session_auth_env(product)}` and **three** readers inherit it for free: both spawn sites (`asf/workers/spawn.py:837` and `:887`), `redact.auth_env_secrets` (so the pattern is real), and `credentials.probe_env` (`asf/credentials.py:205-223`, which builds its probe env through the same call — a `token`-kind connector's probe reaches its own credential). `asf/redact.py` is therefore **not** in any Task's footprint, and neither is the spawn merge: one edit replaces three, and it is the only one of the four that makes the guarantee true. The docstring of `product_auth_env` gains the second source and names F-0185 and D8 as why. |
