# Plan F-0043 — two CI numbers with a target, and a week over it is a defect

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0043.md` (approved). Branch: `plan/F-0043`.

Four Tasks, cut by the module that changes, in the order the spec's own sections run. Task 1 is
the configuration — five typed conventions, `CI_FIELDS` gaining `targets:`, the copy out of the
`ci:` block, and the documented example yaml that proves it (§2.1, §2.2). Task 2 is the
arithmetic and what prints it: `ci_waste_numbers`, the two rows it builds, and `render_daily`
hoisting the seven-day CI read it already makes (§2.3, §2.4). Task 3 is the cap on its own —
`refile_days` and `_too_soon` in place of "already filed today", with `1` as the default that is
byte for byte what the guard has always meant (§2.6). Task 4 is the fourth source that uses both
(§2.5).

Tasks 3 and 4 both write `asf/tick/file_bugs.py` and `tests/test_file_bugs.py`, so they run one
after the other — which is also their dependency order, since Task 4's signature is the first
one that asks for a `refile_days` other than 1. Task 3 depends on nothing and starts in the first
wave beside Task 1: the cap is a change to the existing filer and needs neither the conventions
nor the metrics. Task 2 needs Task 1's `ci_cancelled_target_pct`, `ci_min_runs` and `ci_provider`;
Task 4 needs Task 2's `ci_waste_numbers` and Task 3's cap.

Wave order: **(1 ∥ 3) → 2 → 4**.

1. `CI_TARGET_WINDOW_DAYS = 7` and `CI_SPLIT_CAP = 4` with §2.3's comment on the cap.
2. `_conv_int(conv, key, default)` → `(value, complaint)`: the conventions' integer for `key`, or

3. `_ci_provider(conv)` → the product's provider, or `None` when it is falsy or the literal

   when `den < floor`, an empty window included; otherwise `verdict` is `'over'` when
   `pct >= target` (a product setting `cancelled_pct: 0` gets a verdict, not an unmeetable
   number), else `'ok'`.
5. `by_day` buckets on `parse_ts(r.get('ts')).date().isoformat()`, oldest first, days with runs

   same function.
8. The four other shapes of §2.4, in order: under target → the verdict word is `ok`; `den` under

9. `render_daily` reads `ci7 = read_stream(root, 'ci', week)` once after `week` is computed, hands
