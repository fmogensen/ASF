### Task 1: `asf/capacity.py` — the resolver, the CI source, the overlay, the reserve's new home
stories: S-7301, S-7302, S-7304, S-7305, S-7307
writes: asf/capacity.py, tests/test_capacity.py, asf/workers/pool.py

**Files**
- `asf/capacity.py` — new
- `tests/test_capacity.py` — new
- `asf/workers/pool.py` — `reserve_from_config` delegates; `DEFAULT_RESERVE` re-exported

**Steps**
1. Create `asf/capacity.py` with the module docstring naming the two blocks of spec §2.1 and the
   resolution laws of §2.2. Constants: `DEFAULT_SESSIONS = 4`, `DEFAULT_RESERVE = {'local': 1,
   'cloud': 1}`. A `Resolved` class (plain class or dataclass) with exactly the fields of §2.2:
   `sessions`, `sessions_bound`, `ci`, `ci_bound`, `ci_inflight`, `batch`, `reserve`.
2. `product_sessions(product, cfg)` — D4's chain, returning `(n, source)` with `source` one of
   `'product'`, `'operator default'`, `'feeder.capacity'`, `'default'`: `product` file
   `capacity.sessions` → `cfg['capacity']['per_product']['sessions']` → `cfg['feeder']['capacity']`
   → `DEFAULT_SESSIONS`. A value is honoured only when it is an `int >= 0` (the rule
   `step_wave.capacity` applies today); anything else falls through. Read the product's block via
   the `Product` object's parsed data (`asf.env.Product._get('capacity', {})` or an accessor added
   in this file — no change to `asf/env.py`, which Task 2 owns).
3. `product_ci(product, cfg)` → `(n | None, source | None)`: product `capacity.ci` →
   `capacity.per_product.ci` → `None`. `total_sessions(cfg)`, `total_ci(cfg)` →
   `capacity.total.*` or `None`.
4. `inflight_sessions(name)` and `inflight_sessions_elsewhere(name)` — PD8; "elsewhere" sums
   every product under `~/.ASF/products/*.yaml` (P7: the enumeration
   `asf.schema._all_products` uses — reuse it, do not copy it) except `name`.
5. The session law of §2.2 in `resolve`: `ceiling` from step 2; `headroom = total -
   elsewhere` only when `total_sessions` is set; `sessions = max(0, min(...))`;
   `sessions_bound` is `'operator total'` when the headroom term won strictly, else the step-2
   source. The resolver returns a **ceiling** — it never subtracts this product's own in-flight
   sessions (P5: `asf.feeder.tiers.free_slots` does).
6. The CI source (D7/D8): `class CiRuns` whose `read(product)` runs the `gh run list …` of §2.2
   with a timeout via `subprocess.run`, returning `int` or `None` on non-zero exit, timeout,
   `OSError`, unparsable output, `ci: none`, missing `repo_slug`, missing `ci.workflow` — never
   raises; `class NoCiRuns` whose `read` returns `None`. `ci_source(product, cfg)` → `NoCiRuns()`
   when the product's `ci` is `none` or unset, else `CiRuns()` (the shape of
   `asf.workers.quota.source_from_config`). The CI law of §2.2 in `resolve`: when neither
   `product_ci` nor `total_ci` is set, **no source call at all** (D9); the product's own count is
   read only when `capacity.ci` resolves; others' counts only when `capacity.total.ci` is set; an
   unknown count leaves `ci_inflight = None` and never lowers `ci`.
7. `batch_shape(product, cfg)` → `{per_run, parallel, runners}` from the product's
   `capacity.batch`, keeping only keys whose value is an `int >= 0`.
8. `reserve(cfg)` — `capacity.reserve_for_s1` wins, else `worker_pool.reserve_for_s1`, else
   `DEFAULT_RESERVE`; per-lane merge exactly as `pool.reserve_from_config` does today (P4's style).
9. `deprecations(cfg)` → one line per old key in use, the text of §4.2:
   `feeder.capacity is set — move it to capacity.per_product.sessions`,
   `worker_pool.reserve_for_s1 is set — move it to capacity.reserve_for_s1`.
10. `env_overlay(resolved, product)` → `ASF_PRODUCT`, `ASF_CAPACITY_SESSIONS`,
    `ASF_CAPACITY_CI`, `ASF_CAPACITY_BATCH_PER_RUN`, `ASF_CAPACITY_BATCH_PARALLEL`,
    `ASF_CAPACITY_RUNNERS` (names as in §2.6), string values, and **only** the keys that
    resolved (D10).
11. `resolve(product, cfg=None, ci_source=None)` — `cfg` defaults to `env.load_config()`,
    `ci_source` to `ci_source(product, cfg)`; the injected source is what the tests stub.
12. `asf/workers/pool.py`: `from asf.capacity import DEFAULT_RESERVE` (re-export, existing
    importers unchanged); `reserve_from_config(cfg)` returns `capacity.reserve(cfg)`. Update the
    module docstring's `reserve_for_s1` example to name the new key and the fallback. No behaviour
    change when neither key is set.
13. `tests/test_capacity.py`: the classes `ResolveSessions`, `ResolveCi`, `Reserve`, `Overlay`
    with exactly the test names of spec §3.2. Use a temp `ASF_HOME` with product files and
    `state/<p>/sessions.jsonl` ledgers for the in-flight counts; stub the CI source with a small
    counting fake to prove "no source call" (and patch `subprocess.run` to fail the test if
    `test_ci_none_product_never_calls_gh` reaches `gh`).
