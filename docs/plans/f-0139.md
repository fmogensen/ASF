# Plan F-0139 — three numbers where there was one: one Task, one wave

Epic: E-0004 — Control plane, the factory's dashboard, served from the record. Spec:
`docs/specs/f-0139.md` (approved). Branch: `plan/F-0139`.

**One Task, one wave.** The spec is two Stories and they are one edit: both rewrite the same
twenty-line function in the same module and assert it from the same test file. Their `writes:` are
not merely overlapping but *identical*, so two Tasks would queue anyway and the second would re-open
the lines the first had just written (PD4). The Task lands `RECORD_TYPES`, the rewritten
`record_cell`, the two docstrings and three test classes, and after it the Record row reads
`<n> work · <n> Resolved · <n> records · <n> Active · <n> blocked · <n> no rule`.

**This spec is accurate.** Every anchor it cites is exact at this branch's head, every string in its
"after" table and every string in its acceptance reproduces byte for byte when its own design is run
over its own fixtures, and its `feda154b2` measurement has not drifted (PD1). That is unusual and it
is worth saying plainly: the coder can trust the snippets. The three things it does *not* say are
below.

**Read PD3 before writing `RecordSplitTests`.** The spec's own S-39200 fixture **cannot detect
C6** — measured here, it prints `1 Active · 1 blocked` whether the flags count over `work` or over
`opened`, because the only Active and only blocked item in it is a Bug, which is work either way.
`RecordFlagTests` is therefore the *sole* proof of the flag narrowing, not a second opinion on it. A
coder who lands the split and forgets C6 gets a green `RecordCellTests` **and** a green
`RecordSplitTests`.

**Read PD7 before touching the `no_rule` line.** Nothing in the suite — shipped or new — pins
`no rule`'s population. Measured: every existing fixture gives the same count over `live` as over
`opened`, so a coder who "tidies" that one line to match its three new neighbours passes every test
in the module while silently changing an untouched population the spec's Out puts out of scope.

**PD2 is the gate neither this session nor the spec's could run.** `tools/check_conventions.sh` is
refused by both sandboxes. It was emulated here pattern for pattern against the exact text the card
adds — clean — but the Task's Gate runs the real script, and CI runs it on the pull request.
