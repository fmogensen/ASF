# Plan F-0133 — three Tasks in one wave: the groom's own commit, the stamp with a format, and the gate a new product gets

Epic: E-0002 — ASF 0.2 — self-improvement. Spec: `docs/specs/f-0133.md` (approved). Branch:
`plan/F-0133`, cut from `origin/main` at `dca5d85f3`.

**Three Tasks, one wave.** The spec is three independent gaps that share no function, no module and
no test file. Their footprints are disjoint (PD1) and none reads code another writes, so all three
carry `after: none` and start together. This is the rare card where the split is free: it is not a
judgement about how to carve one change, it is the card already being three.

1. **Task 1 — §1, the groom commits its own output.** `cmd_groom` → `_groom` plus the wrapper and
   `_commit_message`, `asf/cli.py`'s groom branch loses `_published`, the new
   `tests/test_groom_publish.py`, and the two tick-path tests in `tests/test_groom_every_tick.py`.
2. **Task 2 — §2, a stamp ASF did not write.** `STAMP_MARKER`/`_STAMP_RE`/`read_daily_stamp`/
   `daily_due`/`write_daily_stamp` in `asf/tick/steps.py`, `doctor.check_daily_stamp` and its row,
   the new classes in `tests/test_tick_steps.py` and `tests/test_doctor.py`, **the two existing
   `tests/test_tick.py` assertions the new format breaks (PD4)**, and the operating guide's
   daily-stamp paragraph.
3. **Task 3 — §3, a new product grooms.** `init.render_product_yaml`'s `approvals:` block,
   `approvals.check_doctor`'s leading note, the new tests in `tests/test_install.py` and
   `tests/test_approvals.py`, **the one existing approvals assertion the note breaks (PD6)**, and
   the two docs lines — `docs/products.example.yaml` **as a comment only (PD5)**.

Wave order: **1, 2, 3 together**. One wave, three seats.

Read **PD4 before writing a line of §2** — two tests in a file the spec's `## In` never names
assert the old stamp format byte for byte, and a coder who does not carry that file will red its
own gate with no footprint to fix it in. Read **PD5 before touching
`docs/products.example.yaml`** — uncommenting the `groom: auto` line there fails a whole-repo
catalogue test, measured. Read **PD6 before adding the doctor note**, and **PD12 before opening
`docs/guide/operating.md`**: half of that file's wrongness is F-0144's, not this card's.
