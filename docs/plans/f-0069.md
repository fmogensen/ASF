### Task 2: `asf/precheck.py` — the rows a sensitive diff owes, and the level it is never read below
stories: S-32251
writes: asf/precheck.py, tests/test_precheck.py
after: Task 1

§2.3: five signatures gain one `security=` argument and one gains `security=False`, and with the
default every existing caller's answer is byte-identical. The module stays pure — no file, no git,
no path (F-0060's PD5 scoped that sentence to the grammar, and this is grammar).

**Files**

- `asf/precheck.py` — `SECURITY_DIMENSIONS`, `CLASS_DIMENSION`, `class_dimension`,
  `security_dimensions`; `dimensions`, `covered`, `faults`, `render_table` gain `security=()`;
  `level_for` gains `security=False`
- `tests/test_precheck.py` — `SecurityDimensionTests`, and the floor cases added to `LevelTests`

**Steps**

1. `SECURITY_DIMENSIONS`, the three standing rows of §2.3 byte for byte, with the `#:` comment "The
   rows any diff touching a sensitive class owes, whatever the class."
2. `CLASS_DIMENSION`, §2.3's one-sentence template with its `{name}` field and its `#:` comment
   ("The class name is the product's; this sentence is not."), and `class_dimension(name)` →
   `CLASS_DIMENSION.format(name=name)`.
3. `security_dimensions(hit)`: one `class_dimension` per key of `hit` in the order the mapping
   gives them (Task 1's `touched` preserves configuration order), then `SECURITY_DIMENSIONS`; `()`
   for `{}` or None. It takes the mapping, not a list of names, so the lane hands it `f['security']`
   unchanged.
4. `dimensions(level, security=())`: today's cumulative list for `level`, then `security` appended
   in order — LOW's rows first, the class rows last. Unknown level still reads as `HIGH`'s.
5. `covered(rows, level, security=())`, `faults(text, level, security=())` and
   `render_table(level, security=())`: each threads `security` into its `dimensions` call and
   changes nothing else. `faults` therefore emits one `dimension not covered: "<name>"` per
   unanswered class row, in the same order and with the same wording as a level row's, which is
   what makes an unread class an *incomplete* precheck rather than a pass (P5).
6. `level_for(size_class, changed_lines, max_lines, security=False)`: the existing body, then the
   floor — a result of `LOW` with `security` true becomes `HIGH`, and its `why` becomes
   `size class small, floored by sensitive paths` (§2.3's exact sentence). `MAX` and `HIGH` are
   returned unchanged; `security=False` leaves every one of today's eight cases alone.
7. Nothing else in the module moves: `HEADER`, `parse`, `findings`, `blocking`, `keys`, `head_of`
   and `level_of` are untouched, and no new constant is exported — a security row is a row (D7).
8. `SecurityDimensionTests` per §3's T2: `security_dimensions({})` is `()`; over two classes it is
   two class rows in configuration order then the three standing rows, with no name repeated;
   `dimensions(LOW)` and `covered(rows, LOW)` **called with no `security` argument** are asserted
   equal to the values computed from `DIMENSIONS` itself, so the test fails if the default ever
   stops being empty; `dimensions(HIGH, security=…)` is `high`'s list then the security rows in
   order; `covered` names an uncovered class row; `faults` over a table answering every level row
   and no class row prints exactly one `dimension not covered: "billing: …"` per class;
   `render_table(HIGH, security=…)` re-parsed by `parse` yields one row per dimension including the
   class rows, and two unfilled faults per row.
9. `LevelTests` gains the floor: a `size.SMALL` footprint under the line cap is `low` today and
   `high` with `security=True`, and its `why` names the floor; a `max` answer is unchanged by
   `security=True`; every existing case is re-asserted with `security=False`.
