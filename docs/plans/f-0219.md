# Plan F-0219 — the factory stops breaking its own reservation, and every relief cancel says which kind it was and what it cost

Epic: E-0004 — Control plane — the factory's dashboard, served from the record. Spec:
`docs/specs/f-0219.md` (approved). Branch: `plan/F-0219`.

**Five Tasks, five waves, run 1 → 2 → 3 → 4 → 5.** They serialise by construction, not by choice:
four of the five write `asf/ci_queue.py` and `tests/test_ci_queue.py`, and Tasks 1 and 5 both write
`asf/ci_pool.py` and `tests/test_ci_reserve.py`. The order is also the order the card reads in, with
one deliberate inversion recorded in **PD3**: the measured *hold* travels with Task 1 rather than
with the gate, because `held_by_pr` takes `hold_s` as an argument and Story 1's fix is inert without
it.

**Read PD1, PD2, PD5, PD6 and PD8 before writing a line of any Task.** Five things in the spec do
not survive contact with this checkout.

* **PD1: `asf/ci_cancels.py` has landed.** P19 says F-0230 "is specced and in plan"; its first Task
  merged as `35d2cc1a7` (#518). The good news is that it landed *reconciled* — no second ledger, no
  JSONL, `CANCELS_FILE`/`claim_cancel`/`load_claims` still `ci_queue`'s — so C9 and C12 are now
  enforced by code rather than argued against a spec. The bad news is one word: the landed module's
  `REREAD` says `superseded` "is never honoured … the weak reading this card exists to replace", and
  §4 prints `expected` on exactly that row.
* **PD2: `_relieve_for` raises `UnboundLocalError` today**, in the scenario this card is about,
  reproduced live. Out of scope, and the Task that edits that function must not depend on the names
  that are unbound.
* **PD5: the hold the spec defines cannot be measured from the read the spec says it is free from.**
  `attempt_jobs`' `--jq` does not select the run's `created_at` — nor a job's `name` or `status`.
* **PD6: `parse_runs_on` grew a `variables` argument since the spec** (F-0183, `b2681ae88`), and a
  `runs-on` naming `${{ vars.X }}` is now *unresolved* rather than its default. That silently widens
  the set of runs the gate will never hold.
* **PD8: `cmd_queue` returns before the `free:` lines when the line is empty**, so the cancels block
  at the spec's placement is invisible exactly when an operator asks for it.

Every measurement below was taken in this worktree at `9e27c70e5` — twenty-one commits past the
