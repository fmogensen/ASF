Epic: E-0004 — Control plane — the factory's dashboard, served from the record. Spec:
`docs/specs/f-0226.md` (approved). Branch: `plan/F-0226`.

field, renames the row at its one site and extends the four kind-keyed sets — it is the whole
behaviour fence, so it lands alone. Task 2 makes the two producers name the cause; Task 3 makes
the two readers print it. Both need Task 1's constants and neither needs the other, so they run
together in wave 2.

**Read PD1 before writing a line of Task 1.** The rename is not confined to the five test modules
the spec names: it was applied to `asf/feeder/rows.py:745` in this worktree and the suite run, and
it turns **four** tests red across **three** modules — one of them `tests/test_ingest.py`, which
the spec names nowhere. Task 1's `writes:` carries it. Skip PD1 and Task 1 lands a red trunk.

Everything else in the spec is sound. Every anchor was re-derived here at `7793b3515` (PD2); the
four kind-keyed sets in P6–P9 are provably the complete list (PD3); the baseline is green (PD10).
The remaining findings are three hazards a coder would otherwise pay for — a tuple return that
silently weakens two existing assertions (PD5), a dead import in the spec's own snippet (PD6), and
one refusal the spec's mapping labels wrongly (PD7).
