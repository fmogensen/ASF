# Plan F-0098 — one classifier for a run's state

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0098.md` (approved). Branch: `plan/F-0098`.

Four Tasks, cut by reader. Task 1 is the classifier itself — `Status`, `classify`, `state_of`,
`holds_seat`, `seats`, and `derive` re-expressed over it — plus the structural test as a ratchet
that starts with the six unconverted readers exempt. Task 2 converts the seat (`inflight`,
`live_all`, `capacity`, `tiers`, `Pool`, the wave's reads) and removes its own modules from the
ratchet. Task 3 converts the three views (`asf sessions`, `asf status`, the tick digest) and
removes theirs. Task 4 converts health, stall, harvest and the cold-retry step, empties the
ratchet, and is where §3.6's fence becomes the test the spec asks for.

Every Task writes `tests/test_lifecycle.py` — Task 1 to add `SessionStateInvariants` and the
ratchet, each later Task to shorten the ratchet by its own modules. That is the queue: the four
run one after the other, which is also the dependency order (every Task imports what Task 1
defines, and the ratchet can only reach empty once the last reader is converted).

Wave order: **1 → 2 → 3 → 4**.

### Task 1: the classifier — five states, the evidence ladder, and `derive` re-expressed over it
stories: S-15050, S-15051, S-15052
writes: asf/workers/lifecycle.py, tests/test_lifecycle.py

§2.1, §2.2 and §2.3: one pure function from a run and its evidence to one state, one impure entry
point that gathers no more evidence than the answer needs, and `derive` reading the first instead
of re-testing `ended` and `end_reason` itself. No reader is converted here — this Task adds the
thing the other three call, and the ratchet that will hold them to it.

**Files**

- `asf/workers/lifecycle.py` — the state names and reason texts; `Status`; `classify`; `state_of`;
  `holds_seat`; `seats`; `is_dead_reason`; `LIVE_GROUPS`; `derive` re-expressed
  (`asf/workers/lifecycle.py:493-515`); the module docstring's state list.
- `tests/test_lifecycle.py` — `SessionStateInvariants` (new) and `OneClassifierTest` (new, with the
  ratchet of P4). `StateMachineInvariants` (`:225`) is unchanged and is the regression net.

**Steps**

1. The vocabulary of §2.1, beside the existing `FINISHED`/`DEAD_PID`/`STOPPED`
   (`asf/workers/lifecycle.py:85-89`): `WORKING`, `ENDED_AWAITING_TICK`, `FAILED`, `DEAD`,
   `SESSION_STATES`, `PUSHED_NO_REPORT`, `NO_RECORD`, `STOPPED_BY_OPERATOR`, `DEAD_REASONS`.
   `DEAD_PID` keeps its value and gains the comment of §2.1: read, never written.
   `is_dead_reason(reason)` is true for `DEAD_PID` and for `f'{DEAD}: {NO_RECORD}'` — the one
   place both texts are accepted (P8).
2. `LIVE_GROUPS` per P11 — `(state, table heading, count word)` for the three live groups, in the
   order the views print them.
3. `Status` as §2.1 fences it — `name`, `result`, `reason`, `source`, and the `label` property
   rendering §2.1's table: `working`; `ended, awaiting tick (<result>)`; `finished`;
   `failed: <reason>`; `dead: <reason>`.
4. `classify(run, ev, path=None)`, pure, in §2.1's order:
   - `run['ended']` — `reason = run.get('end_reason') or DEAD_PID` (P6):
     `FINISHED` → `Status(FINISHED, result=FINISHED, source='ledger')`;
     `STOPPED` → `Status(DEAD, result=STOPPED, reason=STOPPED_BY_OPERATOR, source='ledger')` (P7);
     `is_dead_reason(reason)` → `Status(ENDED_AWAITING_TICK, result=judge(run, ev, …), source='report')`
     when `ev.result is not None` (B-0028's re-judge), else `Status(DEAD, reason=NO_RECORD, source='ledger')`;
     anything else → `Status(FAILED, reason=reason, result=reason, source='ledger')`.
   - no `ended`, `ev.alive` → `Status(WORKING, source='pid')`.
   - no `ended`, gone, `ev.result is not None` →
     `Status(ENDED_AWAITING_TICK, result=judge(run, ev, landing=lands(run, path)), source='report')`.
   - no `ended`, gone, no result, `ev.remote_sha` and `ev.has_commits` →
     `Status(ENDED_AWAITING_TICK, result=PUSHED_NO_REPORT, source='branch')`.
   - otherwise → `Status(DEAD, reason=NO_RECORD, source='pid')`.
   No git, no clock, no file: `judge` and `lands` are the only calls, and `path` is passed through
   to `lands` exactly as `derive` passes it today.
5. `state_of(product, run, alive=None, path=None, gather_fn=None)` — §2.2's ladder, in order:
   a recorded run that is not a recorded death classifies against `Evidence()` and reads nothing;
   a recorded death reads the log's result line alone (`runtime.read_result(run.get('log'))`);
   a run with no `ended` whose `alive(run.get('pid'))` answers classifies against
   `Evidence(alive=True)`; only a run with no `ended` whose process is gone calls
   `gather(product, run, alive=alive)`. `alive` defaults to `health.pid_alive`, imported inside
   the function as `gather` already does (`asf/workers/lifecycle.py:400`). `gather_fn` exists for
   the test that asserts git is never reached.
6. `holds_seat(status)` → `status.name == WORKING`. `seats(rows)` counts the rows of an inflight
   list whose `state` holds a seat, and counts a row carrying no `state` as one (§1.4, P14). A row
   may carry its state as a `Status` or as its `name` string; `seats` accepts both.
7. `derive` re-expressed exactly as §2.3 fences it, over `classify(run, ev, path=path)`, with the
   `landed`/`held`/`corrected`/`adjudicate` arms and `TRANSITIONS` untouched. The `ENDED` arm reads
   `status.result or status.reason`, which P6 and P7 keep equal to today's text for every input.
8. The module docstring gains the five session states beside the nine branch states, and says which
   is which: the branch lifecycle is what lands, the session state is what a reader prints.
9. `SessionStateInvariants` — every bullet of §3.1, over hand-built runs and `Evidence`, with no
   git and no clock, including the `gather` that raises if called (step 5's `gather_fn`) and the
   sweep asserting `classify` returns a name in `SESSION_STATES` over the runs and evidence
   `StateMachineInvariants`' own generator produces (`tests/test_lifecycle.py:225-243`).
10. `OneClassifierTest` — the AST walk of P10 over every `asf/**/*.py` but
    `asf/workers/lifecycle.py`, reporting `<file>:<line>` for each state word constant and each
    direct `end_reason ==` comparison, with §2.7's three `views/sessions.py` headings named as the
    allowed exception, and with `NOT_YET` (P4) listing the six modules this plan has not converted
    yet: `asf/capacity.py`, `asf/feeder/tiers.py`, `asf/views/sessions.py`, `asf/views/status.py`,
    `asf/tick/summary.py`, `asf/workers/stall.py`, `asf/workers/health.py`, `asf/tick/step_health.py`,
    `asf/harvest/harvest.py`. A docstring in `NOT_YET` says which Task empties which entry.

`SessionStateInvariants` covers, over hand-built runs and `Evidence`, with no git and no clock:

- the four sessions of 2026-09-23 — no `ended`, pid gone, a result line that says ok, a pushed
  branch — classify `ended-awaiting-tick` with `result == 'finished'`, **not** `dead`;
- a run with no `ended`, pid gone, a result that says ok on a branch with unpushed commits →
  `ended-awaiting-tick(failed: not pushed: 0 uncommitted file(s), 2 unpushed commit(s))` — the
  same text health writes one tick later;
- no `ended`, pid gone, no result, `remote_sha` set and `has_commits` → `ended-awaiting-tick`,
  `result == 'pushed, no report'`, `source == 'branch'`;
- no `ended`, pid gone, no result, no `remote_sha` → `dead`, `reason == NO_RECORD`;
- no `ended`, pid gone, no result, a `remote_sha` but `has_commits` false (B-0076's empty
  branch) → `dead`, not `ended-awaiting-tick`;
- `ended` + `end_reason: finished` → `finished`; `+ stopped` → `dead(stopped by the operator)`;
  `+ failed: <x>` → `failed(<x>)`;
- a ledger line carrying the retired `dead pid` → `dead(NO_RECORD)`, and the same line once a

- `classify` returns a name in `SESSION_STATES` for every combination of the generated runs and
  evidence the existing `StateMachineInvariants` generator produces;
- `holds_seat` is true for `working` and false for the other four;
- `state_of` gathers no git for a recorded run and for a live one — asserted with a `gather`
  that raises if called.

`StateMachineInvariants` (unchanged, now over the re-expressed `derive`) proves the two axes
still agree: every `derive` result is a named state, and the lane walk still walks.
