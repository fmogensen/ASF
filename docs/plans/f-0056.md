# Plan F-0056 — eight Tasks: four memories become code, one becomes a pointer, and the check that finds the next six

Epic: E-0001 — ASF 0.1 — a working factory. Spec: `docs/specs/f-0056.md` (approved). Branch:
`plan/F-0056`.

Eight Tasks, one per Story, which is the cut the spec's own §1.4 asks for ("the plan mints one
Task per Story, and four small disjoint footprints parallelise where one does not"). Task 1 is the
interface and the config surface (§2.1, §1.2's `conventions` block), Task 2 the rule script the
CONSTITUTION has been promising (§2.2), Task 3 the epic route (§2.3), Task 4 the refused inbox
answer (§2.4), Task 5 `asf plan-check` (§2.5), Task 6 `asf spec-check` (§2.6), Task 7 the
half-applied reshape (§2.7), Task 8 the committed pointer table (§4, §3's T8).

**The wave order is three waves: (1, 4, 7) → (2, 3, 5) → (6, 8).** Four of the eight are
footprint-disjoint from everything and could run at any time; the queues that remain are three
shared files, each named in PD11: `asf/cli.py` (Tasks 1, 5, 6), `tests/test_memory.py` (Tasks 1, 2,
8) and the two groom modules `asf/groom/inbox.py` + `asf/groom/groom.py` (Tasks 3, 4). Every
queue is declared on an `after:` line rather than left to whichever coder gets the slot first.

§3's preamble binds every Task — the whole suite stays green — and so does §3's T9, the tree-wide
guard that has no Story of its own: no console path, account or host name in the repo, no
convention default outside `asf/conventions.py`, and an unchanged plugin. Both fences are copied
into every Task's **Acceptance** beside the Task's own, and every **Gate** runs them.

Each Task's own **Acceptance** is the §3 fence its Story names, copied byte for byte.

### Task 1: `asf.memory` — the interface, the five conventions, and the check that names a file with no card
stories: S-30450

§2.1 and §1.2's `conventions` block. One new module, named for the interface and not for any
backend; five typed fields with documented defaults; one `asf memory check` registration. The
module is the only thing in the package that knows a memory directory exists, and it never opens a
file for writing (§4, "Not written").

**Files**

- `asf/memory.py` — §2.1's docstring verbatim; `memory_files`, `pointer`, `unpointed`,
  `cmd_check`, `register`
- `asf/conventions.py` — `DEFAULT_MEMORY_DIR`, `DEFAULT_MEMORY_GRACE_DAYS`,
  `DEFAULT_MEMORY_INDEX`, `DEFAULT_MEMORY_STYLE_GLOBS`, `DEFAULT_EPIC_ROUTES` and the five fields
- `asf/cli.py` — `from asf import memory` / `memory.register(sub)` in the registration block
- `tests/test_memory.py` — new module; `MemoryCheckTests`
- `tests/test_conventions.py` — `MemoryConventionsTests`
- `docs/products.example.yaml` — the five keys under `conventions:`, commented, with no path
- `docs/guide/product-config.md` — five rows in the Conventions table

**Steps**

1. `asf/conventions.py`: the five module constants beside the ones already there —
   `DEFAULT_MEMORY_DIR = None`, `DEFAULT_MEMORY_GRACE_DAYS = 14` (the fortnight R-0124 names),
   `DEFAULT_MEMORY_INDEX = 'MEMORY.md'`, `DEFAULT_MEMORY_STYLE_GLOBS = ()`,
   `DEFAULT_EPIC_ROUTES = ()`. None of the five contains `/`, `{` or `#`, so
   `forbidden_patterns()` generates no new pattern for them (`asf/conventions.py:320-336`) and
   nothing else in the tree becomes unlandable.
2. The five fields on `Conventions`, each with the `#:` comment the module's style requires and a
   `:data:` reference to its default: `memory_dir: str = DEFAULT_MEMORY_DIR`,
   `memory_grace_days: int = DEFAULT_MEMORY_GRACE_DAYS`,
   `memory_index: str = DEFAULT_MEMORY_INDEX`,
   `memory_style_globs: tuple = DEFAULT_MEMORY_STYLE_GLOBS`,
   `epic_routes: tuple = DEFAULT_EPIC_ROUTES`. The two sequence fields default to a tuple and
   need no `default_factory`: nothing mutates them, and `Conventions()` must read back as `()`
   (§3's T1). A yaml override arrives as a list and is iterated, never mutated. `memory_dir`'s
   comment says what §1.3 says: unset by default, because a default would be a machine path in a
   public repo.
3. `from_mapping` needs no branch for any of the five — each is a flat key, and the generic
   `for key in list(data): if key in known` loop already takes them (`asf/conventions.py`'s
   `from_mapping`). Assert that in `MemoryConventionsTests` rather than adding a case: each
   override lands on its field and `extra` stays empty.
4. `asf/memory.py`, opening with §2.1's docstring copied as it stands. It imports `fnmatch`, `os`
   and `re`-free: the one regex it needs is `asf.record.core.MENTION_ID_RE`, imported, never
   re-spelled (§1.1, PD10). No path literal, no product name, no index name of its own — the
   index name comes from `conventions.memory_index` or the caller.
5. `memory_files(dir, index=DEFAULT_MEMORY_INDEX)` → sorted absolute paths of `*.md` directly
   under `dir`: `os.listdir`, no recursion, skipping any name starting with `.` and the index
   itself. A missing or unreadable `dir` returns `[]` — the caller decides whether that is a
   finding, and for an operator who has not configured one it is not.
6. `pointer(text)` → `MENTION_ID_RE.search(text)`'s matched text, or `None`. Its docstring
   carries PD10: the match of a five-digit id is its first four digits, the function is a
   presence test, and no caller prints its return — which is why one id form in this repo stays
   one id form.
7. `unpointed(dir, now, grace_days, style_globs=(), index=DEFAULT_MEMORY_INDEX)` →
   `[(path, age_days)]`, oldest first: for each `memory_files` entry, skip it when
   `fnmatch.fnmatch(basename, g)` for any `g` in `style_globs` (style is exempt however old,
   R-0124), skip it when `pointer(text)` is set, and keep it when
   `age_days >= grace_days` where `age_days = int((now - os.stat(path).st_mtime) // 86400)`
   (PD13: `>=`, so `--grace-days 0` means every file). `now` is a parameter, never `time.time()`
   inside — the tests set mtimes and pass a clock.
8. `cmd_check(args, out=print)`: resolve the directory as `args.dir` first, then
   `env.load_product(args.product).conventions.memory_dir` — the shape
   `asf/groom/inbox.py:31` already uses — and the grace and style globs and index the same way,
   with `args.grace_days` overriding. With no directory, print
   `memory: no directory configured — pass --dir or set conventions.memory_dir` and return 0

   `memory: <n> files carry no card` header and one indented `<name> <age>d` line per entry, the
   names column-aligned — and return 1; with nothing to report print
   `memory: every file carries a card` and return 0 (§3's T8 names that line byte for byte).

9. `register(sub)` exactly in `plugin_build.register`'s shape (`asf/plugin_build.py:187-192`):

10. `asf/cli.py`: `from asf import memory` and `memory.register(sub)` in the block at `:345-352`,
