(`asf/harvest/lane.py:4927-4935`; `recheck` does the same at `:4426`.) `exact_head(f)`

* `pr_graph.checks_for(slug, number, head)` answers `None` unless the snapshot's head *is* that sha,
  so `pr_checks` falls to the REST read `gh pr checks <n>` — which reports the checks of the head
  the **PR** is at — and then adds `head_runs(slug, head, …)` for the branch head. A green rollup
  earned by the PR's head is judged, and attributed to the branch head;
* `remember_green` writes `{head: <branch head>, tree: tree_at(repo, <branch head>), passed: …}`
  into `tree-green.json` — a green row for content that never ran those checks;
* `tree_green.carried` hands that row to any later head of the same PR with that tree
  (`asf/tree_green.py:123-141`), and `carried_green` turns it into `'green'` at the landing gate
  (`lane.py:4438-4458`) and in the merge queue (`merge_queue.py:2613-2620`). A false green on the
  landing path is the one thing the carry must not produce.
