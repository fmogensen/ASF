## C — blocks this verdict

**C1** `asf/views/status.py:833` — the snapshot's default stale horizon no longer matches the live `Stale` row's horizon, which D4 (`docs/specs/f-0118.md`, "Two definitions of 'stale' in one product is the bug, not the feature") explicitly forbids.

`snapshot_text` computes `horizon = int(stale_after_s if stale_after_s is not None else 2 * _record_period_s(product))` (`asf/views/status.py:833`). That was correct against the spec's own precondition P8 ("`stale_cell` already means stale as *twice* that period", verified at checkout `9e27c70e5`) and the replan's RD6. But `stale_cell` itself (`asf/views/status.py:300-337`) no longer uses `2 * _record_period_s(product)` — it falls through to `_stale_after_s(product, duration_s)` (`asf/views/status.py:290-296`), landed by `cdc074ecb` "T-0778 — the Stale row reads the cadence the tick measured… (#829)", a commit that post-dates both the spec's `9e27c70e5` checkout and the replan's own `140bc5477` re-derivation checkpoint (`git merge-base --is-ancestor cdc074ecb 140bc5477` fails). `_stale_after_s` is `2 * (_record_period_s(product) + duration)`, where `duration` is the last record tick's measured length — and that length is always populated (`duration_s=round(sum(r['seconds'] for r in ran), 1)`, `asf/tick/tick.py:940`), so the two horizons now differ on essentially every real tick, growing with how long the tick takes.

Concretely: a product on the default 300s record clock whose ticks run ~60s has `stale_cell`'s real threshold at `2*(300+60)=720s`, but the snapshot's header carries `stale_after_s=600`. `asf status --line` would call the table `· STALE` up to two minutes before `asf status`'s own `Stale` row agrees — the exact "two definitions of stale" D4 calls the bug. No test in this diff pins the specific `stale_after_s` value (only that the header matches `stale_after_s=\d+`), so this did not surface in the Gate.

Fix: use the same function `stale_cell` uses, not `_record_period_s` alone —
```python
def snapshot_text(root, product, cfg=None, now=None, stale_after_s=None):
    now = now or datetime.datetime.now(datetime.timezone.utc)
    last = _last_record_tick(root, product)
    horizon = int(stale_after_s if stale_after_s is not None
                  else _stale_after_s(product, last[1] if last else None))
    ...
```
