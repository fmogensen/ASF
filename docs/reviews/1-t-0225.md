- `asf/budget.py:47-51` — `Budget.source`'s split between `'default'` and `'product'` compares the
  *pair* `(sessions, usd)` against the global defaults as a whole, not per measure. If a product
  overrides only one of the two keys (e.g. `usd: 20`, `sessions` left at the default 3), the
  result is `source='product'` even though the tighter, actually-binding measure (`sessions`) is
  still the default. The plan's step 5 reading — "`source` is whichever of default/product/item
  set the measure that is **lowest**" — is genuinely ambiguous from the prose alone, and no
  acceptance test (T2, or this Task's own tests) exercises the product-vs-default distinction, so
  this isn't a proven defect against anything fenced. Worth settling before Task 6 writes the
  groom line that reads `Spent.budget.source` to print `(product default)` / `(product override)`
  / `(item)` — a single-measure product override could then print a source that doesn't match the
  measure actually named in the line.
