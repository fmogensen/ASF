## C — must change

1. **`asf/groom/inbox.py:79-85` — `_UNKNOWN_HEADER_RE` also eats the first line of a body that
   happens to look like `word: value`, when that line follows the header block with no blank
   line in between.** This is the exact failure the card is about — a line silently dropped,
   without a word — now on the body side instead of the header side, and it is not a contrived
   case: the existing test `test_bug_card_is_minted_with_its_signature_and_shape_line`
   (`tests/test_inbox_shape.py:349-353`) already relies on a body starting immediately after
   the last header with **no** blank line, which is exactly the shape this bites:

   ```python
   from asf.groom import inbox
   text = ("# Title\nparent: E-0001\n"
           "Note: this is body text right after headers, no blank line.\nMore body.\n")
   c = inbox.parse_inbox_file(text)
   # on origin/main:  c.description == 'Note: this is body text right after headers, no blank line.\nMore body.'
   # on this branch:  c.description == 'More body.'   -- the "Note:" line is gone
   ```

   A URL is enough to trigger it too (`https://example.com/foo is where it broke` matches
   `^[A-Za-z][\w-]*:\s*.*$` on `https:`), which is a plausible first line of a bug report pasted
   straight after the headers.

   Fix: an unrecognized header-shaped line should only be skipped while still inside a
   contiguous run of header-shaped lines from the top of `rest` — i.e. stop treating
   `word: value` as "more header" as soon as one recognized header (`INBOX_KV_RE` match) has
   already been followed by a blank line, or more simply: only apply `_UNKNOWN_HEADER_RE` while
   `body_start` has not yet been set by a blank-line-free run that has closed. A minimal
   version: track whether the header block has already ended by a blank line since the last
   match, and once it has, treat the next unmatched line as body regardless of its shape. Add a
   test asserting `test_bug_card_is_minted_with_its_signature_and_shape_line`'s own fixture shape
   — a `word:`-shaped first body line with no blank line before it — keeps that line.
