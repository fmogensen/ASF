## C — must change

1. **`asf/cli.py` — half the card is unbuilt: there is no `asf watch`.**
   The Description names two symptoms, *"no per-tick digest, no asf watch,"* and the branch
   closes only the first. `grep -n "watch" asf/cli.py` is empty; no subcommand, no docs, no test
   mentions it anywhere in the tree (`grep -rn "asf watch" .` outside this review file is empty
   too). Either build it here, or — if it is deliberately a separate follow-up — say so: split
   the card's Description/Task so a later round does not read this as forgotten, and file the
   `asf watch` half as its own item so it is tracked.

2. **`asf/tick/summary.py:174` — the digest reports counters that are never set.**
   `digest()` reads `ctx.counts` verbatim (`did = ', '.join(f'{name} {n}' for name, n in
   (counts or {}).items() if n)`), and `ctx.counts` is seeded with five keys at `tick.py:158`
   (`launches, merges, stalls, refusals, relaunches`). Only two of the five are ever
   incremented anywhere outside a test: `launches` at `asf/tick/step_wave.py:389`, `stalls` at
   `asf/tick/step_health.py:163`. `grep -rn "counts\['merges'\]\|counts\['refusals'\]\|counts\['relaunches'\]" asf/`
   (excluding tests) returns nothing. Concretely: a tick that harvests and merges three PRs, or
   refuses an approval, or relaunches a stalled session, still prints `nothing launched, merged
   or stalled` whenever `launches` and `stalls` both happen to be zero that tick — the exact
   blind spot this card exists to close, now wearing a label that says it is fixed. This
   predates the branch (`tick.py:158` is unchanged since `66df9bf8`, 2026-09-21), but the digest
   is built directly on top of it and ships anyway; either wire the missing increments (harvest
   merge, approvals refusal, relaunch) before this lands, or have `digest()` name only the
   counters that are actually tracked so the line it prints does not claim more than the code
   knows.

3. **`run_tests_b0087.log` — a stray, empty debug artifact is now in the tree.**
   Added 0 bytes in `2d83057` ("the session ended with this uncommitted — committed by the
   factory"). It carries no test output, no relation to the fix, and does not belong at the repo
   root. `git rm run_tests_b0087.log`.
