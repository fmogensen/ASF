## I — noted, not blocking

1. **`asf/briefs/templates/delivery-code.md:6` renders `<kind>(<id>): <what>`; the spec's fenced
   block at `docs/specs/f-0102.md:328` literally reads `` `<kind>({id}): <what>` `` — curly, not
   angle, braces around `id`.** Copying that byte-for-byte would make `{id}` a template
   placeholder with no matching `context()` key (`build.py` has `item_id`/`feature_id`/`epic_id`,
   never a bare `id`), which `test_every_template_placeholder_is_a_context_key` and
   `test_an_unknown_placeholder_is_an_error_not_an_empty_string` would both catch. The angle
   bracket the branch actually shipped is consistent with the surrounding `<kind>`/`<what>` in
   the same example and with every other descriptive placeholder in both templates (`<title>`,
   `<the globs …>`), so this reads as a spec typo the writer correctly did not transcribe — but
   the spec itself is worth a one-character fix so a future byte-for-byte copy does not have to
   rediscover this.
