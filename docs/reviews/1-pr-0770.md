## I list

- `asf/connectors/command.py`'s `CommandConnector.__getattr__` turns any non-underscore attribute into a callable operation, including a typo'd one (e.g. `.pr` vs `.prs`); a caller mistake surfaces as a runtime Unknown (or a command run with the wrong `op`) rather than an `AttributeError` at the call site. Harmless today since callers only ever go through the `Forge`/`Quota`/`Secrets` Protocol methods, but worth a comment or an allow-list if a fourth connector kind grows a wider surface.
- Timeout defaults are scattered and inconsistent across the three command forms with no shared constant: `command.py`'s generic bridge defaults to 120s, `secrets.py`'s `CommandSecrets` to 30s, `workers/quota.py`'s `CommandQuotaSource` (unchanged by this PR) to 60s. Each is documented at its own call site, so this is cosmetic, not a behavior risk.
- `connectors.problems()` is the only thing that catches a `connectors.<kind>: command` written without a `command:` key (e.g. `connectors.forge: command`) — `build()` will otherwise happily construct a `CommandConnector` with an empty command that is Unknown on every call. That's fine for this stack (doctor's wiring to `problems()` is PR 5 of 5), but worth keeping in mind until that PR lands.
