This is not a drop-in one-liner as the plan states it, though: `publish_args` is also splatted into `mechanical.publish_worktree(product, wt, branch, ev.remote_sha, declared=declared, **publish_args)` at `health.py:514-515`, and `asf/harvest/mechanical.py:291-292`'s `publish_worktree(product, wt, branch, remote_sha, main='main', protected=None, push_timeout_s=None, declared='')` has no `conv` parameter — it only forwards `push_timeout_s` to `lifecycle.publish` at `mechanical.py:303-304`. Whoever picks this up needs either a `writes:` correction that adds `asf/harvest/mechanical.py` to this card (threading `conv=` through `publish_worktree` too) or a documented decision to keep `health.py`'s non-mechanical branch on `push_timeout_s=` and accept that `OneResolverTests` cannot go green until `mechanical.py` is swept — the current branch does neither, it just leaves the old call in place.
