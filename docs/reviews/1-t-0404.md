## C (blocking)

- **asf/install.py:283, asf/install.py:326** — both docstrings write the literal string
  `tools/install.sh`, which `tools/check_conventions.sh` forbids for every file under `asf/`
  except the four named exemptions (`asf/install.py` is not one of them; the module already
  works around this everywhere else, e.g. `INSTALL_TOOL = os.path.join('tools', 'install' + '.sh')`
  at asf/install.py:27). Fails the Gate's `bash tools/check_conventions.sh` and
  `tools.test_conventions.CheckConventionsScriptTests.test_the_whole_package_is_clean` inside
  `python3 tools/run_tests.py`. Fix: reword both docstring lines to not spell the path literally
  — e.g. "the bootstrap script's own `doctor_reds`" and "`scheduler_install_verified`, the
  bootstrap's own retry, behaviour intact" — the way the rest of the module already refers to it
  by name (`INSTALL_TOOL`) rather than by literal string.

## I (non-blocking)

- `_clock_labels` (asf/install.py:307-312) catches `scheduler.SchedulerError` and returns `[]`,
  but by the time it's called, `_step_scheduler` has already called `scheduler.cmd_scheduler`
  with the same product, which itself raises through the identical `clocks(product)` call and
  returns 2 on that error (asf/scheduler.py:830-835) — caught earlier by the `rc not in (0, 3)`
  check, so `_clock_labels` never actually reaches a product whose `clocks()` raises. Dead
  defensive code; harmless, but worth a comment or removal.
- `tests/test_install.py`'s new `_publish` helper (tests/test_install.py:35-47) duplicates
  `tests/test_sample_product.py`'s own git-fixture helper, as the docstring itself notes. Not
  worth a shared module for one duplicated helper, but flag it if a third caller shows up.
