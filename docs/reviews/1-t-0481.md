## C (blocking)

- `asf/workers/lifecycle.py:1913-1914` — `card_fingerprint(product, item_id, items)` returns a
  real digest, not `''`, when `item_id` is truthy but absent from `items` ("an unknown id" —
  plan step 8, docs/plans/f-0126.md:449). Fix: extend the early return to
  `if not item_id or items is None or item_id not in items: return ''` (or normalize through
  `asf.feeder.rows.items_of` first if `items` may still be a raw `index.json` dict at a call
  site, then check membership on the normalized map). Add the missing case to
  `tests/test_lifecycle.py`'s `test_card_fingerprint_is_empty_for_none_items_or_no_id`
  (:1075-1080): `self.assertEqual(lc.card_fingerprint(product, 'T-9999', items), '')` where
  `'T-9999'` is not a key of `items`.

## I (non-blocking)

- `asf/workers/lifecycle.py:1933` — `blocked_park`'s printed line is
  `f'parked {item}: {reason}'`, but plan step 3 (docs/plans/f-0126.md:417-419) says "the line is
  `f'parked {branch}: {reason}'`, the shape every other park in `hold` prints." Both the plan's
  and the spec's own `blocked_park(question, item, card, now)` signature carry no `branch`
  parameter, so the plan's own sentence cannot be implemented literally as written — this reads
  as a copy-paste of `hold`'s convention rather than a considered instruction for a function that
  only has `item`. Worth a one-line operator confirmation on whether `blocked_park` should gain a
  `branch` parameter (health.py has `s.get('branch')` at the call site) so a parked run's log line
  matches `hold`'s shape, or whether `item` is the intended identifier here since a park is
  reported per-item, not per-branch, elsewhere in this file (e.g. `park_text`, `loop_text`).
  Untested either way, so nothing currently depends on the exact wording.

  `step_wave.stale_briefs` (the precedent step 2 cites) imports `importlib` once at module scope
  and only defers `importlib.import_module('asf.briefs.build')` into the function body (to dodge
  the circular import). Functionally identical; a module-level `import importlib` in
