## I — would change, will not block

- **I1 — `asf/harvest/lane.py:1533-1535`: the line says `merged` before anything has merged.**
  It is printed *before* the retry runs, so a `gh` that rejects `--subject` **and** refuses the
  method logs a landing that never happened. Reproduced on this head with a `gh` that answers
  `unknown flag: --subject` to the flagged call and `Squash merging is not allowed on this
  repository` to the retry: the lane logged
  `plan/F-0001: merged without --subject — this gh does not know the flag` **twice** — once for
  `--squash` and once for `--merge`, since `'not allowed'` continues the loop — and `merge()`
  then returned `(None, 'Squash merging is not allowed on this repository')`. Two false landing
  lines and a refusal, in that order. The fix is one move: log after `if rc == 0:` on the retry,
  or word it as the attempt it is — `f'{branch}: retrying the merge without --subject — this gh
  does not know the flag'`. The latter is one word and keeps the line where it is.
- **I2 — `asf/harvest/lane.py:1527,1533`: nothing in the suite pins either new guard.** Mutation
  run against
  `tests.test_harvest.ProductHarvestTests.test_a_gh_that_does_not_know_subject_still_lands_the_doc_lane`,
  the only test on this path: `H._gh(args[:-2])` → `H._gh(args[:-1])` goes **red**
  (`rc=1 FAILED (failures=1)`), so the positional strip is pinned; but reverting `:1527` to the
  pre-head condition `if subject and _rejects_subject(err):` stays **green** (`rc=0 OK`), and
  `grep -rn "merged without" tests/` returns nothing, so the degrade line is unpinned too. Both
  are the commit's own new code. The guard is the conjunct that makes `args[:-2]` sound — without
  it a `--rebase` whose error text happens to name `--subject` would strip `--delete-branch` and
  the method itself — so it deserves the assertion its sibling has. Two lines on the existing
  test: assert the retry's args equal the flagged args minus the last two, and assert the lane's
  output carries the degrade. I filed this as an I and not a C because the guard is present and
  correct at this head; what is missing is the test that would keep it there.
