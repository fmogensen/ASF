## C list

- C1 — `asf/doctor.py:508,511` (`check_savings`): `savings = getattr(conv, 'savings', None) or {}`
  guards only `None`/falsy, then `for key, value in savings.items()` assumes a dict. `savings` is
  not in `conventions.MAP_CONVENTIONS`, so nothing upstream ever rejects or reshapes a
  non-dict `conventions.savings:` (PD13 says exactly this: "the doctor row of §2.9 is the check
  that a product's `savings:` keys are real"). A product yaml that writes `conventions: {savings:
  yes}` (or any scalar/list) makes `Conventions.savings` that same non-dict value, and
  `check_savings` raises `AttributeError: 'str' object has no attribute 'items'`, taking down
  `doctor.run()` for the whole product (reproduced live, see the "every Step" row above) instead
  of printing the red finding the Task exists to give the operator. Fix: guard the shape before
  iterating, e.g. `savings = getattr(conv, 'savings', None); savings = savings if
  isinstance(savings, dict) else {}`, and emit a red finding naming the bad shape (mirroring how
  `Conventions.map_of()` already handles this for `MAP_CONVENTIONS` members) rather than silently
  falling back to `{}` — the whole point of this Task is that a misconfigured `savings:` is told
  to the operator, not read as the default or crashed on.
