# F-0069 — the sensitive diff is read before the expensive round, and the host's own alarms become Bugs

This factory has three security guards today and each one guards something other than what this
card asks about. `asf/redact.py` scans a *commit* for a secret shape and refuses the push (F-0075),
so a session cannot publish a token it typed itself. `approvals.touch_security` classifies a *tool
call* — an edit of `.env`, a `gh secret`, a `core.hooksPath` write — and holds it for a human
(`asf/approvals.py:133-146`). `asf/customer_content.py` reads a *diff* against a path class and
sends the branch back. Nothing reads a diff for a security defect: a session may add a route with
no authentication check, a billing path that trusts a client amount, a connector that logs a bearer
token, and the only thing between that and the trunk is a general review that was asked whether the
diff stays inside `writes:`.

The second half is worse, because the information exists and nobody reads it. The code host runs
secret scanning and dependency alerts on this repository every day. Those alerts sit in an API
nothing in `asf/` has ever called: a leaked credential is known to the host and unknown to the
factory until a person opens a web page. Which is the third item's failure exactly — on
**2026-09-13** a scanner reached an end-to-end database through a publicly reachable port and
dropped it. Nothing probes a box from outside, so the port was open for as long as it took someone
to find it.

The first of the three checks is mostly already being built. F-0060 — Active, planned, its grammar
module landed — is *the mechanical pass that reads a code branch before the expensive review*: a
`PRECHECK` lane state in front of `REVIEW`, a cheap `precheck` session per level, a four-column
findings table on the branch, and a bounce on exactly one condition — a `fail` row at `high`
confidence (`asf/precheck.py:18-19`, `docs/specs/f-0060.md:289-345`). That is this card's first
item, sentence for sentence, minus the one thing F-0060 has no reason to know: which paths are
sensitive, and what a reader owes each of them. So this Feature does not build a second pass in
front of the first. It teaches the one that exists about path classes, and then builds the two
checks that have no home at all:

1. **the pass, given security dimensions** (§2.2–§2.5) — a configured path class the diff touches
   adds its own required row to the precheck's table and floors the level; a class touched makes
   the pass mandatory even where the product waived it. The bounce, the correction kind, the
   adjudicate escape and the "cheaper than the round it precedes" guarantee are F-0060's and are
   not re-decided.
2. **the host's alerts as a rule check** (§2.6–§2.8) — one check reading secret-scanning and
   dependency alerts, one Bug per alert, S1 for a secret and S2 for a dependency, keyed on the
   alert.
3. **an exposed-port probe** (§2.9) — nightly, run on a runner (a connect from the tick host proves
   nothing about what the internet reaches), against every CI box and every machine the operator
   lists, for the common database and daemon ports. Every open port is an S1, and so is a box the
   probe could not reach.

All three land as rule cards with check scripts, in the core `rules/` directory F-0061 designed and
nothing has yet created.

## 1. Decisions

### 1.1 In

- **`conventions.security`, one block, three parts** (§2.1). `paths: {<class>: [globs]}` — the
  class names are the product's (`auth`, `billing`, `mail`, `connectors`, `secrets`,
  `ci_credentials` are what this card names and what the guide documents; the code knows none of
  them); `alerts: {max_age_h}`; `ports: {boxes, ports, workflow, artifact, max_age_h}`. Validated
  in `conventions.validate_mapping`, defaults in `conventions.py`, documented in
  `docs/products.example.yaml`. Unset, nothing is sensitive and no check violates — the "unset
  means nothing is checked" rule `customer_content` already has.
- **`asf/security/paths.py`** (§2.2) — `classes(conv)`, `touched(conv, files) -> {class: [file]}`,
  `describe(hit)`. The glob matcher is `customer_content.matches`, imported, not copied.
- **Security dimensions in `asf/precheck.py`** (§2.3) — `SECURITY_DIMENSIONS`, the three standing
  rows; `class_dimension(name)`, the one row a touched class owes; `security_dimensions(hit)`, the
  tuple for a diff. `dimensions`, `covered`, `faults` and `render_table` each take one new
  `security=()` argument, and with it empty they are byte-identical to F-0060's. `level_for` takes
  `security=False` and floors the level at `HIGH`: a sensitive diff is never read at `LOW`.
- **The lane makes it required** (§2.4) — `branch_facts` gains `f['security']`; the level and the
  faults are computed with the security tuple, so a table missing a class's row is an *incomplete*
  precheck, which F-0060's `Tq` already re-asks for; and `Tq` fires for a branch touching a class
  even when `conventions.review.precheck` is `none` and even when the landing class is `docs` (a
  workflow file is a docs-class diff by size and `ci_credentials` by content). That override is the
  card's "runs as a required check for every pull request touching …".
- **The precheck brief learns the classes** (§2.5) — `context()` gains `security_classes` and
  `security_files`; `templates/precheck.md` gains one `{security_section}` block, empty for a diff
  that touches nothing; `precheck_table` is rendered with the security rows appended.
- **`asf/security/alerts.py`** (§2.6) — `Host` with `secrets()` and `dependencies()`, a
  `GitHubHost` over `gh api`, an atomically written cache under `state/<product>/security/`, and
  `violations()`: one line per open alert, plus one line when the feeds cannot be read and the last
  good read is older than `alerts.max_age_h` — a blind check is a violation, never a pass.
- **Per-line `sev=` and `sig=` fields on a violation line** (§2.7) — `rules.py`'s check contract
  gains two optional trailing fields and `file_bugs.rule_violation_signatures` reads them: `sev=`
  is that place's severity, `sig=` makes the place its own Bug. A line carrying neither behaves
  exactly as today: one Bug per rule, S2.
- **`asf/security/ports.py`** (§2.9) — `probe()` (one TCP connect per target, injectable
  connector), `dispatch()` (the nightly `gh workflow run`, one new part of the daily step),
  `latest()` (the newest successful run's artifact through two `gh` calls), `violations()` (one line
  per open port, per unprobed box, and one when the newest probe is older than `ports.max_age_h`).
- **A box's address is never written down** (§2.9, D11) — the probe's targets reach the runner as a
  repository secret the operator sets once; every line this Feature prints, files or commits names
  the box *label* and the port, and so does the artifact.
- **`rules/` with three cards and three scripts** (§2.8) — `README.md`, `R-0008.md`–`R-0010.md`,
  `r0008.sh`–`r0010.sh`, in the layout and the reserved band F-0061 §2.1 specifies, created by
  whichever of the two Features lands first (P13).
- **`asf security`** (§2.8) — one parser, four subcommands: `paths` (what a branch touches),
  `pass --check` (R-0008), `alerts --check` (R-0009), `ports probe|dispatch|--check` (R-0010).
- **`asf doctor` gains a `security` row** (§2.10) — a product with a repo and no `security.paths`;
  a record with no adoption card for a core check; a stale alert feed; a stale, absent or partial
  probe; a configured box with no address.
- **The guide** (§2.11) — `docs/guide/security-checks.md`: the block, the three cards, the probe
  workflow job to paste, and the one-line `tools/checks/` shims a product's record needs.

### 1.2 Out

- **No second pass, no new lane state, no new brief kind, no new correction kind.** F-0060 owns
  `PRECHECK`, `precheck`, `KIND = 'precheck'`, the occupancy bucket, the feeder row, the model
  table row and the adjudicate escape. This Feature adds dimensions, a level floor and one
  override to a gate that is being built; a `security` state beside `PRECHECK` would be two passes
  in front of one review, each able to bounce, with two loop guards over one head.
- **The pass does not run under `asf-security`.** `roles.BINDINGS` binds a role to a *kind*
  (`asf/roles/roles.py:45-56`), so a role chosen per row is a launch-path change, and
  `roles.UNBOUND` keeps its entry for `asf-security` with its reason. What the sensitive precheck
  gets instead is the attack framing in its brief section (§2.5). Binding the role is a card of its
  own, and it is named here so its absence is not read as an oversight.
- **No new approval class, and no change to the matrix.** `touch_security` keeps its globs, its
  commands and its `human-now` level. It classifies a call a session *makes*; this reads a diff a
  branch *carries*. Both on the same paths is the intent: F-0061's "the hook prevents, the check
  reports".
- **No host-side required check, and no branch protection.** "Required" means the factory's gate
  refuses to land without it, not a context in the code host's branch protection. The lane is what
  merges (`asf/harvest/lane.py:3198-3208`); a protection rule is an operator setting this Feature
  neither reads nor writes.
- **No secret scanning of our own.** `asf/redact.py` already scans every commit and every unpushed
  range at the push, and the host scans the pushed branch against a provider list no local regex
  set matches. R-0009 reads the host's answer; it does not become a second scanner. What it adds is
  the coverage F-0075 structurally cannot have: a commit pushed from outside the factory, and a
  credential that is only a credential because the provider says so.
- **No port is closed here, and nothing is reconfigured.** The probe reads and files an S1 naming
  the box and the port. Shutting a port is an operator action on a machine, and `ci_pool.apply`'s
  "dry run by default, a person applies" is the precedent.
- **No port scan of anything not listed.** The target list is the union of `ci.pool` boxes and
  `security.ports.boxes`; a label with no address in the operator's secret is *reported as
  unprobed*, never discovered, never guessed, never ranged.
- **No new metrics stream.** `metrics.STREAMS` is a closed, schema-validated set. The alert cache is
  operator state; the Bugs are the record's, filed on the one path `asf file-bugs` owns.
- **`rules.py` keeps its line contract.** `sev=`/`sig=` are optional trailing fields on an
  otherwise unchanged line: no JSON mode, no per-card severity field, no second filing route.
- **Nothing is added to `asf/reviews.py`.** F-0053's table module has no caller in the tree
  (P12) and the pass's grammar is `asf/precheck.py`'s four-column one. Two grammars for one pass is
  what F-0060 D8 already refused.

## 2. The design

### 2.1 `conventions.security` — the one block

```yaml
conventions:
  security:
    # (1) the path classes. The names are yours; the globs are matched as customer_content's are
    #     (a trailing / is a prefix, else fnmatch, and * crosses /).
    paths:
      auth:           [apps/api/auth/**, asf/approvals.py, asf/hooks.py]
      billing:        [apps/api/billing/**]
      mail:           [apps/api/mail/**]
      connectors:     [apps/api/connectors/**]
      secrets:        [asf/redact.py, "**/*.env.example"]
      ci_credentials: [.github/workflows/**, asf/ci_pool.py]
    # (2) the host's alert feeds
    alerts:
      max_age_h: 24        # a feed unread this long is a violation, not a pass
    # (3) the exposed-port probe
    ports:
      boxes: [plane-1]     # machines beyond ci.pool's own boxes; every ci.pool box is included
      workflow: security-ports.yml
      artifact: security-ports
      max_age_h: 30        # nightly, plus slack
      # ports: unset takes DEFAULT_PROBE_PORTS
```

`asf/conventions.py` gains the documented constants — `DEFAULT_ALERT_MAX_AGE_H = 24`,
`DEFAULT_PROBE_MAX_AGE_H = 30`, and `DEFAULT_PROBE_PORTS`, the common database and daemon ports
with the daemon named beside each: 445 (smb), 1433, 1521, 2049 (nfs), 2375, 2376 (docker), 2379
(etcd), 3306, 3389 (rdp), 4369 (epmd), 5432, 5672, 5900 (vnc), 5984, 6379, 6443 (kube-apiserver),
7000, 8086, 9000, 9042, 9092, 9200, 9300, 10250 (kubelet), 11211, 15672, 27017, 27018 — plus
`security_paths()`, `security_alerts()` and `security_ports()` readers off `map_of('security')`,
each defaulting on a malformed value the way `review_skip_under_lines()` does.

One block in `validate_mapping`, beside `customer_content`'s (`:403-421`): `security` must be a
map; `paths` a map of name → path list (`_path_list_problem` each); `alerts.max_age_h` and
`ports.max_age_h` positive numbers; `ports.ports` a list of integers in 1..65535; `ports.boxes` a
list of non-empty labels; `ports.workflow` and `ports.artifact` non-empty strings. There is no
`pass_pattern` here: the pass's file is F-0060's `precheck_pattern` (P8).

### 2.2 `asf/security/paths.py` — which classes a diff touches

```python
def classes(conv):
    """``{class: [glob]}`` from ``conventions.security.paths`` ({} = nothing is sensitive)."""

def touched(conv, files):
    """``{class: [file]}`` — the files among ``files`` under each class's globs, classes with
    none left out, class names in configuration order. The matcher is
    :func:`asf.customer_content.matches`."""

def describe(hit, limit=SHOW_HITS):
    """``auth: a.py, b.py · billing: c.py`` — for a lane line, a brief and a violation line."""
```

Three functions, no I/O; `SHOW_HITS = 10` and the cap-with-a-count convention from
`customer_content.describe`. A file in two classes is listed under both: the pass owes a row per
class, and a diff that is both auth and billing is exactly the diff that needs both read.

### 2.3 `asf/precheck.py` — the dimensions a sensitive diff owes

Additive, and with `security=()` every existing caller's answer is unchanged:

```python
#: The rows any diff touching a sensitive class owes, whatever the class.
SECURITY_DIMENSIONS = (
    'the diff adds no new trust in a value that comes from outside the process',
    'nothing the diff adds weakens or removes an existing check, guard or hook',
    'no secret value appears in the diff, a fixture, a test or a log line it adds',
)
#: The row one touched class owes. The class name is the product's; this sentence is not.
CLASS_DIMENSION = ('{name}: every path the diff adds or changes here enforces what the code '
                   'around it enforces, and the attack an outsider would try is named')


def class_dimension(name):
    """:data:`CLASS_DIMENSION` for one class name."""


def security_dimensions(hit):
    """The dimensions a diff touching ``hit`` (``{class: [file]}``) owes: one per class, in the
    order the configuration named them, then :data:`SECURITY_DIMENSIONS`. ``()`` for ``{}``."""

    """The level's cumulative list, then ``security`` — LOW's first, the classes last."""


def covered(rows, level, security=())     # the uncovered names, security ones included
def faults(text, level, security=())      # + one `dimension not covered: "<name>"` per class row
def render_table(level, security=())      # the skeleton the brief carries, security rows appended
def level_for(size_class, changed_lines, max_lines, security=False):
    """``(level, why)`` as today, floored at :data:`HIGH` when ``security`` — a sensitive diff is

    ``size class small, floored by sensitive paths``."""
```

Nothing else in the module moves: the grammar, `blocking`, `keys`, `findings` and the four-column

### 2.4 `asf/harvest/lane.py` — the pass becomes required

### 2.7 `sev=` and `sig=` — a place's severity, and a place as its own Bug
