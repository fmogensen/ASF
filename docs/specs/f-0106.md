# F-0106 — a Task the trunk already carries is closed by trunk, and an `after:` nobody can answer is never silently dropped

On 2026-09-23 23:09–00:15 three coder sessions ended `empty branch: nothing to land`. None was a
coding failure; each was a plan the factory accepted without asking the trunk anything:

- **T-0083** (F-0095) duplicated T-0076, whose work was on `main` at `dff2286`. **T-0084** (F-0095)
  named a change — `EMPTY_CAP`, `empty_ends`, `park_text`, `EmptyEndsTests` — that was already on
  `main` at `989b775`. Both were minted `New`, both got a seat, both coders found the surface there
  and wrote nothing.
- **T-0071** (F-0028) carried `after: T-14651` — an id from a session's reserved five-digit block
  that was never minted. The order hotfix `ea6b09e` could not resolve it, so it **dropped it**, and
  T-0071 launched before the work it names existed. The F-0023 plan commit `dfe10fe` names the same
  class: reserved five-digit ids `asf check` does not accept.

Three launches, three holds, three correction rounds, for three facts a single `git` question would
have answered. The operator's direction on 2026-09-23 is speed and cost first.

This card is: **the trunk is asked before a Task is minted and again before its coder launches, and
an `after:` the record cannot answer is either mapped onto the plan's own Tasks or sent back to the
plan session — never dropped.**

### The choices

| # | Chosen | Against | Why |
| --- | --- | --- | --- |
| C1 | **The minting step, not the plan review.** | A plan reviewer asked to check the trunk. | The card allows either. A reviewer is a session reading a document: it can be talked out of a finding, it costs a launch, and it answers once. The minter runs every tick, costs nothing, and cannot be persuaded. P5 puts it at exactly the point where a plan section becomes a card, which is the last moment the answer is still free. |
| C2 | **The predicate is the tests the Task's own section names, checked against `origin/<main>`.** | Comparing `writes:` sets against a landed sibling's; diffing the Task's Files block against the trunk. | It is what both observed cases carried: T-0084's whole change *was* `EmptyEndsTests` and three names beside it, and a duplicate Task copies its twin's Acceptance block verbatim (T-0083 ↔ T-0076). A `writes:` comparison cannot work — Task 2 of a plan legitimately writes the same file Task 1 landed, so identical footprints prove nothing. Naming a test that already exists on the trunk, on the other hand, is the plan saying *the thing I am asking for is already there*. |
| C3 | **A test **id** — a class or a function — is evidence; a bare file path is not.** | Accepting `tests/test_feeder.py` as "the acceptance is on main". | Every Task in this product writes a test file that already exists. A Task whose acceptance is only `tests/test_feeder.py passes` names nothing new and nothing old; treating it as satisfied would close real work. The node name is the falsifiable half. |
| C4 | **At least one test id, every one of them on the trunk, and every non-glob `writes:` path already in the trunk tree.** | Any-of; a majority; the ids alone. | Three timid guards, each with the same default: **when the answer is not certain, nothing closes.** No test id → no answer. One id missing from the trunk → the Task has work to do. A `writes:` path the trunk does not have → the Task creates a file, which is by definition not already there. A false close costs a Task's work; a false open costs one seat, which is what the factory spends today anyway. |
| C5 | **A closed-by-trunk Task is minted `state: Closed` **and** typed `landed: <sha>`.** | `state: Closed` alone (P11's `sticky` would hold it); `landed:` alone. | `state: Closed` is what the *same tick* needs: `do_index` runs after `plan-tasks` in the same record step, and the wave that follows plans off that index — a Task left `New` for one tick is a seat spent. `landed: <sha>` is what every *later* tick needs: it is the reason, in the record, in the field the record already defines for it (P9), and it makes the close derive from a rule instead of from `sticky`'s "held Closed; planned would say New". |
| C6 | **`closing.Ev.landed` is wired in `ingest`'s task loop, with `_green_after` answering the green half.** | Leaving P8's rule dead and relying on `sticky`. | The card requires the sha to be recorded and to mean something. One keyword and one `green` line make `reconciled` decide it by name. The green half is `_green_after` (P12), the same call the Bug loop makes: `True` for a product with no CI, else a green run at or after the sha. |

## The design

### §1 `asf/record/trunk_check.py` — the one question, asked once

```python
"""asf.record.trunk_check — is this Task's work already on the trunk? (F-0106)

Three coder sessions on 2026-09-23 ended `empty branch: nothing to land` because a plan cut Tasks
whose work was already on `main`: T-0083 duplicated T-0076 (landed at dff2286), and T-0084 named a
change — EMPTY_CAP, empty_ends, park_text, EmptyEndsTests — that was on main at 989b775. Nothing
between the plan landing and the coder's seat asked.

The predicate is the tests the Task's own section names (C2): a plan copies the spec's fenced
acceptance into every Task, so a Task whose named tests are *already* on the trunk is a Task
asking for work that is there. Timid by construction — every uncertain answer is None:

  * no test id named           -> None (nothing to check is not evidence)
  * a test id not on the trunk -> None (the Task has work to do)
  * a `writes:` path the trunk tree does not carry -> None (the Task creates a file)

A bare file path is not a test id (C3): every Task writes a file that already exists; only a class
or function name is falsifiable.

Two callers: `plan_tasks` (the mint) and `tick.step_wave.trunk_preflight` (the seat). They must
agree, or the factory refuses to launch a Task the minter was happy to mint — which is why the
predicate is one function and not two.
"""
import re

#: ``tests.test_empty_ends.EmptyEndsTests`` / ``…EmptyEndsTests.test_cap`` — the unittest form the
#: product's own acceptance blocks use (`python3 -m unittest -v tests.test_x.Klass`).
DOTTED_RE = re.compile(r'\btests\.(test_[a-z0-9_]+)((?:\.[A-Za-z_][A-Za-z0-9_]*)+)')
#: ``tests/test_empty_ends.py::EmptyEndsTests[::test_cap]`` — the pytest form.
PATH_RE = re.compile(r'\b(tests/[\w/]*test_[a-z0-9_]+\.py)((?:::[A-Za-z_][A-Za-z0-9_]*)+)')
#: a definition of ``node`` in a python blob: the falsifiable half of a test id (C3)
DEF_RE = '^[ \t]*(?:class|def)[ \t]+%s\\b'
GLOB = set('*?[')
CAP = 8   #: at most this many test ids are read — the cost ceiling on one Task's question


def test_ids(text):
    """``[(path, node), ...]`` — every test id ``text`` names, in first-seen order, at most
    :data:`CAP`. ``node`` is the last component: a class, or a method. A bare ``tests/x.py`` with
    no ``::node`` yields nothing (C3)."""
    out = []
    for m in DOTTED_RE.finditer(text or ''):
        out.append((f'tests/{m.group(1)}.py', m.group(2).strip('.').split('.')[-1]))
    for m in PATH_RE.finditer(text or ''):
        out.append((m.group(1), m.group(2).strip(':').split('::')[-1]))
    seen, uniq = set(), []
    for pair in out:
        if pair not in seen:
            seen.add(pair)
            uniq.append(pair)
    return uniq[:CAP]


def satisfied_on_trunk(product, text, writes, read_ref=None, sh=None):
    """``(sha, subject, why)`` when the trunk already carries every test ``text`` names and every
    concrete path ``writes`` declares — else None. Never guesses: an unreadable ref is None.

    ``read_ref``/``sh`` are injected for the tests; by default they are
    :func:`asf.evidence.evidence.read_ref` and :func:`~asf.evidence.evidence.sh`, both of which
    batch and cache per product (P13)."""
    from asf.evidence import evidence
    read_ref = read_ref or (lambda ref: evidence.read_ref(ref, product=product))
    sh = sh or (lambda cmd: evidence.sh(cmd, product=product))
    main = product.main
    ids = test_ids(text)
    if not ids:
        return None
    blobs = {}
    for path, node in ids:
        if path not in blobs:
            blobs[path] = read_ref(f'origin/{main}:{path}')
        blob = blobs[path]
        if not blob or not re.search(DEF_RE % re.escape(node), blob, re.M):
            return None
    for w in writes or ():
        if not (GLOB & set(w)) and read_ref(f'origin/{main}:{w}') is None:
            return None
    sha, subject = _completing_commit(sh, main, ids)
    if not sha:
        return None
    named = ', '.join(f'{p}::{n}' for p, n in ids[:3]) + (' …' if len(ids) > 3 else '')
    return sha, subject, f'origin/{main} already carries {named}'


def _completing_commit(sh, main, ids):
    """``(sha, subject)`` of the newest commit on ``origin/<main>`` that introduced one of the
    named test ids — the commit that completed the surface the Task asks for. ``('', '')`` when
    git cannot answer, which :func:`satisfied_on_trunk` reads as "do not close"."""
    best = (0, '', '')
    for path, node in ids:
        out = sh(f'git log -1 --format=%H%x09%ct%x09%s -S{node} origin/{main} -- {path}')
        parts = (out or '').strip().split('\t')
        if len(parts) == 3 and parts[1].isdigit() and int(parts[1]) > best[0]:
            best = (int(parts[1]), parts[0], parts[2])
    return best[1], best[2]


def close_by_trunk(root, iid, sha, out=print):
    """Write the trunk's answer onto the card: typed ``landed: <sha>``, and nothing else (C12).
    ``state``, ``evidence:`` and the ``ingest:`` History line are the ingest's keys; the next
    ingest derives ``Closed`` from this sha by ``closing``'s ``reconciled`` rule. Returns True
    when the card now carries it. Idempotent: a card already carrying the sha is not rewritten."""
    from asf.record.core import canonicalize, load_items
    from asf.record.setfield import set_typed
    by_id, _errors = load_items(root)
    canonical, _dupes = canonicalize(by_id)
    rec = canonical.get(iid)
    if rec is None:
        return False
    if (rec['meta'].get('landed') or '') == sha:
        return True
    err = set_typed(rec, {'landed': sha}, writer='trunk-check')
    if err:
        out(f'trunk-check: {iid}: {err}')
        return False
    return True
```

Two things are load-bearing. `satisfied_on_trunk` has **one** `return` that is not `None`, and every
branch before it returns `None` — the timid default is structural, not remembered (C4). And
`close_by_trunk` writes one typed key, so the mint and the preflight write the same fact by the same
call and the ingest owns everything derived from it.

```python
PLAN_ID_RE = re.compile(r'\b([A-Z]-\d{4,})\b')


def plan_own_ids(records):
    """``{id token: task number}`` for an id a plan's own ``### Task N:`` heading or section names
    as its own — a plan that minted five-digit ids for its Tasks and then referred to them
    (F-0023's class). The heading and the section's first three lines only: an id in the prose is
    a reference, not a name."""

    for r in records:

        if not m:
            continue
        head = (r['title'] or '') + '\n' + '\n'.join((r['body'] or '').splitlines()[:3])
        for tok in PLAN_ID_RE.findall(head):
            out.setdefault(tok, int(m.group(1)))
    return out


def derived_after(plan_text, cards, known=None):
    """{card id: [predecessor card ids]} for the cards of one plan (``cards``: {id: meta}).

    Plan Task numbers resolve to their cards. A card id the plan names is first mapped onto the
    plan's own Tasks (:func:`plan_own_ids`); an id that maps to none and that ``known`` does not
    hold is **kept** (F-0106): dropping it is what let T-0071 launch before `T-14651` — an id from
    a session's reserved block that was never minted — existed. The wave answers a kept unminted
    id with a `WAITS ON` row and one `RESHAPE → PLAN` row that says so; a dropped one was
    answered by a coder ending `empty branch`. Dropped still: the card itself and its own parent,
    which would wait for ever.
    """
    from asf.tick.migrate import plan_task_records
    records = plan_task_records(plan_text or '')
    ids = task_ids(records, cards)
    own = plan_own_ids(records)
    out = {}
    for n, preds in task_order(plan_text).items():
        cid = ids.get(n)
        if not cid:
            continue
        parent = (cards.get(cid) or {}).get('parent')
        after = []
        for p in preds:
            if isinstance(p, int):
                p = ids.get(p)
            elif known is not None and p not in known and p in own:
                p = ids.get(own[p])          # the plan's own Task, under a reserved id (C10)
            if p in (cid, parent):
                p = None
            if p and p not in after:
                after.append(p)
        out[cid] = after
    return out
```

```python
def trunk_preflight(ctx, planned, items, out=print):
    """The launching code rows whose Task the trunk already carries — refused, and closed by trunk
    (F-0106). Returns the rows that survive.

    The minting check (:mod:`asf.record.trunk_check`) answers a plan at the moment it lands; this
    answers the seat. Three gaps it and it alone covers: a Task minted before that check existed,
    a trunk that moved between the mint and the seat (a sibling landing the surface), and a Task
    whose own id a trunk commit already names — the fact `landed_shas` was meant to carry and no
    production caller ever passes (P6). Nothing is written but the typed sha (C12); the state and
    its History line are the next ingest's, by ``closing``'s ``reconciled`` rule."""
    from asf.harvest import lane
    from asf.record import stage, trunk_check
    product = ctx.product
    if not product.repo_dir:
        return planned
    root = ctx.record_root()
    kept = []
    for row in planned:
        card = items.get(row.item_id) or {}
        if not (row.launches and row.brief_kind == 'task' and card.get('type') == 'task'):
            kept.append(row)
            continue
        sha = lane.item_on_trunk(product.repo_dir, product.main, row.item_id)
        why = f'a commit on origin/{product.main} names {row.item_id}'
        if not sha:
            found = trunk_check.satisfied_on_trunk(product, trunk_check.card_body(root, card),
                                                   card.get('writes') or ())
            sha, _subject, why = found if found else ('', '', '')
        if not sha:
            kept.append(row)
            continue
        stage.guarded(root, 'trunk-check', trunk_check.close_by_trunk, (row.item_id, sha),
                      product=product, out=out)
        line = f'on trunk {row.item_id:<10} — {sha[:12]}: {why} — closed by trunk, not launched'
        ctx.event('on_trunk', item=row.item_id, sha=sha, text=line)
        ctx.counts['refusals'] += 1
        out(line)
    return kept
```

## Records

- **The Task card** — one typed line, `landed: <40-hex sha>`, above the machine marker, written by
  `trunk_check.close_by_trunk` from either caller and by nothing else. `asf check` already
  validates its shape (P9). It is not a machine key, so no later pass rewrites or drops it (P10).
  A Task the **mint** closes carries it from birth, together with `state: Closed` and the History
  line `- <date>: created (plan <F> — already on the trunk at <sha12>: <why>)`.
- **The Task card's machine block** — written by the ingest, as for every other state change:
  `state: Closed`, `evidence:` ending `rule: reconciled`, and
  `- <stamp> ingest: state New → Closed (a typed landed sha and green CI)`. The wave writes none of
  these (C12).
- **`<record>/metrics/events/<day>.jsonl`** — one `on_trunk` event per preflight refusal:
  `{"kind": "on_trunk", "item": "<id>", "sha": "<sha>", "text": "<the printed line>"}`. The mint
  raises no event: the record step's own printed line and the card it wrote are the trace.
- **The tick's counters** — a preflight refusal increments `ctx.counts['refusals']`, so the tick
  line says how many seats the trunk saved. Nothing increments `launches`, which is the point.
- **stdout** — the record step: one `plan-tasks: <F>: <Tn> is already on the trunk at <sha12>
  "<subject>" — minted Closed (<why>)` per closed Task. The wave: one `on trunk <id> — <sha12>:
  <why> — closed by trunk, not launched` per refusal. The feeder's rows: `WAITS ON <id>` and one
  `RESHAPE → PLAN` line carrying `unminted after: <id> is not in the record — …`.
- **`asf/feeder/rows.py`** — one new module constant, `UNMINTED_AFTER_RECUT`, beside
  `NO_WRITES_RECUT`: the reason string is the contract between the feeder and the reshape brief,
  and it is written once.
- **Nothing is filed.** No Bug for a Task the trunk already carries — that is a fact, not a defect;
  no Bug for an unminted `after:` — the reshape row is the answer, and a Bug would be a second
  queue for the same line. No card changes state anywhere but on the Task itself.
