# F-0125 — adopting the in-flight queue

A product that moves onto ASF does not arrive empty. The first customer arrived with about twenty
open pull requests its previous process had opened: foreign branch names, commits that name no
card, and reviews written in its own convention — a file in the reviews directory ending `(APPROVED)`.
ASF's native landing merges branches ASF's own sessions pushed, whose commits name their item and
whose review is an ASF review file of the head. None of those twenty qualifies. So the product
keeps its old merge machinery running beside ASF (`steps.batch`, a merge-queue script of its own)
until the queue drains, or it strands the PRs — and "until it drains" has no end, because nothing
in the factory counts what is left.

The lane can already do most of this and does not know it. Under `conventions.merge: auto` it
already adopts every open PR on the trunk that no run holds, mints it an id, writes a **synthetic
run line** for it and drives it through the same state machine to the same merge (P4, P5). What is
missing is three things: a way to adopt *named* PRs, deliberately, under any merge mode, and to
attribute each one to the card whose work it is (`merge: auto` is all-or-nothing and gives every
PR a `PR-nnnn` id of its own); a way to accept the product's **own** review form as the review of
those PRs; and a count, so the operator knows when the old batch step can be switched off.

After this change: `asf adopt-pr 412 415 --product acme` writes one adopted run per PR with its
card's id on it; `conventions.legacy_review` names the product's own review glob and its approval
marker, read for an adopted run and for nothing else; the queue drains through the ordinary gate,
with the product's required checks, its approval matrix, `pr_order` and `branches_per_tick`
unchanged; `asf status` carries `Adopted | 7 open` until it is `0`, and `asf doctor` then says
`steps.batch` can go off.

### In

- **`asf adopt-pr <n>… | --all <glob>` `[--item <id>] [--product P] [--dry-run]`** — one adopted run
  line per open PR, through the lane's own `Lane.adopt` (P3), never a second writer of the registry.
- **An item per PR**, derived in a stated order: `--item`, then `conventions.branch_patterns`'s
  `<id>` capture over the head branch and the title, then `match.match_event` (P17). A PR nothing
  attributes is refused by name, and the rest of the invocation still runs.
- **`branch_patterns` promoted from an extra to a declared, shaped convention** (P14, P16), with
  `<id>` and `<slug>` captures — the card's "derived … via the product's `branch_patterns`" — and
  retention's existing glob reading left working unchanged.
- **`conventions.legacy_review: {glob, verdict_regex}`** — declared, shape-checked (P15), default
  `None`, read by the one review reader (P10) **only for an adopted run**.
- **One predicate in the lane for "no factory session wrote these commits"**, covering the adopted
  run as `f['foreign']` covers a `PR-nnnn` one (P6): review always required, no naming or delivery
  refusal, and — the new half — no `BACK`, ever (D6, because of P9).
- **`Adopted` in `asf status`** — `N open` until the queue is empty, then no row at all (P21).
- **One advisory doctor row** (P22) that names `steps.batch` once nothing adopted is still open.
- **The guide's onboarding page**: adopt the in-flight queue, watch it drain, then turn
  `steps.batch` off — plus `legacy_review` and `branch_patterns` in `product-config.md` and
  `docs/products.example.yaml`.

### Out

- **Changing `conventions.merge: auto`.** Its blanket adoption of every open PR (P5) is untouched,
  including the `PR-nnnn` ids it mints. `adopt-pr` is the deliberate, named, card-attributed
  alternative, and it works under `manual` too. A PR `merge: auto` already adopted is adopted
  (D9 makes the second write a no-op).
- **Merging anything from `adopt-pr` itself.** The command writes one registry line per PR and
  exits. Every check, approval, order and cap is the ordinary lane's, on the ordinary tick (P19,
  P20) — which is the whole point of the card: *native* landing drains them.
- **Launching any session on an adopted PR.** No review session, no correction, no adjudication.
  D6 states what a non-approving review does instead.
- **Rewriting a contributor's commits.** No reword, no sign-off repair, no copy-dropping on an
  adopted branch (D5): those exist to fix what a factory session pushed.
- **Reading the product's old review files for anything but an adopted run.** `legacy_review` is
  not a second review format for the factory's own branches; ASF's own form is still the only one
  a session may write, and the existing `<prefix>-review-r<n>.md` fallback (P10) is untouched.
- **Writing to the record.** `adopt-pr` writes no card, no `links.prs`, no state. The attribution
  lives on the run line, which is where every other lane attribution lives (P1, P18).
- **Closing, retargeting or commenting on a PR.** Adoption is a local registry line; the PR is not
  touched until the ordinary lane merges it.
- **A migration.** `branch_patterns` keeps the shape retention already reads (P16); `legacy_review`
  is additive with a `None` default; a registry written before this lands carries no adopted runs
  and every row is absent, not empty.
- **Retiring `steps.batch` for the operator.** The doctor row says it may go; the operator edits
  the product file. An automatic edit of a product's own merge machinery is not the factory's.

## The design

### 1. `conventions.branch_patterns` — a declared key that also names the item

`asf/conventions.py`:

```python
#: ``branch_patterns``: one entry per family of branch names the product uses, read by branch
#: retention (the heads it owns) and by ``asf adopt-pr`` (the item a PR's branch or title names).
#: A pattern is a literal with two placeholders: ``<id>`` an ASF id token (``T-0123``) and
#: ``<slug>`` a legacy id or title slug. Retention substitutes every ``<…>`` with ``*`` and globs;
#: adoption compiles the same value to a regex with those two as named groups.
DEFAULT_BRANCH_PATTERNS = {}
PLACEHOLDER_RE = re.compile(r'<(id|slug)>')
```

added to the dataclass as `branch_patterns: dict = field(default_factory=dict)` and checked in
`validate_mapping` (P15): a map of non-empty strings, each carrying at most one `<id>` and at most
one `<slug>`, and each compiling. `retention.owned_patterns` is unchanged — it reads
`conv.get('branch_patterns')`, which now finds the declared field instead of the extra (P14's
`get` looks at `field_names()` first), and `tests/test_retention.py:93`'s `{'hotfix': '*hotfix*'}`
keeps working because a pattern with no placeholder is already a glob.

One pure function, in `asf/adoptpr.py`:

```python
def by_pattern(conv, text):
    """The ``(id, slug)`` a ``branch_patterns`` entry captures in ``text``, or ``(None, None)``.
    Patterns are tried in name order; the first that matches the whole of ``text`` answers."""
```

`<id>` compiles to `(?P<id>[A-Za-z]+-\d{4})`, `<slug>` to `(?P<slug>[A-Za-z0-9._-]+)`, and every
other character is escaped. `by_pattern` never touches the record; turning a slug into a card is
P17's job.

### 2. `conventions.legacy_review` — the product's own review form

`docs/products.example.yaml`, beside `review_pattern`:

```yaml
conventions:
  # The review form this product used before ASF (F-0125). Read ONLY for a pull request
  # `asf adopt-pr` adopted — never for a branch an ASF session pushed. Unset: no legacy form.
  legacy_review:
    glob: "{reviews_dir}/{slug}-r{n}.md"   # {reviews_dir}, {slug} (the item, lower-cased)
                                           # and {n} (the round) as in review_pattern
    verdict_regex: '\(APPROVED\)'          # matches the file → approved; no match → not approved
```

`validate_mapping` gains the key (P15): a map whose only keys are `glob` and `verdict_regex`, both
non-empty strings, the regex compiling, and the glob carrying `{slug}` — a glob without it would
read one item's review as every item's.

`asf/evidence/review.py` grows one argument and no new reading path:

| what | how |
| --- | --- |
| `legacy_rx(conv, slug)` | the compiled `legacy_review.glob` for `slug`, `{n}` a group — `pattern_rx`'s body with the other pattern (P10). `None` when the product declares none |
| `rounds(conv, paths, slug, legacy_prefixes=(), legacy=False)` | with `legacy=True`, a path matching `legacy_rx` is a third source of rounds, tagged `'product'` |
| `read(text, legacy=False, required=(), conv=None)` | `legacy == 'product'` → `approved` iff `conv.legacy_review['verdict_regex']` searches the text, else `changes` (D8) |
| `review_at(repo, conv, ref, item, required=(), legacy=False)` | passes `legacy` through to `rounds`/`read`; every existing call site keeps today's behaviour by not passing it |

The default (`legacy=False`) path is byte-for-byte what P10 does now, so no branch the factory
pushed changes its reading.

### 3. `asf adopt-pr`

```
asf adopt-pr [N …] [--all GLOB] [--item ID] [--product P] [--dry-run]
```

`asf/adoptpr.py`, `cmd_adopt_pr(args, root)`, registered in `cli.build_parser` and declared in
`asf/surface.py` (P24, D13) — the count in `tests/test_surface.py:49` becomes 50:

```python
    'adopt-pr':             ("adopt a product's open pull requests as lane runs so native landing drains them", HOST, None),
```

The steps, in order, each refusing before anything is written:

1. **Resolve.** The product, its repo, its `repo_slug`; a product with no PR host refuses with one
   line. The record's `index.json` is loaded for P17.
2. **Select.** `Lane(product, …).host.prs()` — the one `gh pr list` the lane already makes (P5's
   `prs()`), so the flags, the JSON fields and the `-R` slug are not written a second time. Numbers
   as given, or every open PR whose `headRefName` matches `--all`'s glob (D10). A number that is
   not an open PR on the trunk refuses by name. `--all` and numbers together refuse; neither
   refuses; `--item` with more than one PR refuses (D3).
3. **Attribute** each selected PR (D2), and print the rule that answered:

   | order | source | printed as |
   | --- | --- | --- |
   | 1 | `--item <id>`, which must be a card in the record | `--item` |
   | 2 | `by_pattern(conv, branch)`, then `by_pattern(conv, title)` — an `<id>` that is a card, or a `<slug>` `match_event` resolves | `branch_patterns:<name>` |
   | 3 | `match.match_event(items, branch=…, pr=…, title=…, prefixes=match.branch_prefixes(product))`, one id only | the rule `match_event` names (`id token`, `legacy_id`, `links.prs`) |
   | — | nothing, or more than one candidate | refused |

4. **Drop what is already adopted** (D9): a branch whose latest run (`lifecycle.by_branch`) carries
   `adopted: True`, counted and printed as `already adopted`.
5. **Print the table**, and with `--dry-run` return 0 here having written nothing:

```
product: acme   repo: o/p   trunk: main
PR     BRANCH                    ITEM     BY                    ACTION
#412   bugfix/inv-77-pdf         B-0044   legacy_id             adopt
#415   feature/T-0123-retries    T-0123   id token              adopt
#418   hotfix/dunning            F-0031   branch_patterns:hotfix adopt
#421   chore/bump-deps           —        no rule matched       refused
#409   bugfix/old-thing          B-0012   —                     already adopted
3 adopted, 1 already adopted, 1 refused
NEEDS OPERATOR: PR #421 (chore/bump-deps, "bump deps") names no card — asf adopt-pr 421 --item <id> --product acme
```

6. **Write**, one `Lane.adopt` per adopted PR (D1), with the PR on the record so the gate finds it
   without a second list (P13's `if not prs and rec.get('pr')`):

```python
lane.adopt(branch, item, conv.branch_kind(branch), pr=pr, job=f'adopt-pr-{n}')
```

   `Lane.adopt` gains the `pr` argument and puts it on `f` before `record()` reads
   `(f['pr'] or {}).get('number')` (P3, `asf/harvest/lane.py:1693`). The line written is P3's
   synthetic run — `pid: None`, `ended`, `end_reason: finished`, `adopted: True` — with
   `lane: {state: PUSHED, head, pr, reason: 'adopted-pr', item}`.
7. **Exit code** 0 when every selected PR was adopted or already adopted, 1 when any was refused —
   so a script can tell, and the operator sees the `NEEDS OPERATOR` line either way.

### 4. The lane: an adopted run is nobody's session

`branch_facts` sets one more fact beside `f['foreign']` (P6):

```python
f['adopted'] = bool((run or {}).get('adopted'))
```

and one module-level predicate carries it:

```python
def no_session(f):
    """True when no factory session wrote this branch's commits: a PR the lane adopted under
    ``merge: auto`` (:func:`pr_item`), or one ``asf adopt-pr`` adopted onto a card (F-0125).
    Its head needs a review whatever its landing class; its commits are not the lane's to reword
    and not a session's to answer, so it is never held BACK (D6) — the reason is a WAITING line."""
    return bool(f.get('foreign') or f.get('adopted'))
```

Five call sites, all of them today's `f['foreign']` (P6, P7, P8):

- `f['review_required'] = no_session(f) or conv.review_required(f['class'])`
- the `review_waived` shortcut is skipped when `no_session(f)`
- `lane_refusal` / `incomplete_refusal` are skipped when `no_session(f)`
- `_repair_naming`, `repair_signoff` and `drop_copies` return None for `no_session(f)`, with one
  line: `reword <b>: adopted, not the factory's to rewrite`
- and the review, when the run is adopted, is read with the legacy form allowed:

```python
rv = review_mod.review_at(repo, conv, f'origin/{b}', item,
                          reviews.required(review_kind(f['kind'])),
                          legacy=f['adopted'])
```

**Never BACK** (D6) is one guard at the one place a transition is written, `Lane.back`:

```python
def back(self, f, kind, text, **extra):
    if no_session(f):
        return self.wait(f, f'{kind}: no session — the PR author answers on the PR')
    ...
```

so T5 (a review reading changes), T9 (a red gate on a green trunk, a conflict, a refusal) and T9c
all become `WAITING` with their own reason. `lifecycle.hold` is not called, so no correction is
written, `rounds` does not move, and by P9 the feeder mints no row. The branch still reaches
`MERGED` the moment the review approves and the checks are green, and still reaches `STALE` by T12
when its PR closes.
