# F-0239 — the one park with no way out

A park is a promise: *this waits on a person, and a person can end it.* Every park in this factory
keeps that promise except one. `asf park` writes a registry line and `asf unpark` appends its undo.
A relaunch cap, an empty end, a security hold: each is a pending correction carrying `parked`, and
`asf unpark` clears it. Both show up in `asf status`'s `Parked` cell, which ends with the command
that releases them.

The STALEMATE → ADJUDICATE row reading `PARKED adjudicated, card unchanged` is not like that. It is
not written anywhere. It is *derived*, every tick, by `rows._capped` from a fact
(`step_wave.adjudications`) computed out of the sessions ledger and a hash of the card. There is no
line to undo. So `asf unpark T-0338` looks in the two places a park can live, finds neither, and
answers **`T-0338 is not parked — nothing to undo`** — about an item whose own NEXT row says
`PARKED` in capital letters.

The card names a second face of the same thing, and that one is already fixed. The digest skips
`## History` by design (D4: filing a ruling must not stale every brief), so for a while a person's
binding ruling at the correction-round cap changed nothing the park could see — T-0338 sat parked
on 2026-10-04 with two of them on its card. `step_wave.ruled_since` landed that fix (P2): an
`adjudicate (operator)` line stamped at or after the newest adjudicate run is a card change, and
`asf correct` at the cap files exactly such a line (P3). That half of the card is done, and this
spec does not redo it.

What is left is the half the fix exposed. `ruled_since` gave the park *one* key, and that key is a
ruling — a decision about the work. An operator who has no ruling to make, who simply wants the
stalemate to go round once more, still has nothing. And one whole class of item never got even that
key: a Bug past the attempt limit (`rows.bug_rows`, `n > limit`) never reaches `_capped` at all
(P7). It emits `WAITS ON operator — adjudicated after N sessions (limit 3): a person decides`, and
no ruling, no card edit, no `asf unpark` and no `asf correct` changes that row, ever. A person is
told to decide, and then given nothing that acts on a decision.

Three things, in the order they pay:

1. **A release a person can write.** `asf unpark <item>` stamps the release the one way this
   factory already records one, and the derived park reads it — the same shape, in the same field,
   that the relaunch cap has honoured since T-0338.
2. **The same judgement for a Bug.** The over-limit Bug row goes through `_capped` like every other
   over-limit row, so a ruling, a card edit or a release moves it, and when none has come it parks
   with a reason instead of waiting on a person who has no lever.
3. **The park says how it ends.** The row's reason and `asf status`'s `Parked` cell both name the
   command, so the operator does not have to already know the answer to find it.

### In

- **`step_wave.released_since(product, item, at, path=None)`** — the newest `unparked` stamp on any
  run of `item` at or after `at`, or `''`. The item-wide `max` of P5, with `_stamp`'s minute
  granularity, so a release written against any job of the item counts — which is what
  `asf unpark <item>` means.
- **`adjudications` reads it** — beside `ruled_since`, under the same `if cur['same_card']:`
  guard: a release since the newest adjudicate run is a card change, so the row launches one
  adjudicate session on this card state again.
- **`unpark.stalemate_release(path, item)`** — `(job, run)` of the newest **ended adjudicate** run
  of `item`, or `(None, None)`. That run is the only thing a derived stalemate park rests on, so
  it is the only thing a release has to name.
- **`cmd_unpark`'s third source** — when neither a by-hand nor a factory park holds the target and
  the target is item-scoped, a `stalemate_release` match is released by stamping `unparked` on that
  adjudicate job, with one printed line naming what was released and what happens next. Exit 0.
  With no adjudicate run either, today's refusal and exit 1 stand, unchanged.
- **`bug_rows(..., adjudicated=None)`** — one keyword argument, passed from `_candidates`. At
  `n > limit` the row is built as the `n == limit` STALEMATE row is, then handed to
  `_capped(row, attempts, limit, product, adjudicated)`, which decides between carrying a ruling,
  parking, and launching one adjudicate session (P8).
- **The park's reason names its release** — `_capped`'s PARKED reason ends
  ``… a card edit, a person's decision (`asf correct <id> --why …`) or `asf unpark <id>` moves it``.
- **`parked_cell(product, root=None)`** — `root` appended, optional. Given one, the cell also lists
  every derived stalemate park, scoped `item`, so the operator sees in `asf status` what the NEXT
  table has been saying.

### Out

- **`ruled_since` is not touched, and the ruling half is not redone** (P2). It landed, it is
  tested, and `asf correct` at the cap already feeds it (P3). This card is what is left after it.
- **`card_digest` still does not read `## History`** (P10). Folding History into the digest would
  stale every brief in flight on every ruling, every state note and every ingest — D4's reason has
  not changed. The release is a separate fact, read separately.
- **No new registry line kind, no new `_Folded` map.** `unparked` already means *released at*, is
  already written by this same command, and is already read item-wide by the relaunch cap (P5).
  A second mechanism for the same event would be a second thing to keep in step.
- **`asf unpark` does not file a ruling.** A release says *go round again*; a ruling says *this is
  settled, and here is what holds*. Writing a History line from `unpark` would put words in the
  operator's mouth and bind every later review of the item to them.
- **`asf park <item>` is not changed.** An item-scope park by hand already holds every row of the
  item, derived ones included, through `correction_of`'s `item_park` branch.
- **The review-round-cap stalemate (`stalemate_round`, `_one_feature_rows`) is not touched** (P11).
  It always launches and never parks; it has no park to release.
- **`tiers._remedy`'s `waits_on == 'operator'` branch keeps giving the severity downgrade.** Its
  advice is about whether a Bug is really S1, not about a park, and the S1 gate's remedy table is
  its own card. S-53455 changes which rows reach that branch; it does not change what it says.
- **No change to the scorecard, to `end_reason`, or to any failure class.** Nothing here is a run
  outcome.

## The design

### 1. The release, read where the park is derived

`asf/tick/step_wave.py`. A new reader, beside `ruled_since` and in its shape:

```python
def released_since(product, item, at, path=None):
    """The newest ``unparked`` stamp on any run of ``item`` at or after ``at`` (the newest
    adjudicate run's start), or ''.

    ``asf unpark <item>`` releases every park on the item, and the "adjudicated, card unchanged"
    park is derived rather than recorded (F-0239), so there is nothing for it to clear — it
    stamps the release on the adjudicate run the park is derived from. Read item-wide, as the
    relaunch cap reads it (:func:`asf.workers.lifecycle.same_head_loop`): a release written on
    any job of the item is the operator's decision that the item moves.
    """
    since = _stamp(at)
    if not since:
        return ''
    runs = lifecycle.item_runs(path or pool_mod.sessions_path(product), item)
    return max((s for s in (_stamp(r.get('unparked')) for r in runs) if s >= since), default='')
```

and in `adjudications`, one line beside the ruling test, under the same guard:

```python
        cur['same_card'] = not cur['digest'] or not now or cur.pop('digest') == now
        cur.pop('digest', None)
        if cur['same_card'] and (ruled_since(product, item, cur['at'])
                                 or released_since(product, item, cur['at'])):
            cur['same_card'] = False
```

Order matters only for cost: the ruling test reads the card, the release test reads the ledger
already folded in memory, and `or` short-circuits either way. Nothing else in `adjudications`
changes — `ruling`/`carried` stay under `if cur['same_card']:`, so a released item never also
hands out a ruling, which is right: it is going back to adjudication, not past it.

### 2. `asf unpark <item>` releases a derived stalemate park

`asf/workers/unpark.py`. One helper and one branch.

```python
def stalemate_release(path, item):
    """``(job, run)`` of ``item``'s newest ended adjudicate run — what a derived "adjudicated,
    card unchanged" park (:func:`asf.feeder.rows._capped`) rests on — or ``(None, None)``."""
    adj = [(r.get('started') or '', job, r) for job, rs in lifecycle.runs(path).items()
           for r in rs if r.get('item') == item and r.get('kind') == 'adjudicate' and r.get('ended')]
    if not adj:
        return None, None
    _at, job, run = max(adj, key=lambda x: x[0])
    return job, run
```

In `cmd_unpark`, the refusal at `if not by_hand and not by_factory:` gains the case before it:

```python
    sjob, srun = (stalemate_release(path, item) if scope == lifecycle.SCOPE_ITEM
                  else (None, None))
    if not by_hand and not by_factory and not sjob:
        print(f'asf unpark: {_scope_text(scope, item, branch, job)} is not parked — nothing to undo')
        return 1
```

and, after the two existing release loops, the third:

```python
    if sjob and not by_hand and not by_factory:
        pool_mod.update_session(product, sjob, unparked=now, unpark_why=why)
        print(f'unparked {item} (job {sjob}): adjudicated on this same card, last '
              f'{str(srun.get("started") or "")[:16]} — the next tick gives it one adjudicate '
              f'session on this card state')
```

Three things this does **not** do. It writes no `correction=None`: there is no correction to
clear, and writing one would retire a pending correction the park never owned. It fires only when
no recorded park was found — when one was, that release is the answer, and `adjudications` reads
the same `unparked` stamp item-wide anyway (D3), so the derived park lifts with it for free. And it
is item scope only: a branch or job target names a branch or job, and the stalemate park holds the
item.

### 3. The Bug past the limit, judged on the same fact

`asf/feeder/rows.py`. `bug_rows` takes `adjudicated=None` and `_candidates` passes it. The
`n > limit` branch stops being a dead end:

```python
        if n >= limit:
            row = Row(tier=tier, kind=STALEMATE, item_id=b['id'], feature_id=fid, action=LAUNCH,
                      brief_kind='adjudicate', branch=branch_for(product, 'fix', b['id']),
                      reason=f"{sev} open after {n} sessions: adjudicate, not another fix")
            out.append(row if n == limit else _capped(row, attempts, limit, product, adjudicated))
            continue
```

At `n == limit` the row is exactly what it is today — one adjudicate session, its own next
attempt. Past it, `_capped` decides: an uncarried ruling the adjudicate session filed is carried
out by one `correct` session on the Bug's fix branch; a release or an operator ruling since gives
one more adjudicate session; and only when the card has genuinely not moved is it `PARKED
adjudicated, card unchanged` — non-launching, so `_candidates` keeps it among `bug_waits` where
`waits('operator', …)` used to sit, with the same `waits_on` and a reason that now says what would
move it (P8).

### 4. The park says how it ends

`_capped`'s PARKED reason:

```python
            why = (f"{row.kind} after {n} sessions (limit {limit}); adjudicated "
                   f"{adj.get('runs') or 1} time(s), last {str(adj.get('at') or '?')[:16]}, on "
                   f"this same card: a card edit, a ruling (`asf correct {row.item_id} --why …`) "
                   f"or `asf unpark {row.item_id}` moves it")
```

and `parked_cell`, which gains the optional `root` and one block:

```python
def parked_cell(product, root=None):
    ...
    parked += [(iid, 'item', f"adjudicated {adj.get('runs') or 1} time(s), last "
                             f"{str(adj.get('at') or '?')[:16]}, on this same card")
               for iid, adj in sorted(_stalemate_parks(product, root).items())]
```

`_stalemate_parks` is the one new helper: `{}` when `root` is None or carries no `index.json`,
otherwise `{item: adj for item, adj in plan_inputs(product, root)['adjudicated'].items()
if adj.get('same_card') and not (adj.get('ruling') and not adj.get('carried'))}` — a park is
listed only when it is really parked, never when a ruling is on its way to a session. The table's
call site becomes `parked_cell(product, root)`; every other caller keeps working unchanged (D6).
