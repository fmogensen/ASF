## The design

### 1. `README.md` — the `## Upgrade` section names both channels

The section's second paragraph (`:84-90`) names the trunk channel and the schema step. The release
channel joins it, and the trunk-channel clause is re-pointed so the pair reads as a pair. `:87-90`
today, byte for byte:

```markdown
([schema migrations](docs/guide/upgrading.md#schema-migrations)). `upgrade: auto` under a product's
`approvals:` lets the tick run `asf upgrade` itself — today only for ASF's own repo as a product
([the product file](docs/guide/product-config.md#approvals)). Rolling back, and what is safe while
sessions run: [upgrading](docs/guide/upgrading.md).
```

becomes:

```markdown
([schema migrations](docs/guide/upgrading.md#schema-migrations)). Every product declares how its
own tick takes a new release under `conventions.flags.upgrade`: `notify`, the default, reports one
once per tag; `off` reports nothing; `auto` authorises the tick to install it. A word that is none
of the three reads as `notify`. Annotated beside every other switch in
[`docs/products.example.yaml`](docs/products.example.yaml), and as a map in
[the product file](docs/guide/product-config.md#flags-conventionsflags). ASF's own repo as a
product is on the trunk channel instead, where `upgrade: auto` under `approvals:` lets the tick run
`asf upgrade` itself ([the product file](docs/guide/product-config.md#approvals)). Rolling back,
and what is safe while sessions run: [upgrading](docs/guide/upgrading.md).
```

Five properties of that text are load-bearing, and each is an assertion in T2: it names
`conventions.flags.upgrade`; it carries all three of `env.UPGRADE_POLICIES` and says which is the
default; it says `auto` *authorises* rather than installs (D2, P5); it carries both of D3's links;
and it keeps `upgrade: auto` and `approvals:` adjacent, so the existing needle `upgrade: auto`
still resolves to the trunk channel and not to the new sentence. No heading is added and no digit
run is written (D8).

### 2. `tests/test_readme.py` — the guard, bounded and reshape-proof

`ReleaseGateHeadingsTests` (`:483-511`) keeps its first test unchanged — that test is already
right, and P2 says it is green. Its docstring gains the bounding sentence. The two content tests
move onto one reader, and two tests join them:

- `_section(title, text=None)` — the body under the heading whose text is `title`, bounded by the
  next heading of **any** depth (D5). The whole of §1's and §2's correctness under T-0138 rests on
  this one function.
- `_as_three_parts()` — the committed page in the shape P7 commits T-0138 to: the five `##`
  sections demoted to `###`, F-0030's three `##` parts inserted, with an assertion that no section
  was left at `##` depth so the fixture cannot silently stop being the reshaped page.
- `test_configuration_names_both_files_and_links_the_guide` — the same three needles, read out of
  `self._section('Configuration')`.
- `test_upgrade_names_the_command_the_schema_step_and_auto` — the same four needles, read out of
  `self._section('Upgrade')`.
- `test_upgrade_names_the_release_channel_key_and_its_three_words` — new, and the card's clause.
  The words come from `asf.env`, never from the test (D6).
- `test_the_guard_survives_the_page_being_cut_into_three_parts` — new, and the answer to the card's
  argument. Against `_as_three_parts()`: no `readme_sections` entry missing from
  `release.readme_headings`, and no section holding its neighbour's content.

### What it looks like when it is there

```python
class ReleaseGateHeadingsTests(unittest.TestCase):
    """The release gate's docs criterion, README half: the committed README carries a heading for
    every ``release.readme_sections`` entry (Install, Quick start, Configuration, Upgrade) — read
    through the gate's own ``readme_headings``, so CI proves what ``asf release-readiness`` reads.
    Each section's content is bounded by the next heading of *any* depth, so the same assertions
    hold on F-0030's three-part page, where these four become ``###`` (S-0005 D5)."""

    _HEADING = r'^#{2,3}\s+%s\s*#*\s*$'
    _PARTS = ('Install', 'Quick start', 'Configuration', 'Upgrade', 'Feedback')

    def _readme(self):
        with open(os.path.join(REPO_ROOT, 'README.md'), encoding='utf-8') as f:
            return f.read()

    def _section(self, title, text=None):
        """The body under the heading whose text is ``title``, bounded by the next heading of any
        depth. Not ``split('## X')[1].split('\\n## ')[0]``: F-0030 cuts these four down to ``###``
        under ``## The manual`` (docs/plans/f-0030.md:259), and a ``\\n## `` terminator then matches
        nothing after the last ``##`` part, so every slice runs to end of file and the assertions
        below stop proving the needle is in *this* section."""
        text = self._readme() if text is None else text
        head = re.search(self._HEADING % re.escape(title), text, re.M)
        self.assertIsNotNone(head, f'README has no heading {title!r}')
        rest = text[head.end():]
        nxt = re.search(r'^#{1,6}\s', rest, re.M)
        return rest[:nxt.start()] if nxt else rest

    def _as_three_parts(self):
        """The committed page in the shape docs/plans/f-0030.md:259 commits T-0138 to: three
        ``##`` parts, today's sections demoted to ``###`` inside the manual."""
        text = re.sub(r'^## (%s)$' % '|'.join(self._PARTS), r'### \1', self._readme(), flags=re.M)
        self.assertNotIn('\n## ', text, 'a section was left at ## depth')
        return text.replace('### Install',
                            '## The argument\n\nA.\n\n## The mental model\n\nB.\n\n'
                            '## The manual\n\n### Install', 1)

    def test_every_readme_section_the_gate_requires_is_a_heading(self):
        from asf import release
        headings = release.readme_headings(self._readme())
        for section in release.DEFAULTS['readme_sections']:
            with self.subTest(section=section):
                self.assertTrue(any(section.lower() in h.lower() for h in headings),
                                f'README lacks a heading containing {section!r}: {headings}')

    def test_configuration_names_both_files_and_links_the_guide(self):
        section = self._section('Configuration')
        for needle in ('~/.ASF/config.yaml', '~/.ASF/products/<product>.yaml',
                       'docs/guide/product-config.md'):
            self.assertIn(needle, section)

    def test_upgrade_names_the_command_the_schema_step_and_auto(self):
        section = self._section('Upgrade')
        for needle in ('asf upgrade --to', 'asf schema-migrate', 'upgrade: auto',
                       'docs/guide/upgrading.md'):
            self.assertIn(needle, section)

    def test_upgrade_names_the_release_channel_key_and_its_three_words(self):
        from asf import env
        section = self._section('Upgrade')
        self.assertIn('conventions.flags.upgrade', section)
        for word in env.UPGRADE_POLICIES:
            with self.subTest(word=word):
                self.assertIn(word, section)
        self.assertRegex(section, r'`%s`[^.]{0,40}default|default[^.]{0,40}`%s`'
                         % (env.UPGRADE_DEFAULT, env.UPGRADE_DEFAULT))
        # S-0005 D2: the flag has no consumer in the package, so the page may say what it
        # authorises and not what it does.
        self.assertIn('authorises', section)
        self.assertNotIn('`auto` installs', section)
        for link in ('docs/products.example.yaml',
                     'docs/guide/product-config.md#flags-conventionsflags'):
            self.assertIn(link, section)
        # the older needle still belongs to the trunk channel, not to the sentence above
        self.assertIn('approvals:', section)

    def test_the_guard_survives_the_page_being_cut_into_three_parts(self):
        from asf import release
        three = self._as_three_parts()
        headings = release.readme_headings(three)
        for section in release.DEFAULTS['readme_sections']:
            with self.subTest(section=section):
                self.assertTrue(any(section.lower() in h.lower() for h in headings),
                                f'the three-part page lacks {section!r}: {headings}')
        # the bounding, not the heading, is what the reshape breaks: before S-0005 every slice
        # ran to end of file, so Configuration held the Upgrade section's own commands.
        config = self._section('Configuration', three)
        self.assertNotIn('asf schema-migrate', config)
        self.assertNotIn('the Apache Software Foundation', config)
        self.assertIn('~/.ASF/config.yaml', config)
        upgrade = self._section('Upgrade', three)
        self.assertIn('conventions.flags.upgrade', upgrade)
        self.assertNotIn('~/.ASF/config.yaml', upgrade)
```
