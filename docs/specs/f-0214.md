# F-0214 — one directory, no rule

Since 2026-09-26 a product's `worker_env` sets `TURBO_CACHE_DIR` to one directory per product
under the product's state dir, shared by every worktree so an unchanged package is a cache hit
across sessions. Every worker session writes into it. **Nothing reads it back out.**

The factory already bounds every other thing it grows on disk. Worktrees are capped at live
sessions + a buffer and reaped oldest-first (`asf/workers/worktrees.py`); their directories go to
a trash a nice'd deleter empties (`asf/workers/trash.py`); origin's heads nothing owns expire by
two dated rules (`asf/workers/retention.py`). Each of those is one pass in the tick's health step,
each writes one state file, and each renders one doctor row off that file without measuring
anything itself. The build cache is the one growing directory with no pass, no file and no row —
so it grows until the disk stops the factory, and nobody can say whether it was ever paying for
the space.

This spec adds the missing pass in the shape the other three already have.

### The choices

| # | Chosen | Against | Why |
| --- | --- | --- | --- |
| C1 | **The pass finds its directories by reading the resolved worker environment**: `cache_prune.env_vars` (default `['TURBO_CACHE_DIR']`) named against `env.worker_env(spawn.load_cfg(), product)`. | Deriving `state/<product>/turbo-cache`; a `cache_prune.dirs` list of paths the operator repeats. | P1: the path is the operator's, set in one place, and the session is the only thing that has ever known it. Reading the same function the spawn reads means the pass prunes *the directory the sessions actually use* — including one an operator moved to another disk — and can never prune a directory no session writes to. A derived path would be a second source of truth that goes wrong silently the first time the operator edits `worker_env`; a repeated `dirs:` list is the same bug with more typing. Naming *variables* also makes a second tool (another build cache, another env var) one config line and no code. |
| C2 | **A directory outside the product's state dir is refused, named, and left alone.** The pass resolves `os.path.realpath(os.path.expanduser(value))` and prunes only while it is inside `os.path.realpath(env.state_dir(product))`; otherwise the state file records `problem` and the doctor row is red with the reason. | Pruning wherever the variable points; an `allow_outside: true` opt-in. | This pass unlinks files. The one thing it must never do is unlink the wrong ones, and the failure mode is one typo away: `TURBO_CACHE_DIR: ~` prunes a home directory oldest-first. The product's own state dir is the one tree the factory already owns and already empties (worktrees, trash, briefs), so it is the correct boundary, and the card's own setup is already inside it. An opt-in flag would buy an operator with a cache on another disk exactly one thing — the ability to point a pruner at an arbitrary path — which is the risk, not the feature. The refusal is loud (a red row), so the case is visible rather than silent. |
| C3 | **A value that is not an absolute path is refused with its own reason**, before any resolution. | Expanding it like a shell and pruning anyway. | P2: `spawn` hands the value over verbatim, so `~/cache` means the sessions are writing into a directory literally called `~` in each worktree — the shared cache is not shared at all, and every gate is a cold miss. Expanding it in the pruner would hide that: the pass would dutifully prune a directory nothing writes to while the real one grew. Refusing turns a silent misconfiguration into a doctor row. |
| C4 | **Two rules, oldest first: age past `max_age_days` (7), then a size cap `max_size_gb` (10) — and a floor: nothing used within `min_age_min` (60) is ever taken.** `max_age_days: 0` and `max_size_gb: 0` each turn their half off. | Age alone; the cap alone; a count cap; an LRU with no floor. | The card names both numbers, and each covers what the other cannot: age alone lets a week of heavy building blow past any disk, the cap alone keeps a fortnight-old entry alive for ever on a quiet product. The floor is not decoration — the cap half prunes oldest-first *whatever the ages are*, so on a small cap it would reach the archive a session wrote four minutes ago and is about to read. One hour is far longer than a gate and far shorter than a day. |
| C5 | **The unit is an *entry*, not a file: the direct children of the cache directory grouped by stem — the name up to its first `.`, with one trailing `-meta` removed — pruned whole.** | Pruning each file on its own merits. | A cache entry is an archive plus a metadata sidecar written together (`<hash>.tar.zst`, `<hash>-meta.json`). Pruning them separately can leave a sidecar whose archive is gone, which is a lookup the tool must then handle; and it makes the size accounting wrong, because the sidecar is bytes the archive's removal does not free. Grouping by stem needs no knowledge of the extensions in use, so it holds for whatever naming the directory actually carries (P16). |
| C6 | **Files only. A child that is a directory is skipped, counted, and named in the state file; the pass never recurses and never `rmtree`s.** | `shutil.rmtree` on a directory entry; recursing to size the tree. | A pruner with a recursive delete inside it is one resolution bug away from removing a tree it was only meant to measure, and C2's boundary is the only thing standing between it and the state dir's worktrees. A flat local cache has no directory children; if one appears, the honest answer is a counted, visible skip — not a recursive delete this spec cannot test against the real layout. Skipping also keeps a pass to one `scandir` plus one `stat` per child, which is what makes it safe to run every tick. |
| C7 | **"Last used" is `max(st_atime, st_mtime)`, from the `stat` `os.scandir` already carries.** | `st_mtime` alone; a sidecar touch file the pass maintains. | A cache *hit* reads the archive and does not rewrite it, so under `st_mtime` alone every entry ages as if it were never used, and the 7-day rule deletes the hottest entries in the cache. `st_atime` is the only record of a read that exists without the tool's cooperation. Where the filesystem does not keep it (`noatime`), `max()` degrades exactly to today's behaviour rather than breaking, and the cost of a wrongly pruned hot entry is bounded and self-healing: one miss, one rebuild, one fresh entry. A touch file would mean the factory writing into a directory owned by another tool's format. |
| C8 | **The hit rate is read from the run summaries the sessions' worktrees already hold** — `<worktrees>/*/<summary_glob>` (default `.turbo/runs/*.json`), the newest `summary_max` (20) whose mtime is inside `summary_window_h` (24) — accepting either `execution.{attempted,cached}` or `tasks[].cache` rows, and counting the files it could not read. | Having the factory turn run summaries on for every product; parsing the tool's terminal output; dropping the hit rate as "not cheaply readable". | P3 makes the worktrees the only durable place a summary can be, and a glob plus at most twenty small JSON reads is cheap by any measure. Two shapes are accepted because this session cannot verify the tool's schema (P16) and a reader that recognises one shape silently reports 0% against the other; a file matching neither is *counted*, so an unreadable schema shows up as a number rather than as a wrong rate. Turning summaries on for every product changes what every session's gate writes to disk for a fact one row consumes — that is the operator's call, and it is the operator line below. Parsing terminal output is a promise about a format nobody publishes. |
| C9 | **The hit rate goes in the status table and the pass's own line; the size goes in the doctor row; neither goes into a metric stream.** | A `metrics/caches` event per pass so the scorecard can trend it. | The card asks for the size in the doctor and the rate in the scorecard *or* status, and status is where an operator already reads one line per subsystem (P9). The metric streams are committed files in the record; a tick every five minutes would add ~8 600 rows a month to a committed file to serve one cell, and the same 24-hour window is already in the state file for free. If a trend is ever wanted, the stream is a later card with a window and a consumer, not a guess made here. |
| C10 | **One line per pass per cache directory, and no line at all when the product configures none** — no state file, no doctor row, no status row either. | A line every tick saying there is nothing to do. | The card asks for one line per pass, and that is what a product with a cache gets, prune or no prune. A product with no `cache_prune.env_vars` match has nothing this pass can say; `retention`/`worktrees` set the precedent that a row nothing feeds is absent (P5), and a per-tick line saying "not configured" is the noise that makes operators stop reading tick output. |
| C11 | **`max_size_gb` is a number, not an integer**, validated `>= 0`; its own validator `_cache_prune_problems` with its own zero-ok keys, not an extension of `ZERO_OK`. | Integer gigabytes; reusing `ZERO_OK`. | An integer floor of 1 GB makes the cap rule untestable without writing a gigabyte of fixture, and it denies an operator a 512 MB cap on a small disk for no reason. A separate validator keeps `branch_retention`'s zero-means-off set from silently deciding what a cache key may be, which is how one block's rule leaks into another's. |
| C12 | **Three Stories, ordered — the pass, then the doctor row, then the hit rate — not three parallel ones.** | One Story; three concurrent ones. | The doctor row and the status row both render the state file the first Story writes, so both would be reviewing a file format that did not exist yet; and all three write `asf/workers/caches.py` and `tests/test_cache_prune.py`, so their footprints cannot be disjoint in one wave. Ordered, each lands something whole and useful on its own: a bounded directory, then the size in the doctor, then the proof it pays. One Story would be a single Task writing five files with three independent acceptance surfaces. |

### Out of scope

Anything that changes what a session's build tool *does*: no `--summarize`, no `TURBO_RUN_SUMMARY`,
no cache flag added to `DEFAULT_WORKER_ENV`, no change to `test_command` or to the gate (P3).
Other growing trees in the state dir — worktrees, the trash, briefs, logs — each already has its
own pass or its own card. A remote cache of any kind. A metric stream (C9). Deduplicating entries,
verifying an archive, or repairing a corrupt cache: this pass removes whole entries by date and by
size and never inspects one. The `pnpm` store, which is per *user*, not per product
(`worktrees.pnpm_note`), and which no product's `worker_env` points into a state dir. Pruning
during a wave or at spawn time: the health step is the only caller.

## The design

One new module, four edited files, one new test file.

```

```

### The conventions block

In the module-head yaml example, after `branch_retention:`:

```yaml
      cache_prune:                # the build cache the worktrees share (asf.workers.caches)
        env_vars: [TURBO_CACHE_DIR]   # worker_env variables that name a cache directory
        max_age_days: 7           # an entry unused this long goes (0 = off)
        max_size_gb: 10           # the directory's cap, oldest entries first (0 = off)
        min_age_min: 60           # never take an entry used this recently
        per_pass: 2000            # the most entries one pass removes
        summary_glob: '.turbo/runs/*.json'   # the run summaries a session's worktree keeps
        summary_max: 20           # the most summaries one pass reads
        summary_window_h: 24      # the window the hit rate is taken over
```

and the defaults, beside `DEFAULT_BRANCH_RETENTION`:

```python
#: ``cache_prune:`` — the build cache a product's worktrees share (:mod:`asf.workers.caches`).
#: ``env_vars``: the ``worker_env`` variables whose value names a cache directory; the pass reads
#: the resolved environment (:func:`asf.env.worker_env`), because the path is the operator's and
#: exists nowhere in this package. ``max_age_days``/``max_size_gb``: an entry unused longer than
#: the first goes, and while the directory is over the second the oldest entries go until it fits
#: (0 turns either half off). ``min_age_min``: an entry used this recently is never taken —
#: a live session's own archive is not pulled out from under it. ``per_pass``: the most entries
#: one pass removes. ``summary_*``: where a session's run summaries are, how many of them one
#: pass reads and over what window, for the hit rate (:func:`asf.workers.caches.hit_rate`).
#: A directory outside the product's state dir, or a value that is not an absolute path, is
#: never pruned: the pass names it and the doctor's ``caches`` row is red.
DEFAULT_RUN_SUMMARY_GLOB = '.turbo/runs/*.json'
DEFAULT_CACHE_PRUNE = {'env_vars': ['TURBO_CACHE_DIR'], 'max_age_days': 7, 'max_size_gb': 10,
                       'min_age_min': 60, 'per_pass': 2000,
                       'summary_glob': DEFAULT_RUN_SUMMARY_GLOB, 'summary_max': 20,
                       'summary_window_h': 24}
#: ``cache_prune`` keys whose 0 means "off", not "malformed".
CACHE_PRUNE_ZERO_OK = ('max_age_days', 'max_size_gb', 'min_age_min')
```

`'cache_prune'` joins `MAP_CONVENTIONS`; the field is
`cache_prune: dict = field(default_factory=lambda: dict(DEFAULT_CACHE_PRUNE))`; `from_mapping`
merges it over the defaults exactly as it merges `branch_retention` (P7); `validate_mapping`
gains `problems.extend(_cache_prune_problems(data.get('cache_prune')))`, whose validator mirrors
`_retention_problems` — an unknown key, a non-list `env_vars`, a non-string `summary_glob`, a
negative or boolean number — and the accessor mirrors `retention`:

```python
    def pruning(self, key):
        """One ``cache_prune`` value (:data:`DEFAULT_CACHE_PRUNE`); a malformed one reads as its
        default — the doctor's ``conventions`` row names it."""
        default = DEFAULT_CACHE_PRUNE[key]
        held = self.cache_prune if isinstance(self.cache_prune, dict) else {}
        value = held.get(key)
        if key == 'env_vars':
            if isinstance(value, str):
                value = [value]
            if not isinstance(value, list):
                return tuple(default)
            return tuple(v.strip() for v in value if isinstance(v, str) and v.strip())
        if key in ('summary_glob',):
            return value.strip() if isinstance(value, str) and value.strip() else default
        least = 0 if key in CACHE_PRUNE_ZERO_OK else 1
        if isinstance(value, bool) or not isinstance(value, (int, float)) or value < least:
            return default
        return value
```

### `asf/workers/caches.py`

```python
"""asf.workers.caches — the build cache the worktrees share, bounded by two numbers.

A product's ``worker_env`` points a build tool's cache at one directory per product under the
state dir, so an unchanged package another session already built is a cache hit
(``TURBO_CACHE_DIR`` by default, ``conventions.cache_prune.env_vars``). Every session writes
into it; nothing read it back out, so it grew without bound (F-0214).

One pass in the tick's health step, in the shape :mod:`asf.workers.retention` and
:mod:`asf.workers.worktrees` already have:

* the directories come from the *resolved* worker environment (:func:`asf.env.worker_env`) — the
  path is the operator's and appears nowhere in this package — and one that is not an absolute
  path, or that resolves outside the product's own state dir, is named and never touched;
* an **entry** is the direct children of the directory that share a stem (an archive and its
  metadata sidecar are one entry, removed together), its size the sum of their sizes and its age
  ``now - max(atime, mtime)`` — a cache *hit* reads the archive without rewriting it, so mtime
  alone would age the hottest entries as if they were never used;
* entries older than ``max_age_days`` go; then, while the directory is over ``max_size_gb``, the
  oldest go until it fits — but never one used inside ``min_age_min``, and never more than
  ``per_pass`` of them;
* the pass prints one line, and records the sizes and counts in :data:`STATE_FILE` for
  ``asf doctor``'s ``caches`` row and ``asf status``'s ``Caches`` row, which measure nothing.

Files only: a child that is a directory is counted and skipped, never recursed into and never
``rmtree``'d — this pass has an unlink in it, and the state dir it runs inside holds the
worktrees.
"""
```

Its surface, in the order a pass uses it:

```python
STATE_FILE = 'caches.json'
GB = 1024 ** 3
MINUTE_S = 60


@dataclasses.dataclass
class Entry:
    stem: str
    paths: list                  # the sibling files this entry is made of
    bytes: int
    used: float                  # max(atime, mtime) over them


def stem_of(name):
    """The entry a child belongs to: its name up to the first ``.``, one trailing ``-meta``
    removed — ``h.tar.zst`` and ``h-meta.json`` are one entry (C5)."""


def cache_dirs(product, cfg=None):
    """``[(var, path, problem)]`` — the cache directories this product's sessions share, from
    ``conventions.cache_prune.env_vars`` against :func:`asf.env.worker_env`. ``problem`` is ''
    when the path may be pruned, else why it may not: not an absolute path (C3), outside the
    product's state dir (C2), or not a directory."""


def entries(path):
    """``([Entry] oldest first, total bytes, directories skipped)`` from one ``os.scandir`` and
    one ``stat`` per child; a child that vanished between the two is skipped."""


def plan(rows, total, max_age_s, cap_bytes, min_age_s, per_pass, now):
    """``([Entry] to remove, {'age': n, 'cap': n}, left)``: every entry past ``max_age_s``, then
    the oldest remaining while ``total`` less what is already doomed is over ``cap_bytes`` —
    never an entry used inside ``min_age_s``, at most ``per_pass``, the rest counted in
    ``left``. Pure: nothing is touched."""


def prune_dir(path, conv, now=None, fix=True):
    """One directory: :func:`entries`, :func:`plan`, then (``fix``) each doomed entry's files
    unlinked. The dict the state file carries — ``bytes``, ``entries``, ``pruned``,
    ``pruned_bytes``, ``by_reason``, ``left``, ``failed``, ``skipped_dirs``."""


def summary_counts(data):
    """``(attempted, cached)`` off one run summary, or None when it is neither shape:
    ``execution.attempted``/``execution.cached``, else ``tasks[].cache`` rows whose ``status``
    is ``HIT`` (or whose ``local``/``remote`` is true)."""


def hit_rate(product, conv, now=None):
    """``{'runs', 'attempted', 'cached', 'unreadable', 'window_h'}`` over the newest
    ``summary_max`` run summaries under ``<worktrees>/*/<summary_glob>`` whose mtime is inside
    ``summary_window_h`` — or None when the glob matches nothing (C8)."""


def line(var, data, rate):
    """The pass's one line for one directory (C10)."""


def prune(product, cfg=None, conv=None, fix=True, out=print, now=None):
    """One pass over every directory :func:`cache_dirs` names: prune it, print its line, and
    write the state the two rows read. Returns the state dict; writes nothing and prints nothing
    for a product that configures no cache directory."""


def read_state(product) / write_state(product, data)   # `.tmp` + os.replace, as retention's
def doctor_line(product)    # (ok, detail) off the state file, or None before a pass has run
def status_line(product)    # the size and the hit rate for the status table, or None
```

### The wrapper

In `step_health.py`, beside `branch_retention` and called last in `run()`:

```python
def cache_prune(ctx, out=print):
    """The build cache the worktrees share, pruned past its age and its size cap, one line a
    pass (:mod:`asf.workers.caches`). Printed, never raised: a prune never stops a tick."""
    from asf.workers import caches
    try:
        return caches.prune(ctx.product, fix=True, out=out)
    except Exception as e:  # noqa: BLE001 — the next tick prunes again
        out(f'caches: skipped — {type(e).__name__}: {e}')
        return None
```

```python
One fixture: an ASF_HOME whose product state dir holds a cache directory of entries with known
sizes and ages, and two worker worktrees carrying run summaries."""
import json
import os
import shutil
import tempfile
import time
import unittest
from unittest import mock

from asf import conventions, doctor, env
from asf.views import status
from asf.workers import caches

DAY = 86400
MB = 1024 * 1024


class CacheFixture(unittest.TestCase):
    def setUp(self):
        self.now = time.time()
        home = tempfile.mkdtemp(prefix='caches_home_')
        self.addCleanup(shutil.rmtree, home, True)
        p = mock.patch.object(env, 'ASF_HOME', home)
        p.start()
        self.addCleanup(p.stop)
        self.product = env.Product('sample', {})
        self.cache = os.path.join(env.state_dir(self.product), 'turbo-cache')
        os.makedirs(self.cache)
        self.cfg = {'worker_pool': {'env': {'TURBO_CACHE_DIR': self.cache}}}

    def conv(self, **over):
        return conventions.Conventions.from_mapping({'cache_prune': over})

    def entry(self, stem, mb, age_days, meta=True):
        """One cache entry: an archive of ``mb`` MiB and its sidecar, last used ``age_days`` ago."""
        paths = [os.path.join(self.cache, f'{stem}.tar.zst')]
        if meta:
            paths.append(os.path.join(self.cache, f'{stem}-meta.json'))
        with open(paths[0], 'wb') as f:
            f.write(b'\0' * (mb * MB))
        if meta:
            with open(paths[1], 'w') as f:
                json.dump({'hash': stem}, f)
        when = self.now - age_days * DAY
        for path in paths:
            os.utime(path, (when, when))
        return paths

    def summary(self, job, name, payload, age_h=1):
        """One run summary in a worker worktree, as a session's build tool leaves it."""
        from asf.workers import spawn as spawn_mod
        runs = os.path.join(spawn_mod.worktrees_dir(self.product), job, '.turbo', 'runs')
        os.makedirs(runs, exist_ok=True)
        path = os.path.join(runs, name)
        with open(path, 'w') as f:
            json.dump(payload, f)
        os.utime(path, (self.now - age_h * 3600, self.now - age_h * 3600))
        return path

    def prune(self, fix=True, **over):
        lines = []
        state = caches.prune(self.product, cfg=self.cfg, conv=self.conv(**over), fix=fix,
                             out=lines.append, now=self.now)
        return state, lines
```

## Records

| What | Where | What it says |
| --- | --- | --- |
| **The pass's state** | `<state>/caches.json` — new, one file per product, written through `.tmp` + `os.replace` | `at`, and per directory: `var`, `path`, `bytes`, `entries`, `pruned`, `pruned_bytes`, `by_reason` (`{age, cap}`), `left`, `failed`, `skipped_dirs`, `problem`; plus `summaries` (`runs`, `attempted`, `cached`, `unreadable`, `window_h`). Overwritten every pass — no history, no growth. Absent for a product that configures no cache directory. |
| **The tick's output** | the health step's lines | One line per pass per cache directory (C10): the size, the entry count, what was pruned and why, what is left for the next pass, and the hit rate — or the reason the directory was not pruned. Never one line per entry. |
| **`asf doctor`** | one new `caches` row, after `worktrees`/`branches` | The size, the entries, what the last pass removed and when, and the hit rate — read off `caches.json`, measuring nothing. Red only when a directory is refused, still over its cap, or something could not be removed. Absent before the first pass, and for a product with no cache directory. |
| **`asf status`** | one new `Caches` row | The size against the cap and the hit rate over the window. Absent (the cell returns None) when there is no cache directory or no pass yet. |
| **The product config** | `products/<p>.yaml` `conventions.cache_prune` | A new optional block, every key defaulted (`DEFAULT_CACHE_PRUNE`). A product that sets nothing gets the 7-day, 10 GB rule over `TURBO_CACHE_DIR`; a misshapen block is a red `conventions` row, never a silent default (P7). No new top-level key, so a v0.1.2 reader still loads the file. |
| **What is not written** | — | No metric stream event (C9), no record card, no ledger row, no event, no new CLI command, no change to `DEFAULT_WORKER_ENV`, and nothing at all inside the cache directory — the pass only removes whole entries from it. |

## Stories

- S-52354: The health step prunes the shared build cache — `asf/workers/caches.py` reads the directories out of the resolved worker environment (`cache_prune.env_vars`, default `TURBO_CACHE_DIR`), refuses one that is not an absolute path or resolves outside the product's state dir, groups the directory's children into entries by stem, ages each by `max(atime, mtime)`, removes those past `max_age_days` (7) and then the oldest until the directory fits `max_size_gb` (10) — never one used inside `min_age_min` (60), never more than `per_pass`, never a directory child — prints one line per pass, writes `caches.json`, and is called last in `step_health.run` through a wrapper that swallows everything — acceptance: `python3 -m unittest -v tests.test_cache_prune.PrunePass tests.test_cache_prune.CachePruneConventions tests.test_tick_steps.HealthStepTests.test_the_cache_pass_runs_and_a_failure_never_stops_the_step`
- S-52355: The doctor carries the cache directory's size — `doctor.check_caches` renders `caches.doctor_line(product)` off `caches.json` alone, measuring and touching nothing: the size, the entry count, what the last pass removed and when; red when a directory was refused, is still over its cap, or something could not be removed; absent before the first pass and for a product with no cache directory — acceptance: `python3 -m unittest -v tests.test_cache_prune.CacheDoctorRow`
- S-52356: The hit rate proves the cache pays — `caches.hit_rate` sums the newest `summary_max` (20) run summaries under `<worktrees>/*/<summary_glob>` inside `summary_window_h` (24), accepting `execution.{attempted,cached}` or `tasks[].cache` rows and counting the files it can read as neither; the rate goes in the pass's line and in a new `Caches` row in `asf status`, and says `no run summaries` plainly when the sessions write none — acceptance: `python3 -m unittest -v tests.test_cache_prune.CacheHitRate`
