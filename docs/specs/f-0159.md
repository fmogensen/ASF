# F-0159 — a rehearsal is a document, so it must not carry a clock

The scorecard filed this card on a product cause: `gate:--- test_dry_run: FAILED (rc N)`, 6 red
runs a week against a threshold of 3, **12 of 12 landing gates red over 14 days, 126 runner
minutes**. That key is not a CI job. It is the *local landing gate* — `asf/harvest/harvest.py`'s
`product_gate`, run by the lane on every set of branches it tries to land, whose first failing
line is written into `gates.jsonl` and read back by the scorecard. So the reading means: for two
weeks, nothing could land, and the first red module to finish was always `tests/test_dry_run.py`.

The mechanism has been in the record five times over, under five different Bugs, each time
recorded as somebody else's flake:

> **I1 — the gate's red is a real flake in `tests/test_dry_run.py:76`, and it will keep stopping
> lanes that have nothing to do with it.** … that output contains
> `f'gate: {count[0]} modules, {time.monotonic() - started:.0f}s, {verdict}'` — an unnormalized
> wall clock. Under load the two runs print `1s` and `3s` and the test fails on a diff that says
> nothing. — `docs/reviews/2-b-0132.md:49`

`tests/test_dry_run.py` asserts that two back-to-back `asf tick --dry-run` runs print the same
thing. That is the right thing to assert: a rehearsal that answers a different question each time
you ask it is not a rehearsal. But the transcript it compares carries two lines whose content is a
wall clock, so the assertion is a coin flip weighted by host load — and when it comes up red, the
landing gate is red, every branch waits, and the next session reads it as its own defect and
re-runs the suite to find out otherwise. `docs/reviews/1-b-0110.md`, `1-b-0115.md`, `2-b-0099.md`,
`1-b-0128.md`, `1-b-0136.md`, `2-b-0132.md` and `3-b-0114.md` each paid for that.

**T-0087 (`1df21cb0a`, 2026-09-26) already stopped the bleeding** — two days before this card was
filed, at the very tail of its 14-day window. It did it by freezing `time.monotonic` for the
duration of both dry runs, inside the test. That works, and P1 below shows the module green here
now. It also means the card's number rests on a monkeypatch: the product still prints a wall clock
into a document it promises is reproducible, the freeze is process-wide rather than local to the
line it was aimed at (P4), and the next duration token anyone prints into the rehearsal is a
1-in-N gate failure again with no test to catch it.

This card finishes the job the other way round: **the rehearsal's transcript becomes a function of
the record, in the product** — then the freeze comes out, the test passes because the thing under
test is deterministic rather than because the clock stopped, and a fence keeps it that way.

### In

- **A rehearsal's gate line carries no duration.** `product_gate` gains one keyword, `timing=True`
  (not `timed`: its own inner closure is already called that, P3). With `timing=False` the line is
  `gate: <n> modules, <verdict>` — the same line with the seconds token and its comma removed,
  nothing else changed. The flag is threaded from `lane.dry_run` through `confirmed_group`,
  `gate_groups` (including both recursive calls) and `red_on_trunk`, exactly as `ledger` already
  is (P9).
- **The live gate is untouched.** `timing` defaults to `True`, so every non-rehearsal caller — and
  every one of P8's four assertions — reads the identical line it reads today.
- **The seconds stay in the record.** Unchanged: `gate_groups` keeps timing its own gate for the
  `ledger` callback, `gates.jsonl` keeps its `seconds` field, and the scorecard keeps summing
  runner minutes out of it (P7).
- **T-0087's clock freeze comes out.** `tests/test_dry_run.py`'s `dry_runs` drops
  `mock.patch.object(harvest_mod.time, 'monotonic', return_value=0.0)` and compares the real
  transcript. The docstring sentence that justified the pin goes with it.
- **A fence on the transcript.** The same test asserts that no line of the rehearsal matches a
  duration token, so the next clock printed into the rehearsal fails a test that names the reason
  instead of failing the landing gate one run in N.

### Out

- **The cause grouping is not changed.** `_sig_class` folding digits to `N`, and
  `first_failing_line` picking the first red module to *finish* (P6), together mean one fast flaky
  module hides every slower red one behind it and the same key cannot distinguish two unrelated
  failures in the same file. That is real and it is a different card: regrouping causes has to keep
  the old key readable, or every card already filed under the old key becomes unverifiable.
- **No per-module timeout is added to `tools/run_tests.py`** (P5). A hang is a different signature
  and a different cause key; nothing in this card's reading is one.
- **The wall clock is not pinned anywhere**, in the product or the test. That is the thing being
  removed, not relocated.
- **The `metrics/daily/<day>.md` date in the transcript's first `git diff --stat` line (P2) is left
  as it is.** Two rehearsals that straddle UTC midnight write two different daily files and their
  transcripts differ. The only fixes are to pin the wall clock — the hazard this card removes — or
  to stop the rehearsal exercising the rollup, which would make it a rehearsal of less than a tick.
  The window is a few seconds once a day and no recorded red has ever been it.
- **No new module, no new command, no new flag on the CLI surface.** Two existing files in the
  product, one existing test file, one new test class beside the assertions it pairs with.

## The design

### 1. `product_gate` learns whether it is being timed

`asf/harvest/harvest.py`, `product_gate` — one keyword, one branch inside the closure that already
formats the line. The keyword is `timing`, not `timed`, because the closure is already called
`timed` (P3) and a parameter of that name would shadow it:

```python
def product_gate(tmp, conv, asf_repo, out=None, only=None, timing=True):
    """``(ok, first failing line, files, red modules)``: … ``out`` gets one timing line per gate:
    ``gate: <n> modules, <s>s, red: …``. With ``timing=False`` — a rehearsal, ``asf tick
    --dry-run`` — that line carries no duration (``gate: <n> modules, red: …``): the rehearsal's
    transcript is compared run against run, and an elapsed time is the one token in it that is not
    a function of the record. The gate's real duration still reaches ``gates.jsonl`` through
    :func:`asf.harvest.lane.gate_groups`'s own clock."""
    ...
    def timed(verdict):
        if out:
            secs = f'{time.monotonic() - started:.0f}s, ' if timing else ''
            out(f'gate: {count[0]} modules, {secs}{verdict}')
```

The closure keeps its name and all three of its call sites unchanged — `timed('timed out')`
(`asf/harvest/harvest.py:882`), `timed(verdict)` (`:888`) and `timed('green')` (`:890`) — only what
it formats changes. `started = time.monotonic()` stays where it is: it is still read for
`timing=True`, and reading it unconditionally keeps the function's one clock call in one place.

### 2. The flag reaches it the way `ledger` already does

Four signatures in `asf/harvest/lane.py`, each gaining `timing=True` as a keyword with a default,
and each passing it on:

```python
def red_on_trunk(tmp, trunk, conv, asf_repo, out, modules=None, timing=True):
    ...
    ok, line, _files, _red = H.product_gate(tmp, conv, asf_repo, out, only=modules, timing=timing)

def gate_groups(tmp, trunk, entries, conv, asf_repo, hold, out, announce=False, only=None,
                trunk_green=False, ledger=None, timing=True):
    ...
    ok, line, files, red = H.product_gate(tmp, conv, asf_repo, out, only, timing=timing)
    ...
        if red_on_trunk(tmp, trunk, conv, asf_repo, out, red, timing=timing):
    ...
    return (gate_groups(..., ledger=ledger, timing=timing)
            + gate_groups(..., ledger=ledger, timing=timing))

def confirmed_group(tmp, trunk, entries, conv, asf_repo, hold, out, announce=True, ledger=None,
                    timing=True):
    ...
        groups = gate_groups(tmp, trunk, candidates, conv, asf_repo, hold, out,
                             announce=announce, ledger=ledger, timing=timing)
```

and the one caller that has `lane` in scope, `gate_one_set` (`asf/harvest/lane.py:2744`), is the
only place the value is decided:

```python
    timing = not lane.dry_run
    ...
                landing_set, sha, deferred, unconfirmed = confirmed_group(
                    tmp, trunk, pending, conv, asf_repo, hold, out, announce, ledger, timing)
                ...
                            trunk_red = red_on_trunk(tmp, trunk, conv, asf_repo, out,
                                                     timing=timing)
```

`gate_groups`'s recursion is a bisection, so both recursive calls must carry it or a bisecting
rehearsal prints a clock in the lines it bisects into. Nothing else in the file reads it.

**What it looks like when it is there.** The rehearsal's transcript (P2) stays eleven lines, with
its two gate lines reading:

```
gate: ? modules, red: tests
gate: ? modules, red: tests
```

and every line in it a function of the record. A live harvest's log is byte-identical to today's.

### 3. The test compares the real transcript, and fences it

`tests/test_dry_run.py`, `DryRun.dry_runs` — the `mock.patch.object` and the docstring sentence
that justified it both go. Two import consequences, both in this file: `from asf.harvest import
harvest as harvest_mod` inside `dry_runs` was there only to reach the clock and becomes unused, so
it goes with the pin; and `import re` joins the module's stdlib imports for the fence below.
`from unittest import mock` stays — `DryRunHostPressure` uses it throughout.

```python
    def dry_runs(self):
        """``(before, after1, after2, lines1, lines2)`` — two ``dry_run.run`` calls back to back,
        under the factory's own environment (:meth:`Factory.seams`), and the real state
        directory's checksum before and after each. No clock is pinned: a rehearsal's transcript
        carries no wall clock (:func:`asf.harvest.harvest.product_gate`'s ``timing=False``), so
        two runs a second apart on a loaded host print the same bytes."""
        ...
        with self.f.seams():
```

and `test_never_touches_real_state_and_is_idempotent` gains the fence beside the comparison it
protects, so it runs under both landings (`DryRunReadyPR` and `DryRunReadyFF`) without a second
pair of dry runs:

```python
        self.assertEqual(lines1, lines2, 'two dry runs printed different things')
        # a rehearsal is diffed run against run: no line of it may carry a wall clock (F-0159)
        self.assertFalse([l for l in lines1 if re.search(r'\b\d+(\.\d+)?s\b', l)], lines1)
```

### 4. What the new tests prove

`tests/test_harvest.py`, a new `GateTimingLineTests` inside `ProductHarvestTests`' file and using
its `runner_product`/`gated` harness (`tests/test_harvest.py:1113`, `:1245`), paired with P8's
existing live assertions:

- `test_a_rehearsals_gate_line_carries_no_duration` — a `run_product_harvest(..., dry_run=True)`
  over one ready lane branch: every line starting `gate: ` matches
  `^gate: \S+ modules, (green|red: .+)$`, and none of them matches `\d+s`.
- `test_a_live_gate_line_still_carries_its_duration` — the same harness with `dry_run=False`:
  every such line matches `^gate: \S+ modules, \d+s, (green|red: .+)$`, which is P8's shape
  restated as a positive so the two halves of D4 sit next to each other.
- `test_the_ledger_still_records_the_gates_real_seconds` — in `GateLedgerTests`
  (`tests/test_harvest.py:2707`), the `gates.jsonl` line a gate writes still carries a `seconds`
  field measured by `gate_groups`' own clock (P7), so D2 is proved to cost the record nothing.
