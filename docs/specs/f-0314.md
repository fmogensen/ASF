# F-0314 — the leftover on the factory floor

Two open pull requests on the reporting product name items the record holds `Closed`. Neither will
ever move again. `#766` (`worker/T-0266`, open since 10-05) carries one patch the trunk does not
have; its item was closed by a different PR's merge. `#1082` (`worker/T-0833`) carries nothing the
trunk lacks; its item was closed by the `reconciled` rule off a typed `landed:`. Every tick the
branch census prints the same line for the first:

```
stray worker/T-0266 1 patch(es) not on origin/main, never landed — no worktree
```

The lane does not close them because the one function that asks "is this branch's card over?"
answers only for Bugs. `asf/harvest/lane.py:1253-1261`:

```python
def superseded_by(items, item):
    """The state that supersedes a branch, or None: a removed card (B-0065) or a Bug the record
    holds Closed/Resolved (B-0057)."""
    card = (items or {}).get(item or '') or {}
    if card.get('removed'):
        return 'removed'
    if card.get('type') == 'bug' and card.get('state') in ('Closed', 'Resolved'):
        return card['state']
    return None
```

`T-0266` is a Task, so the answer is `None`, so `next_state` never reaches its `closed` row, so the
branch walks on to `GATE` — and the gate cannot land a card that is already `Closed`. Retention
cannot delete the branch either: an open PR holds it (`asf/workers/retention.py:288-289`). The PR
holds the branch, the branch holds the census line, and nothing holds the PR. That is the leftover
the card names.

The card's requirement is one rule, and its guard: **an open factory PR whose item the record holds
`Closed` is closed by the lane when the trunk itself carries that item's work, and left alone —
reported once — when it does not.** The evidence is the trunk's, never the card's state on its own:
a `Closed` card with real unlanded work on its PR is a question for a person, not a branch to
archive unseen.

## Decisions

### Preconditions — measured in this worktree at `5b2a8f0`, 2026-10-08

* **P1 — the predicate answers only for Bugs.** With
  `items = {'T-0266': {'type': 'task', 'state': 'Closed', 'landed': 'a102bc8'}, 'B-0057': {'type': 'bug', 'state': 'Closed'}}`:
  `lane.superseded_by(items, 'T-0266')` is `None`; `lane.superseded_by(items, 'B-0057')` is
  `'Closed'`. `lifecycle.closed_state(items, 'T-0266')` is `'Closed'` — the record's own reading,
  any type, already on the trunk at `asf/workers/lifecycle.py:1582-1592`.

* **P2 — so the PR walks to the gate, not to STALE.** `next_state` on a `PR_OPEN` record with
  `pr={'number': 766, 'state': 'OPEN'}`, `ahead=1`, `review_required=False`:
  with `closed=None` (what a `Closed` Task gets today) it returns `('GATE', 'review: none')`;
  with `closed='Closed'` (what a `Closed` Bug gets) it returns
  `('STALE', 'T-0266 is Closed in the record')`. One field decides it, and the type sets the field.

* **P3 — an empty branch never reaches the `closed` row at all, Bug or not.** `next_state`'s
  `if f.get('empty'): return keep` (`asf/harvest/lane.py:1510`) sits *above*
  `closed = f.get('closed')` (`:1512`). With `ahead=0`, an open PR and `closed='Closed'` the answer
  is `('PR_OPEN', 'PR #1082')` — unchanged, every tick. The `empty` fact comes from
  `empty_branch_landed` (`:1234-1251`), which refuses to land a branch *because* its PR is open
  (`return False, f"its PR #{pr.get('number')} is still open"`). The open PR is both the thing that
  blocks the landing and the thing the landing would have closed. This is `#1082`'s half of the
  defect, and it bites a `Closed` Bug exactly as hard as a `Closed` Task.

* **P4 — the trunk's own answer already exists and is already trusted at seat time.**
  `item_on_trunk(repo, trunk, item)` (`asf/harvest/lane.py:1221-1231`) returns the first commit on
  `origin/<trunk>` whose subject names the item as a token (`githooks.names_item`). Its one
  production caller is `asf/tick/step_wave.py:916`, where it is enough to close a Task before its
  session is ever launched (`a commit on origin/main names <id> — closed by trunk, not launched`).

* **P5 — the card's own typed `landed:` sha reaches the lane with no git call.**
  `build_index_data` writes `entry = dict(typed)` (`asf/record/core.py:404-406`), so every typed
  frontmatter key — `landed:` among them — is in `index.json`, which is exactly what
  `health.record_items` loads into `Lane.items` (`asf/workers/health.py:99-111`). `#1082`'s item was
  closed by `closing`'s `reconciled` rule, whose input is that sha.

* **P6 — closing the PR is what releases the branch to retention.** `candidates` only ever
  considers `archive/` and legacy-prefix heads (`asf/workers/retention.py:270-276`: every other head
  `continue`s), and `census` classes a head an open PR carries as `held` before any other rule
  (`:194-195`). `settled_reason` (`:245-259`) already calls a head whose id is `closed_state`-done
  settled, whatever its type — so retention already wants this branch gone and the open PR is the
  only thing in its way.

* **P7 — the `stray` line keys on one registry field.** `prune_branches`
  (`asf/workers/health.py:783-806`) builds `landed = {b for b, r in by_branch(registry).items() if
  r.get('harvested')}`; a branch not in it, not on the trunk and held by no worktree is printed
  `stray`. `Lane.archive` writes `harvested=SUPERSEDED` on the run (`asf/harvest/lane.py:2561`), so
  an archived branch is in `landed` and prints `stale` (or `pruned` with `--fix`) instead.

* **P8 — the hygiene view is a table plus a branch.** `pr_hygiene.LANES`
  (`asf/harvest/pr_hygiene.py:30-37`) is documented as "the whole vocabulary a product's rule check
  switches on, in one place (F-0119, D5/D6) … adding one is a row here and a branch in `rows`".
  Today it holds two rows, and `rows` reads nothing but the lane record.

* **P9 — the orphan path already answers for any type, and a landed test holds it there.**
  `orphan_facts` (`asf/harvest/lane.py:2075-2076`) reads
  `superseded_by(...) or (card.get('state') if card.get('state') in ('Resolved', 'Closed') else None)`
  — so a run-less branch of a `Closed` Task *is* closed and archived today, with no trunk evidence
  asked for, and `tests/test_lane.py::Orphans::test_a_done_card_closes_the_pr_with_a_comment_and_archives_the_branch`
  asserts exactly that on a branch whose patch the trunk does not carry.

### In

* One predicate for "the trunk carries this item's work", with two evidence sources: the card's
  typed `landed:` sha when the trunk carries it, and a commit on the trunk whose subject names the
  item as a token.
* The lane's `closed` fact widened, on the run-held branch path only, to a card of **any** type the
  record holds `Closed`/`Resolved` — and only with that evidence in hand.
* The `empty` short-circuit in `next_state` yielding to a decided `closed` fact (P3).
* The PR closed with a comment naming the trunk commit and the archive ref; the branch archived and
  deleted by the mechanism that already does it (`Lane.archive`), so retention expires the archive
  head on its own days.
* A `Closed` card with no trunk evidence: the PR left open, one line printed, one mark written on
  the lane record, and one `CLOSED → DECIDE` row in the PR-hygiene view.

### Out

* **The orphan path is not touched** (P9, D8). A branch no run holds answers a different question
  and keeps its own bar.
* `superseded_by`'s Bug rule, its text and B-0057's tests: unchanged (D3).
* Reopening, regrooming or re-stating the card. The record's state is read here, never written.
* The `covers` arm of `trunkclose`'s evidence (a `writes:`-only match). A footprint overlap is not
  a landing (D2).
* Closing a PR whose item is not `Closed`/`Resolved`. Every other reason a PR closes stays with the
  lane state that owns it.
* A PR the factory did not open (`f['foreign']`) — never closed by this rule (D7).
* The doctor rows, the scorecard counters and `clutter:branches`. They read the census, and the
  census answer changes on its own once the PR is closed (P6).

### Preconditions the work depends on

* `Lane.items` is the record's `index.json` index and carries typed frontmatter keys (P5). With no
  index (`record_items` returns `None`) the predicate answers `None` and nothing is closed.
* `Lane.repo` and `origin/<trunk>` are readable in the product's checkout: `item_on_trunk` is a
  `git log` on it. An unreadable trunk is no evidence, so the PR is reported, never closed.
* The lane runs in `pr` mode with a host that answers `close` (`Lane.close_pr` is a no-op without
  one), and `Lane.archive` can push a ref (its existing `held` line covers the failure).
* `githooks.names_item` is the one naming rule, shared with the `commit-msg` hook.

| D2 | Two evidence sources: the typed `landed:` sha the trunk carries, then a trunk commit naming the item | A naming commit only | The two live PRs need one each: `#766` has a naming commit and no typed sha, `#1082` was closed by the `reconciled` rule off a typed sha (P5). ## The design

### 1. `asf/harvest/lane.py` — the predicate, beside `superseded_by`

Two module-level functions, no I/O in the first, one `git log` at most in the second.

```python
def closed_in_record(items, item):
    """``'Closed'``/``'Resolved'`` when the record holds ``item``'s card in that state, whatever
    its type (:data:`asf.workers.lifecycle.DONE_STATES`), else None. Not by itself a reason to
    close a branch or its PR — :func:`trunk_landing` is what decides that (F-0314, D1)."""


def trunk_landing(repo, trunk, items, item):
    """``(sha, why)`` — the trunk's own evidence that ``item``'s work landed, else ``('', '')``:

      * the card's typed ``landed:`` sha, when ``origin/<trunk>`` carries that commit — the sha
        ``closing``'s ``reconciled`` rule closed the card on (F-0314, P5); then
      * the first commit on ``origin/<trunk>`` whose subject names ``item`` as a token
        (:func:`item_on_trunk`) — the item landed under another card's PR.

    Timid by construction: an unreadable trunk, an index that is None and a card with neither
    answer are all ``('', '')``, and nothing closes on that."""
```

`why` is the clause the PR comment and the lane record carry: `` `<sha9>` on main carries its typed
landed: `` for the first arm, `` a commit on main names <item> `` for the second.

`superseded_by` is not edited.

### 2. `asf/harvest/lane.py` — the fact, on the run-held branch path

`Lane.branch_facts` keeps `f['closed'] = superseded_by(self.items, item)` (`:1860`) and gains, right
after it, the widening the card asks for — reached only when `superseded_by` said nothing:

```python
if not f['closed'] and not f.get('foreign'):
    state = closed_in_record(self.items, item)
    if state:
        sha, why = trunk_landing(self.repo, self.trunk, self.items, item)
        if sha:
            f['closed'], f['closed_sha'], f['closed_why'] = state, sha, why
        else:
            f['undecided'] = state
```

Two moves make it reach both live PRs:

* the block is hoisted **above** the `f['ahead'] == 0` early return (`:1852-1857`), so an empty
  branch gets the fact too (P3, D6) — the `empty` fact is still computed and still written, it just
  no longer wins;
* `next_state`'s empty row becomes `if f.get('empty') and not f.get('closed'): return keep`
  (`:1510`), so a decided `closed` fact is read on an empty branch.

Nothing else in `next_state` changes: its `closed` row (`:1523`) already returns
`(STALE, f'{f.get("item")} is {closed} in the record')`, and `f['on_trunk']` is still tried first,
so a branch whose own diff the trunk carries still lands as `method=on-trunk` rather than
superseding.

### 3. `asf/harvest/lane.py` — the reason, and the comment that names the commit

`Lane.enter`'s `STALE` arm (`:2429-2440`) builds its `why` from the fact instead of inlining it:

```python
    def closed_why(self, f):
        """The STALE reason for a branch whose card the record holds done: the card's state and,
        when the lane proved it, the trunk commit that carries the item's work (F-0314, AC1)."""
        closed, item = f.get('closed'), f.get('item')
        if not closed:
            return None
        said = f'{item} is {closed} in the record'
        return f"{said}; {f['closed_why']}" if f.get('closed_sha') else said
```

so `enter` reads `why = f.get('orphan') or self.closed_why(f)` and everything downstream is already
built:

* `Lane.archive` makes the `archive/<branch>` commit, writes the `STALE` record with
  `harvested=SUPERSEDED`, closes the PR with
  `Closed by the factory lane: <why>. The branch is kept as `archive/<b>` (<sha7>).` and deletes the
  branch on origin (`:2536-2575`);
* `unclaimed_legacy`/`drop_legacy` still divert a legacy-prefix branch no card claims to an outright
  delete (`:2577-2594`) — "archived or deleted per branch retention" (AC2) is this fork, unchanged;
* `harvested=SUPERSEDED` is what takes the branch out of the `stray` class (P7), and the deleted
  head is what takes it out of `held` so retention can expire the archive (P6).

### 4. `asf/harvest/lane.py` — the decision, written once

```python
    def note_undecided(self, f):
        """A card the record holds done whose work the trunk does not carry: the PR is left where
        it is and the fact is written once on the lane record as ``decide`` — with one line the
        first time, and cleared when the fact goes away (the card reopened, or the trunk caught
        up). F-0314, AC3: the lane never closes a PR it cannot account for."""
```

Called from `Lane.advance`, after its transition loop and before `return moved`, when
`f['undecided']` is set and the record's state is still one of `OPEN_STATES`. The mark is

```json
"decide": {"state": "Closed", "at": "<iso>", "why": "<item> is Closed in the record but no commit on main carries its work"}
```

written with `self.write(f, rec)` on the record as it stands — the `delete: owed` pattern (D4), so
no state moves and no `lane:` transition line is printed. The line, printed only when the mark is
new or its `why` changed:

```
decide worker/T-0266: T-0266 is Closed in the record but no commit on main carries its work — PR #766 left open
```

A later pass that finds the fact gone (the card reopened, or the trunk caught up) drops the key and
says so once: `decide cleared worker/T-0266: <why it went>`.

### 5. `asf/harvest/pr_hygiene.py` — the row

One constant, one row in `LANES`, one branch in `rows` (P8):

```python
CLOSED_DECIDE = 'CLOSED → DECIDE'

LANES = {
    STALE_CLOSE:     ('stale', 'close'),
    CONFLICT_REBASE: ('conflict', 'rebase'),
    CLOSED_DECIDE:   ('closed', 'decide'),
}
```

and, in `rows`, after the `BACK kind=conflict` branch:

```python
        elif rec.get('decide'):
            out.append({'kind': CLOSED_DECIDE, 'branch': branch, 'item': rec.get('item'),
                        'pr': rec.get('pr'), 'why': (rec['decide'].get('why') or ''),
                        'since': rec['decide'].get('at') or rec.get('at')})
```

`since` is the mark's own `at`, not the record's: the question is how long the decision has been
waiting, not how long the branch has been in `PR_OPEN`. `_entries`, `render`, `main` and the
`--lanes` contract are untouched, and a `decide` mark with no PR number is left out of the listing
by the rule that is already there (F-0119, D4).

### What it looks like when it is there

On the reporting product's next tick, with `T-0266` `Closed` and `a102bc8` on `main`:

```
prs: closed PR #766 — Closed by the factory lane: T-0266 is Closed in the record; a102bc8f on
  main names T-0266. The branch is kept as `archive/worker/T-0266` (4e1c2ab).
superseded worker/T-0266: T-0266 is Closed in the record; a102bc8f on main names T-0266 —
  archived as archive/worker/T-0266
```

and the census line for it, next pass:

```
stale worker/T-0266 landed by the lane (superseded)
```

`asf pr-hygiene` holds nothing for it any more. For a `Closed` item the trunk cannot account for:

```

```

```

CLOSED → DECIDE  worker/T-0999 (T-0999) PR #880 — T-0999 is Closed in the record but no commit on main carries its work
$ asf pr-hygiene --lanes
{"action": "decide", "branch": "worker/T-0999", "lane": "closed", "pr": 880, "since": "2026-10-09T04:12:00Z"}
```

printed once, and the PR still open.

## Records

Nothing in the record is written by this change. What it writes down:

* **The lane record** (`<state>/sessions.jsonl`, the run's `lane:` object) — for a closed PR, the
  terminal `STALE` record the archive already writes, its `reason` now carrying the trunk commit:
  `T-0266 is Closed in the record; a102bc8f on main names T-0266`; `harvested: superseded` and
  `correction: null` beside it on the run (`Lane.archive`, unchanged).
* **The `decide` key** on the lane record of an undecided branch —
  `{"state": "Closed", "at": "<iso>", "why": "<text>"}` — written once, rewritten only when `why`
  changes, removed when the fact goes. It is the only new field this change adds anywhere.
* **The archive ref** `archive/<branch>` at the branch's tip, over one `[skip ci]` commit whose
  subject is `archive(<item>): <branch> — <why>; superseded, kept for reference` — the existing
  shape, with the trunk commit now inside `<why>`.
* **The PR comment**, on the closed PR: `Closed by the factory lane: <why>. The branch is kept as
  `archive/<b>` (<sha7>).` — AC1's "a comment naming the trunk commit", and D10's way back.
* **The lane's output lines** — `prs: closed PR #<n> — …` and `superseded <b>: … — archived as
  archive/<b>` (both existing), and the new `decide <b>: … — PR #<n> left open` /
  `decide cleared <b>: …`.
* **The hygiene rows** — one `CLOSED → DECIDE` row per undecided PR from `asf pr-hygiene`, and one
  `{"action": "decide", "lane": "closed", …}` entry in `--lanes`.
* **The census line that stops** — `prune_branches` prints `stale`/`pruned` instead of `stray` for
  the archived branch, because the run now carries `harvested` (P7). Nothing is written to make that
  happen; it is the archive's own record read by a second reader.

## Stories

Five Stories, one per section of `## The design`, each declared below as a `### S-…: <title>`
heading with its acceptance lines under it — the form `asf.record.idcheck.declared_stories` reads
and `asf.record.plan_tasks` mints the card from, so a cited id with no declaration here would be a
phantom and the plan citing it refused whole. The ids come from this session's block
`S:84505-84554`, taken from its floor upward; the record holds no Story for F-0314 yet, so none is
reused and nothing below is renumbered.

Each acceptance line is one physical line of plain text with no backticks: the reader is
line-anchored (`CHECKBOX` matches a single line) and `_prose` replaces every inline code span with
one space before parsing, so a wrapped line reaches the minted card truncated and an identifier
inside backticks reaches it missing.

One Story below is a pin rather than a change: the fifth asserts that the `stray` line stops and
that the orphan path still closes what it closes today (D8, P9). Both halves of it are mechanisms
this change must leave working, not mechanisms it builds.

- S-84505: one owner for "the trunk carries this item's work", with two evidence sources and no guess — acceptance: `python3 -m unittest tests.test_closed_item_prs.TrunkEvidenceTests`
- S-84506: a Closed item's open PR the trunk accounts for is closed, its comment naming the trunk commit — acceptance: `python3 -m unittest tests.test_closed_item_prs.ClosedItemPRTests`
- S-84507: a Closed item's open PR the trunk cannot account for is left open and reported once — acceptance: `python3 -m unittest tests.test_closed_item_prs.UndecidedReportTests`
- S-84508: the PR-hygiene view lists that PR in a closed lane whose action is decide — acceptance: `python3 -m unittest tests.test_pr_hygiene.ClosedDecideRows`
- S-84509: the stray line stops for the archived branch, and the orphan path keeps its own bar — acceptance: `python3 -m unittest tests.test_closed_item_prs.NoMoreStrayTests tests.test_lane.Orphans`

### S-84505: one owner for "the trunk carries this item's work", with two evidence sources and no guess

Design §1 — `closed_in_record` and `trunk_landing`, beside a `superseded_by` that is not edited
