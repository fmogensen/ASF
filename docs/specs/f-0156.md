# F-0156 — the factory deletes a head whose work the record says is finished, and shows its working for the rest

The scorecard filed this card off one number: `clutter:branches`, 711 against a threshold of 40.
That number is every head on origin but the trunk that no open PR carries
(`asf/scorecard/facts.py:419-424`). Seven hundred of them is not a tidiness problem; it is the
factory losing track of what it made.

Two reapers exist and neither can move that number far:

- **The lane** judges a head only when its name carries a branch prefix the product mints
  (`names = {b for b in heads if conv.branch_kind(b) and b != trunk}`,
  `asf/harvest/lane.py:1252`). Every other head — a retired worker system's, a hand-made
  `integration/…`, another tool's — is outside the state machine entirely.
- **Retention** deletes exactly two namespaces: `archive/<b>` after `archive_days` (14) and a
  head under a configured `legacy_prefixes` after `legacy_days` (7). `legacy_prefixes` is empty
  by default (`asf/conventions.py:278-279`), so out of the box the second rule reaps nothing.
  Everything else retention only *counts*, as `unowned`, and prints in a doctor row
  (`asf/workers/retention.py:145-162`).

So the namespace is covered by prefix rules, and a prefix rule only ever covers what somebody
remembered to enumerate. Meanwhile the record already knows, for most of those heads, that their
work is finished: the id in the branch name is a card, and the card is `Closed`, `Resolved` or
removed. And git already knows, for others, that the trunk carries every commit they hold.
Neither fact is read by either reaper.

There is a second, quieter problem. The doctor's `branches` row says `unowned branches: 1` while
the scorecard says `711`, because they count different sets — the row counts only the heads no
pattern owns, and the metric counts every head without an open PR, `archive/*` included. An
operator handed this card has no breakdown of the 711 to act on, and no way to tell which of them
a rule would ever take.

This card is three things:

- **a census** — every head on origin classified by the rule that covers it, over exactly the set
  `clutter:branches` counts, so the 711 becomes a table;
- **a `settled` rule** — a head the trunk already carries, or whose card the record has closed,
  expires like any other and is deleted, whatever prefix it wears;
- **an off switch** — `settled_days`, a `branch_retention` key an operator can set to `0`.

What it deliberately does not do is delete a head the trunk does not carry and no card claims.
That residue stays, and the census names it by prefix — which is the line an operator needs in
order to write one `legacy_prefixes:` entry for a retired system and have the existing rule take
the rest.

### In

- **`asf/workers/retention.py`** — a whole-namespace tip read (`tips`), a census over every head,

  the state file.
- **`asf/conventions.py`** — `settled_days` in `DEFAULT_BRANCH_RETENTION`, its doc sentence, and

- **`asf/doctor.py`** — `check_branches`'s docstring only; the row itself is a pass-through (P9).
- **`tests/test_retention.py`**, **`tests/test_conventions.py`**, **`tests/test_doctor.py`** — the
  fixture heads and the cases below.

### Out

- **Deleting a head the trunk does not carry and no card claims.** Never, at any age, under any
  key. That head may hold the only copy of real work, and no fact available to the sweep says
  otherwise. It stays, and the census names it. This is the line that keeps the whole rule safe,
  and it is why this card cannot promise a number on its own (see D6).
- **Narrowing what `clutter:branches` counts.** Excluding `archive/*` from `forge_clutter` would
  move the number by a third in this repo's own shape (25 of 71 heads) and change nothing on
  origin. An archive head *is* clutter. `asf/scorecard/facts.py` is not touched.
- **Moving the threshold.** `THRESHOLDS['branches']` stays 40.
- **The lane's T12o orphan path** (`Lane.orphan_facts`, `Lane.archive`, `drop_legacy`). Retention
  is the net under the lane, not a second lane (D3). No file under `asf/harvest/` changes.
- **A new command or flag.** No `asf` surface row, no `--reap`. The sweep already runs every tick
  (P10).
- **`per_tick`, `archive_days`, `legacy_days`, `legacy_prefixes`.** Unchanged, defaults included.
- **F-0067's `asf/floor.py` restructure.** This card lands in `retention.py` where the code is
  today; whoever lands second rebases (D7).

## The design

Three pieces, in dependency order: the convention (`settled_days`), the census (`tips`, `census`,
the doctor line), then the rule that reads both.

### `asf/conventions.py` — one key and its off switch

`DEFAULT_BRANCH_RETENTION` gains `settled_days`, and the two `least` expressions gain a second
zero-accepting key:

```python
#: Keys whose 0 means "off", not "malformed".
ZERO_OK = ('per_tick', 'settled_days')

DEFAULT_BRANCH_RETENTION = {'archive_days': 14, 'legacy_prefixes': [], 'legacy_days': 7,
                            'per_tick': 50, 'settled_days': 7}
```

`_retention_problems` (`:605-622`) and `Conventions.retention` (`:938-953`) each replace their
`least = 0 if key == 'per_tick' else 1` with `least = 0 if key in ZERO_OK else 1`. Nothing else in
either function names a key, so a new whole-number key needs no other edit (P7).

The doc comment above `DEFAULT_BRANCH_RETENTION` gains one sentence. **Its first line —
`` #: ``branch_retention:`` — how long origin's heads nobody owns any more are kept `` — stays
byte-identical**, because `tests/test_security_paths.py` slices the source up to exactly that
string (P8):

```
#: ``settled_days``: a head whose work is over — the trunk carries every commit on it, or the
#: card its name names is done or removed in the record — goes this many days after its tip was
#: committed, whatever prefix it wears. 0 turns that rule off.
```

### `asf/workers/retention.py` — the census

`tip_dates(repo, prefixes)` (`:59-76`) becomes `tips(repo, trunk)`: one fetch of the whole heads
namespace, one `for-each-ref` for `(sha, committer time)`, one `for-each-ref --merged` for
containment, then `_clear_ns` as today.

```python
def tips(repo, trunk):
    """``({branch: (sha, committer unix time)}, {branch the trunk already contains})`` for every
    head on origin — one fetch into :data:`FETCH_NS`, two ``for-each-ref`` reads, then the
    namespace is emptied. Containment is read in the same pass because the settled rule needs
    both facts about the same ref (D9)."""
    _clear_ns(repo)
    H.sh(['git', 'fetch', '-q', '--no-tags', 'origin',
          f'+refs/heads/*:{FETCH_NS}*'], cwd=repo)
    dates = {}
    r = H.sh(['git', 'for-each-ref', '--format=%(refname) %(objectname) %(committerdate:unix)',
              FETCH_NS], cwd=repo)
    for line in r.stdout.splitlines():
        parts = line.split()
        if len(parts) == 3 and parts[2].isdigit():
            dates[parts[0][len(FETCH_NS):]] = (parts[1], int(parts[2]))
    m = H.sh(['git', 'for-each-ref', '--merged', f'origin/{trunk}', '--format=%(refname)',
              FETCH_NS], cwd=repo)
    contained = {ref[len(FETCH_NS):] for ref in m.stdout.split()}
    _clear_ns(repo)
    return dates, contained
```

A fetch that fails leaves both empty, and every rule below skips a head with no tip — the pass
reports and deletes nothing, exactly as it does today when `ls-remote` fails.

`census` is new, beside `unowned`:

```python
#: The census's classes, in the order a head is tried against them: each head lands in exactly one.
CENSUS_CLASSES = ('trunk', 'release', 'protected', 'held', 'archive', 'legacy', 'settled',
                  'lane', 'unowned')


def census(conv, heads, prs, protected, holds, settled_of):
    """Every head on origin in exactly one class, plus ``no_pr`` — the number
    ``clutter:branches`` reads (every head but the trunk that no open PR carries,
    :data:`asf.scorecard.facts.forge_clutter`), or None when the PR list was unreadable.

    ``holds`` is the branches something still holds (an in-flight run, an open card);
    ``settled_of(b)`` is :func:`settled_reason`. The classes are tried in
    :data:`CENSUS_CLASSES` order, so a head an open PR carries is ``held`` however it is named,
    and an ``archive/`` head keeps the archive rule's days (D3)."""
```

It returns `{'total': n, 'no_pr': n or None, 'by_rule': {class: count}, 'unowned': {prefix: count},
'at': iso}` — `by_rule` carrying only the non-zero classes, `unowned` reusing `unowned(conv, heads)`
unchanged so that class and the doctor's existing wording keep their meaning.

`unowned_line` stays. `census_line` is new and is what the doctor prints:

```
branches: 711 of 712 heads carry no open PR — 402 settled, 120 archive, 88 lane, 51 unowned
(prefixes hotfix- 40, analysis/ 11), 25 held; 50 deleted, 352 expired awaiting delete
```

`doctor_line(product)` (`:312-324`) reads that off the state file instead of `unowned` alone. Its
`ok` is unchanged in meaning — green when no head is `unowned`, since that is the one class no
rule will ever take — and the row stays `required=False` (P9). Before a pass has run it still
returns `None`, and a state file written by an older binary (no `census` key) falls back to
today's `unowned_line`, so an upgrade never loses the row.

`write_state` gains `census` and `reaped`:

```python
{'at': …, 'heads': 712, 'unowned': {…}, 'deleted': 50, 'due': 352, 'kept': 25,
 'census': {'total': 712, 'no_pr': 711, 'by_rule': {…}, 'unowned': {…}},
 'reaped': [{'branch': 'worker/T-0110', 'sha': '9e4a711…', 'rule': 'settled',
             'why': 'T-0110 is Closed in the record', 'at': '2026-09-28T09:00:00Z'}, …]}
```

`reaped` is the tail of the previous pass's list plus this pass's deletes, capped at
`REAPED_KEPT = 200`, newest last (D5).

### `asf/workers/retention.py` — the settled rule

```python
def settled_reason(items, b, contained):
    """Why a head's work is over — or None, and then it is never a settled candidate.

    ``the trunk carries it``: every commit on it is already on the trunk, so the delete loses
    nothing, card or no card. ``<id> is <state> in the record``: the id token in its name is a
    card :func:`asf.workers.lifecycle.closed_state` calls done or removed — the work it was cut
    for is finished, whichever branch finished it. A head the trunk does not carry and no card
    claims is never settled: the factory deletes nothing it cannot account for (Out)."""
    from asf.harvest.lane import item_of
    from asf.workers import lifecycle
    if b in contained:
        return 'the trunk carries it'
    item = item_of(b, None)
    closed = lifecycle.closed_state(items, item) if item else None
    return f'{item} is {closed} in the record' if closed else None
```

`items` being `None` — no record index to read — makes `closed_state` return `None` for every id
(P4), so a sweep with no record only ever reaps contained heads. That is the conservative
direction and needs no extra branch.

`candidates` (`:168-202`) takes `items` and `contained`, and its rule chain gains a third arm
**after** the two existing ones so `archive/` and `legacy` keep their own days:

```python
def candidates(conv, heads, dates, now, prs, protected, flight, item_text, items, contained):
    archive_s = conv.retention('archive_days') * DAY_S
    legacy_s = conv.retention('legacy_days') * DAY_S
    settled_s = conv.retention('settled_days') * DAY_S      # 0: the rule is off (D8)
    …
    for b, sha in sorted(heads.items()):
        why = ''
        if b.startswith(ARCHIVE_PREFIX):
            rule, limit, also = 'archive', archive_s, b[len(ARCHIVE_PREFIX):]
        elif any(b.startswith(p) for p in legacy):
            rule, limit, also = 'legacy', legacy_s, None
        elif settled_s and settled_reason(items, b, contained):
            rule, limit, also = 'settled', settled_s, None
            why = settled_reason(items, b, contained)
        else:
            continue
```

Everything below that chain is untouched: the trunk / release / protected refusal, the
"a prefix the product still mints is never legacy" guard (which the settled rule does not want and
is already keyed on `rule == 'legacy'`), the moved-tip check, the age check, and the three holds —
open PR, in-flight run, named by an open card. A head under an **active** lane prefix whose card is
closed is therefore settled and reapable, which is the point: `worker/T-0110` with T-0110 `Closed`
is dead whether or not `worker/` is a prefix the product still mints.

`due` widens from `(branch, sha, rule, age_days)` to `(branch, sha, rule, age_days, why)`; its sort
key and `result['due'].extend(b for b, *_ in due[cap:])` are unaffected. In `sweep` the one
unpacking site becomes `for b, sha, rule, days, why in due[:cap]`, and `what` grows the reason:

```
retention: deleted worker/T-0110 (settled, 41d old) — T-0110 is Closed in the record
retention: would delete integration/backfill-spec (settled, 22d old) — the trunk carries it
```

`sweep`'s call site changes from `tip_dates(repo, prefixes)` to `tips(repo, product.main)`; the
`prefixes` list it built for the scoped fetch goes away, and the `prs, protected` read no longer
hangs off `if dates` — with a whole-namespace census the host is asked on every pass that reaches
this point, which is what `no_pr` needs.

### What stays exactly as it is

- `delete()` — the hosted-API path, the lease, the refguard refusal, the three-failure stop.
- `unowned()`, `unowned_line()`, `group()`, `owned_patterns()`, `in_flight()`, `open_item_text()`,
  `_names()`, `host_facts()`, `read_state()`.
- The blind-host rule: when the open-PR list or the protected list is unreadable, nothing is
  deleted and the pass only reports. The settled rule is inside that gate like the other two.
- `per_tick` 50 and the oldest-first order.
- `asf/scorecard/*`, `asf/harvest/*`, `asf/tick/step_health.py`, `sample/product.yaml`.

## Acceptance tests

All four run from the repo root with no network and no `gh`: `tests/test_retention.py` builds its

## Records

- **`<state>/branch-retention.json`** — the pass's own file, already written every pass, gains two
  keys: `census` (`total`, `no_pr`, `by_rule`, `unowned`) and `reaped` (the last 200 deletes, each
  `{branch, sha, rule, why, at}`). `at`, `heads`, `unowned`, `deleted`, `due` and `kept` keep their
  meaning, so a reader of the old shape is not broken and an older binary's file still renders a
  doctor row.
- **The doctor's `branches` row** — same name, same `required=False`, a wider detail: the number
  `clutter:branches` reads, the class breakdown, the unowned prefixes, and how many are expired
  and awaiting delete. This is the reading an operator uses to decide whether one
  `legacy_prefixes:` line would take the residue.
- **The tick's own output** — one line per delete, now carrying the reason
  (`— T-0110 is Closed in the record`, `— the trunk carries it`), and the existing summary lines
  (`N more expired, left for the next pass`, the unowned count). These are the tick's stdout, which
  the tick already commits with its log; no new stream and no new file.
- **Nothing is written to the product's record.** No card is filed, no session line is appended, no
  lane state moves. Retention's only side effects on origin are ref deletes.
- **What is *not* written**: no `archive/<b>` ref is created by this change (D2), and no branch is
  deleted that the trunk does not carry and no closed card names (Out).
