# F-0322 — the park is not kept, it is never checked against the record

The card reads the symptom off one cell of `asf status`: `status` still shows `B-1557`'s
relaunch-cap park after `B-1557` was retired. The obvious suspect is the park itself — a line in
`sessions.jsonl` nothing cleared. **It is not the defect.** The park is a fact about a run that
happened, and it is still true; what is no longer true is that it holds anything back.

Every other reader of these same parks asks the record whether the card is still on the board
before acting on one. The feeder drops the row (`rows.drop_gone`, `rows.correction_rows`,
`rows.hold_parks`), health releases the correction (`closed_state`), the wave never plans a row it
has not got. `parked_cell` (`asf/views/status.py:561-583`) is the one reader that asks the record
**nothing**: it folds the ledger, keeps everything carrying `parked`, and prints it with
`` `asf unpark <item|branch|job>` releases one ``.

So the cell is not showing a stale park. It is showing a park it never checked — and, measured
below (P5), sometimes one `asf unpark` cannot release even when the operator takes the cell's
advice, because the release paths are keyed by **job** and the job has since been reused by a run
on another item.

Measured against the reporting product's live state (P4, 2026-10-10): the cell prints **39** lines,
**9** of them on cards the record has retired or closed — five retired (`removed:`), four closed —
and three of those nine are derived in the view alone and have never appeared in NEXT (P7).

## Decisions

### What is in

* **One rule, in one place.** The expression `drop_gone` already filters its rows by
  (`asf/feeder/rows.py:2339-2340`) gets a name — `rows.closed_ids(items)` — and `drop_gone` calls
  it. No behaviour change there; it is the rule the operator already sees obeyed in NEXT.
* **`parked_cell` applies that rule** to every line it builds, from all three of its sources: a
  pending correction carrying `parked` (the relaunch cap, an empty or blocked end, a security
  hold, an item park by hand), a by-hand branch or job park, and a derived "adjudicated, card
  unchanged" stalemate park.
* **An id the record does not hold at all is kept** — `drop_gone`'s own rule: unknown is not
  closed. The live cell has one (P4: `PR-1379`, an operator park on a PR the factory did not mint).
* **With no record to read, nothing is dropped** — no `root`, or no `index.json` under it: the
  cell reads exactly as it does today, which is the contract two test modules already pin.
* **A cell whose every line is dropped is silent** (`None`, no row in the table), the same as a
  cell with nothing parked.
* The tests: the existing `ParkedCellTests` fixture is split into a `_ParkedCell` base so the new
  class can share it, as `tests/test_relaunch.py` shares `_Ledger`.

### What is out, and why

* **Clearing the park.** Nothing is written to `sessions.jsonl`, nothing is released, no
  `unparked` stamp. The card asks what `status` shows; a release writes state, and the path that
  would write it cannot reach an orphaned park at all (P5) — a real second defect, with its own
  blast radius, named in this session's report for the operator to file. Retention trims the line
  in its own time.
* **`health`'s and `asf unpark`'s reach** (`lifecycle.latest`, one record per job) is therefore
  unchanged. So is what a park *means*, when one is written, and when one lifts.
* **The feeder's rows.** They are already right (P2, P6) and are not touched.
* **No note counting the hidden lines** (a decision, below): the mention is the symptom.
* **The three other readers of `lifecycle.corrections`** — `trunkclose.parked`, `tick.land_spec`,
  `tick.widen_footprint` — are gates over items the record holds open, show the operator nothing,
  and act on no closed card (P6). Untouched.
* No new config key, no new field, no new record file, no change to `index.json`.

## The design

Two edits, 12 added lines, no new file.

### 1. The rule gets a name — `asf/feeder/rows.py`

```python
def closed_ids(items):
    """Every id the record no longer holds open: a card it retired (``removed:`` or ``moved_to:``
    — the index reader's ``retired_done``/``retired_open``) and a card whose ``state:`` is done.
    An id the record does not hold at all is never in it: unknown is not closed."""
    return set(_retired(items)) | {i for i, v in items.items()
                                   if isinstance(v, dict) and (v.get('removed') or not is_open(v))}


def drop_gone(rows, items):
    """``rows`` less every row of a card the record removed or closed (:func:`closed_ids`): a
    removed or closed item never renders a row (a product's T-0335, removed, still showed PARKED
    off a standing branch park). A row naming an id the record does not hold at all — a PR opened
    outside the factory — is kept."""
    gone = closed_ids(items)
    return [r for r in rows if r.item_id not in gone]
```

The body of `closed_ids` is `drop_gone`'s own expression, moved whole: the same `_retired`, the
same `removed:` test, the same `is_open`. `drop_gone`'s behaviour is unchanged by construction, and
`tests/test_stale_act.py:383` is what says so.

### 2. The cell reads it — `asf/views/status.py`

```python
def _closed_items(root):
    """The ids the record no longer holds open (:func:`asf.feeder.rows.closed_ids`), or ``None``
    when there is no record to read it from — no ``root``, or no ``index.json`` under it."""
    if not root or not os.path.isfile(os.path.join(root, 'index.json')):
        return None
    from asf.feeder import rows as feeder_rows
    from asf.views import index_reader as ix
    items, _generated = ix.load(root)
    return feeder_rows.closed_ids(items)
```

The same `root`/`index.json` guard `_stalemate_parks` (`status.py:549-558`) already uses, and the
same lazy import style every cell in the module uses. `None` is "there was no record to ask", which
is not the same answer as "the record holds nothing closed" — hence a tri-state, not an empty set.

In `parked_cell`, one read above the three sources and one filter below them:

```python
    path = pool_mod.sessions_path(product)
    closed = _closed_items(root)
    ...
    parked += [(iid, 'item', f"adjudicated {adj.get('runs') or 1} time(s), last "
                             f"{str(adj.get('at') or '?')[:16]}, on this same card")
               for iid, adj in sorted(_stalemate_parks(product, root).items())]
    if closed is not None:
        parked = [p for p in parked if p[0] not in closed]
    if not parked:
        return None
```

One filter under all three appends, not three filtered comprehensions: the sources disagree about
what else a line carries (a scope, a job, a branch) but agree that its first field is the item id,
and a single filter is what makes "the cell and NEXT drop the same card" one statement rather than
three. The `if not parked: return None` that follows already turns an emptied list into a silent
row, so a cell whose every line was dropped needs nothing new.

And the docstring says what it now does:

```python
    A park on a card the record has retired or closed is not shown: the feeder draws no row for
    such a card either (:func:`asf.feeder.rows.drop_gone`), so the park holds nothing back, and
    `asf unpark` may not even be able to release it (F-0322). An id the record does not hold at
    all is kept, and with no record to read (no ``root``) nothing is dropped.
```

### A2 — a retired card's park is not shown

```python
class ARetiredCardsParkIsNotShown(_ParkedCell):
    """F-0322: ``asf retire B-1557`` took the card off the board and the Parked cell kept its
    relaunch-cap park — the feeder draws no row for a retired card (``rows.drop_gone``), so the
    park holds nothing back, and when the park's job has since been reused by a run on another
    item ``asf unpark`` cannot even reach it. The cell reads the record the feeder reads."""

    OPEN = {'id': 'T-0100', 'type': 'task', 'state': 'Active'}
    RETIRED = {'id': 'B-1557', 'type': 'bug', 'state': 'Closed',
               'removed': 'retired: Superseded by B-1553 (landed af6c1a30b)'}
    MOVED = {'id': 'T-0634', 'type': 'task', 'state': 'New', 'moved_to': 'T-0615'}
    CLOSED = {'id': 'T-0200', 'type': 'task', 'state': 'Closed'}

    def _park(self, item, job, reason, at='2026-10-07T20:48:47Z'):
        return {'job': job, 'item': item, 'kind': 'correct',
                'started': '2026-10-07T20:03:19Z', 'ended': '2026-10-07T20:40:00Z',
                'correction': {'kind': 'relaunch cap', 'text': reason, 'at': at,
                               'parked': True, 'reason': reason}}

    def test_the_park_of_a_retired_card_is_dropped_and_the_open_one_is_kept(self):
        self._ledger(self._park('B-1557', 'correct-b-1557', '6 launches in 24 h'),
                     self._park('T-0100', 'correct-t-0100', 'launched 2 time(s) on 650de93e4'))
        root = self._root({'B-1557': self.RETIRED, 'T-0100': self.OPEN})
        cell = status.parked_cell(self.product, root)
        self.assertTrue(cell.startswith('1 — '), cell)
        self.assertNotIn('B-1557', cell)
        self.assertIn('T-0100 [relaunch cap on job correct-t-0100]', cell)

    def test_the_same_ledger_shows_both_while_the_card_is_open(self):
        self._ledger(self._park('B-1557', 'correct-b-1557', '6 launches in 24 h'),
                     self._park('T-0100', 'correct-t-0100', 'launched 2 time(s) on 650de93e4'))
        root = self._root({'B-1557': dict(self.RETIRED, state='Active', removed=None),
                           'T-0100': self.OPEN})
        cell = status.parked_cell(self.product, root)
        self.assertTrue(cell.startswith('2 — '), cell)
        self.assertIn('B-1557', cell)

    def test_a_moved_or_closed_card_is_dropped_too_and_an_unknown_id_is_kept(self):
        self._ledger(self._park('T-0634', 'correct-t-0634', 'merged into T-0615'),
                     self._park('T-0200', 'correct-t-0200', 'closed, never unparked'),
                     self._park('PR-1379', 'review-pr-1379', 'its review row is refused'))
        root = self._root({'T-0634': self.MOVED, 'T-0200': self.CLOSED})
        cell = status.parked_cell(self.product, root)
        self.assertTrue(cell.startswith('1 — '), cell)
        self.assertNotIn('T-0634', cell)
        self.assertNotIn('T-0200', cell)
        self.assertIn('PR-1379 [relaunch cap on job review-pr-1379]', cell)

    def test_a_by_hand_branch_park_on_a_retired_card_is_dropped(self):
```

### A3 — the cell and the feeder drop the same card

The fence that keeps the two from drifting: for one item map, the ids the cell leaves out are
exactly `rows.closed_ids` — the set `drop_gone` draws no row for.
