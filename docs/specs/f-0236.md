# F-0236 — 19 of 35 open PRs have not moved in three days

The lane is a state machine with thirteen states, and it documents itself as one where every open
state has a way out: *"The states that still move — each has an outgoing transition with a time
bound"* (`asf/harvest/lane.py:157`). The product's own convention says the same in so many words:
`lane.stale_after` is *"an open lane state (not MERGED/STALE/REAPED) whose head has not moved and
that no session holds for longer than this"* (`asf/conventions.py:212-213`).

Neither sentence is true. `lane.stale_after` is read in exactly one place, under exactly one
state:

```python
    if s == PUSHED:
        at = _parse_at(rec.get('at'))
        if at is not None and f.get('now') and f.get('stale_after') \
                and f['now'] - at > f['stale_after']:
            return STALE, 'unmoved in PUSHED past lane.stale_after'
```
> `asf/harvest/lane.py:1285-1289`

`PUSHED` is the state *before* a PR exists — T2 is what opens one. So the single deadline this
factory has expires only in the one window where there is no PR to go stale, and **the moment a
PR is opened the branch leaves the reach of every clock the lane owns.** Measured in this
checkout, with a record dated 2020 and an OPEN PR on the branch, four open states are outright
fixpoints — `REVIEW`, `GATE`, `WAITING_CI`, `WAITING` — and a fifth, `BACK` holding a pending
correction, is a sixth. Nothing in `next_state` returns `STALE` for any of them, at any age.

That is the whole of the 19. A PR enters one of five sinks and stays:

- **`REVIEW`** — a review was asked for and never written. The in-process pass owns this state and
  bounds it by nothing.
- **`GATE` / `WAITING_CI` / `WAITING`** — re-decided by the detached gate every harvest
  (`GATE_STATES`, `asf/harvest/lane.py:162`), which is not the same as bounded: a red trunk, a
  required check that never starts, an approval hold or host pressure holds the branch for as long
  as the blocker lasts, and no blocker has an expiry.
- **`BACK` with a pending correction** — waits on a correcting session the feeder has to launch.

And the exit the machine already declares for this is wired to nothing. `REAPED` is defined
(`:148`), is listed terminal (`:155`), is a free state for the feeder
(`asf/invariants.py:482`), and has a test asserting it never transitions out (`:159`) — and
**no code path anywhere writes it.** The read-only view over the lane says the quiet part out
loud:

```
    pr_hygiene.py --close    the lane closes nothing itself: one line saying so
```
> `asf/harvest/pr_hygiene.py:15`

So the factory opens PRs on a cap of six a tick (`DEFAULT_PRS_PER_TICK`) and closes them on
exactly three events: a merge, an orphan rule that only applies to branches **no run holds**, and
a card that went Resolved/Closed under a branch's feet. Nothing else. 19 of 35 is not a backlog —
it is the arithmetic of an inflow with no outflow.

The card's own line for this is *"The factory reaps what it opened."* The reading below takes that
literally in one half and refuses it in the other: a branch that **cannot land any more** is
reaped, and a branch that **still can** is sent back to a session — because closing a sound PR
whose only fault is that the trunk was red for three days destroys work the factory paid for, and
would move this number by throwing away the thing the number exists to protect.

### What was chosen, against what, and why

| # | Choice | Against | Why |
| --- | --- | --- | --- |
| D1 | **One deadline, `lane.stale_after`, applied to every open state** — the behaviour its own docstring already claims (P2). | A per-state limit map, on `stage_limits`' model. | Seven states times a tunable is seven ways for a product to configure the deadline back off. The convention already promises one bound for "an open lane state"; honouring the sentence that is written is a smaller change than replacing it, and the per-state nuance this card actually needs is in the *outcome* (D2), not the duration. A second knob can be cut later against evidence a single one is wrong. |
| D2 | **Two outcomes, split on whether the branch can still land.** Cannot land → `REAPED`: the PR closed, the branch archived, the record written. Can still land → `BACK` `kind=stalled`: a session re-engages and pushes. | One outcome: reap everything overdue. | Reaping everything would move this number by destroying sound work. A branch sitting in `WAITING` for three days because the trunk is red has nothing wrong with it; the fault is outside the branch, and closing its PR throws away a paid-for session and re-opens the same PR a day later. The split is also free: both halves already exist — `archive()` (P4) and `enter_back`/`hold_with_correction`. |
| D3 | **The clock is `rec['head_at']`, never `rec['at']`.** | `at`, the obvious field, and the one the `PUSHED` check at `:1286` already uses. | `at` is restamped on every written record, and a record is written whenever state **or reason** changes (P6). A `WAITING` branch whose gate cycles between blockers, or a `REVIEW` advancing its round, would restamp its own deadline away and never trip it — the naive design is silently inert in exactly the states that need it most. `head_at` resets on one event only, a new head (P7), which is also what the forge counts as the PR's update — so the lane's clock and the metric's clock measure the same thing. |
| D4 | **Exempt: `PARKED`, `MERGING`, `QUEUED`, a live session, and a PR no factory item made (`f['foreign']`).** | Bounding every open state without exception. | `PARKED` is a person marking their PR a draft — the owner parked it, and the factory closing a human's park is not a deadline, it is a liberty (Tp already forbids every other action on it). `MERGING`/`QUEUED` have a merge in flight: a deadline there races the host and can close a PR that is landing. A live session is already short-circuited at `:1239`. A `foreign` PR is not the factory's to close. |
| D5 | **The measure is not touched.** `forge_clutter` keeps counting every open PR, drafts and human PRs included. | Narrowing the count to factory-owned, non-draft PRs — defensible, since `clutter:stale-prs` is filed as a FACTORY cause. | Editing the metric in the same change that is meant to move it destroys the card's own verify: the before-span and the after-span would be computed by different code, and `scheme changed` is a verdict the loop already has a word for. If the count needs narrowing, that is its own card, measured on its own. |
| D6 | **No heartbeat comment on a waiting PR.** | A periodic lane comment, which would move `updatedAt` and drop the number to zero in a week. | It would move the metric without moving the clutter — the 19 PRs would still be 19 PRs nobody is working on, now with a robot comment each. The number exists to measure the thing, not to be the thing. Named here so no later reading mistakes it for an option. |
| D7 | **A churn cap: `STALLED_CAP = 2` reaps or send-backs of one item, then the item is parked for a person.** | Letting a reaped card flow back to the feeder indefinitely. | `REAPED` is a free state (P3), so the feeder relaunches the card, the session pushes, a new PR opens, and it stales again — an inflow with no outflow, reconstructed, now also paying for a session each lap. Without the cap this mechanism can hold the count at 19 forever and spend money doing it. The cap is the house pattern (P10) and makes the third lap a question for the operator instead of a fourth PR. |
| D8 | **`STALLED` joins `MECHANICAL`.** | A correction kind that spends a review round. | Nothing about the branch is wrong — nothing moved it. Spending a round would charge the work for the factory's own stall and could push it to adjudicate, and it keeps the launch on `'FIX → CORRECT'`, which `LANE_LAUNCH_KINDS['BACK']` already admits (P11): no `asf/invariants.py` edit. |
| D9 | **The unlandable judgement is `orphan_facts`' rule, lifted — and computed only for a branch already overdue.** | Computing it for every branch every pass. | It needs `merges_clean(b)`, a `git merge-tree` per branch, and a pass sees every lane branch. Gating it behind the deadline keeps the normal path at today's cost and puts the git calls only where a decision depends on them. |
| D10 | **`ORPHANS_PER_PASS`' bound is extended to the new closes: `REAPS_PER_PASS = 25`.** | An unbounded reap pass. | Each reap is an archive push, a PR close and a branch delete (`:267`). The first pass after this lands faces a 19-PR backlog; a bound keeps one tick's forge traffic and one tick's duration predictable, and the rest follow on the next pass. |

## The design

### 1. The deadline — `asf/harvest/lane.py`

Four new module constants beside the existing ones:

```python
#: An open lane state whose head has not moved for longer than ``lane.stale_after`` is overdue
#: (:func:`overdue_s`). These three never are: PARKED is the owner's own draft (Tp), and
#: MERGING/QUEUED have a merge in flight that a deadline would race (D4).
OVERDUE_EXEMPT = (PARKED, MERGING, QUEUED)
#: The correction kind T16 writes: the lane stalled, not the branch — no round, never adjudicate.
STALLED = 'stalled'
#: Overdue outcomes (a reap or a send-back) one item may take before it is parked for a person,
#: on the EMPTY_CAP/INCOMPLETE_CAP/LOOP_CAP pattern (D7).
STALLED_CAP = 2
#: How many reaps one pass takes up — each is an archive push, a PR close and a branch delete,
#: exactly as ORPHANS_PER_PASS bounds the orphan closes (D10).
REAPS_PER_PASS = 25
```

and one pure function, which is the whole of the clock:

```python
def overdue_s(rec, facts):
    """Seconds ``rec``'s branch has sat in its current open state past ``lane.stale_after``, or
    None when it has not, when the state is exempt (:data:`OVERDUE_EXEMPT`), or when the record
    carries no clock.

    The clock is ``rec['head_at']`` — when the lane first saw this head
    (:func:`head_since`) — falling back to ``rec['at']`` for a record written before ``head_at``
    existed, which is what :func:`asf.harvest.pr_hygiene.rows` already reads. It is never
    ``at`` alone: :meth:`Lane.record` restamps ``at`` on every record it writes, and a record is
    written whenever the state *or the reason* moves, so a WAITING branch whose gate cycles
    between blockers and a REVIEW advancing its round would both restamp their own deadline away
    and never trip it (D3).
    """
```

`next_state` reads it once, after the `live` and `empty` short-circuits (`:1239-1243`) and before
the per-state branches, so no existing transition is reordered:

```python
    over = overdue_s(rec, f)
    if over is not None and not f.get('foreign'):
        if f.get('unlandable'):
            return REAPED, f"overdue in {s} for {_age(over)}: {f['unlandable']}"
        return BACK, f'kind={STALLED}'
```

The `PUSHED` check at `:1285-1289` is **removed**: `PUSHED` is an open state and `overdue_s` now
covers it. Its reason string changes from `'unmoved in PUSHED past lane.stale_after'` to the
`overdue in PUSHED for 3d` form — one reason string for all seven states, and `tests/test_lane.py:
150-151` moves with it.

### 2. The two outcomes

`Lane.branch_facts` sets `f['unlandable']` — the reason the branch can no longer land, or None —
**only when `overdue_s` is not None** (D9), reusing `orphan_facts`' own three questions:

| The branch cannot land because | Read from |
| --- | --- |
| its card is Resolved/Closed, or superseded | `superseded_by(self.items, item)`, the card's `state` |
| another branch answers for its card | `self.orphans`' `owner`, or `self.items`' claim |
| it no longer merges onto the trunk | `not self.merges_clean(b)` |

`Lane.enter` gains the `REAPED` arm, which is `archive()`'s path with the terminal state changed —
the archive ref is pushed, the record is written, the PR is closed with a comment naming the state
and the age, and the branch is deleted:

```python
        if state == REAPED:
            if self.reaped >= REAPS_PER_PASS:
                if self.reaped == REAPS_PER_PASS:
                    self.out(f'reaps: {REAPS_PER_PASS} taken up this pass — the rest next pass')
                    self.reaped += 1
                return None
            self.reaped += 1
            return self.archive(f, reason, state=REAPED)
```

`archive()` takes a `state=STALE` keyword so the one implementation serves both callers; its
`close_pr` comment becomes *"Closed by the factory lane: `<reason>`. The branch is kept as
`archive/<branch>` (`<sha>`)."* — unchanged in shape, with the new reason text flowing through it.

`enter_back` gains the `stalled` arm beside `review` and `refusal`:

```python
        if kind == STALLED:
            text = (f"this branch sat in {prev.get('state')} for {_age(over)} with no push — "
                    f"past lane.stale_after ({self.conv.lane_stale_after}). Nothing is wrong with "
                    f"the branch: nothing moved it. Rebase it on {self.trunk}, see the product's "
                    f"pre_push_check pass, and push — or close the card if its work is done.")
```

and `STALLED` is added to `lifecycle.MECHANICAL` (D8), which routes the launch to `CORRECT` and
keeps it off the round counter and out of adjudicate.

### 3. The churn cap — `asf/workers/lifecycle.py`

```python
def stalled_holds(path, item):
    """How many overdue outcomes — a reap or a ``kind=stalled`` send-back — the registry holds
    for ``item``: the laps this item has taken through F-0236's deadline."""


def stalled_park_text(n, item):
    return (f'went overdue in the lane {n} times: each time a PR was opened for it and nothing '
            f'moved it before lane.stale_after — the item is parked. Something outside the branch '
            f'is holding it (a review nobody writes, a red trunk, a required check that never '
            f'starts): fix that, then `asf unpark {item}`')
```

At `STALLED_CAP` the lane writes the park instead of the outcome, in `blocked_park`'s field shape
(P10) — `parked: True` and `operator_flagged: 1` — so the item leaves the feeder's reach and
appears in the operator's For-you digest rather than minting a third PR.

### 4. The views

`asf/harvest/pr_hygiene.py` learns the two lanes, so the read-only view stays true to the machine:

```python
REAP_CLOSE = 'OVERDUE → REAPED'
STALLED_BACK = 'OVERDUE → BACK'

LANES = {
    STALE_CLOSE:     ('stale', 'close'),
    CONFLICT_REBASE: ('conflict', 'rebase'),
    REAP_CLOSE:      ('reaped', 'close'),
    STALLED_BACK:    ('stalled', 'correct'),
}
```

`rows()` gains a `REAPED` branch and a `BACK`/`reason == 'kind=stalled'` branch. Two docstrings
are corrected in the same commit, because both are now false the other way round: the module
header's *"the lane closes nothing itself"* (`:15`), and `--close`'s line at `:98-100`.

## Records

**Written on the run line** in `state/<product>/sessions.jsonl`, in the `lane` field — no ledger
of its own, as every lane transition already is (`asf/harvest/lane.py:10-14`):

| Field | Value |
| --- | --- |
| `state` | `REAPED`, or `BACK` |
| `reason` | `overdue in <STATE> for <age>: <why it cannot land>`, or `kind=stalled` |
| `head_at` | unchanged — the clock the deadline read (D3) |
| `harvested` | `superseded`, for a reap (as `archive()` already writes) |
| `correction` | `{kind: 'stalled', text: …, at: …}` for a send-back; plus `parked: True`, `reason`, `card` at the cap |
| `operator_flagged` | `1`, at the cap only |

**On the forge:** one comment and one close per reaped PR (`close_pr`); one `archive/<branch>` ref
per reap; one branch delete per reap. Nothing is written for a send-back — the session's own push
is what moves the PR.

**Printed by the pass:** `reaped <branch>: overdue in <STATE> for <age> — <why>; archived as
archive/<branch>`, `held <branch>: overdue in <STATE> for <age>`, `reaps: 25 taken up this pass —
the rest next pass`, and `parked <item>: went overdue in the lane 2 times`.

**Read by:** `pr_hygiene` (the two new lanes), the feeder's `FIX → CORRECT` row for a stalled
hold, the operator's For-you digest for a park, and — with no code change at all — the scorecard's
`clutter:stale-prs`, whose next reading is this card's acceptance.
