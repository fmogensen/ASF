# F-0118 — the tick writes it down; the session only reads it

The operator's rejected alternative is the whole argument for the shape of this card. A per-session
`/loop 5m /asf:status` recomputes the factory's state once per session per five minutes — a live
`gh run list`, a live quota probe per account, a live `git rev-list` — dies when the session dies,
and a session's own auto-mode refuses to arm it when a peer asks. Operator, 2026-09-24: *"each
session runs asf for itself … no central controller."*

So the expensive half runs **once per tick, in the tick**, which is already paying for those
probes; and the cheap half — one file read and one subtraction — runs in every session, as often
as the runtime cares to ask. Three seams, in that order:

1. the tick, at its end, writes `~/.ASF/state/<product>/status.txt` atomically;
2. `asf status --line --product P` prints that file and how old it is, reading nothing else;
3. `asf hooks install --product P` merges the `statusLine` setting into the product repo's
   `.claude/settings.local.json`, under the same rule the git hooks already follow, and `asf
   doctor` grows a row saying whether it is there.

### The choices

| # | Chosen | Against | Why |
| --- | --- | --- | --- |
| D1 | The snapshot is written **at the end of the tick**, after `finish`, beside `summary.run` | Writing it in the `record` step, where a table render would be free of a second clone | The two rows an attended session actually watches — `Agents` and `Ready to launch` — are the two the `wave` step changes, and the `record` step runs before it. A snapshot taken at step 0 would be a picture of the factory as it was *before* this tick decided anything, and would be stale by construction rather than by accident. The cost is one more round of the probes in P3, once per tick, on a pass already measured in minutes |
| D2 | The `statusLine` goes into the product repo's `.claude/settings.local.json` | `.claude/settings.json` (where the rule hooks go), or a worker account's user settings (O2) | Three reasons, and they agree. It carries an absolute `asf` path, which is per-machine and must never reach a trunk (P13); `settings.local.json` is the runtime's own local-settings file and is untracked by convention; and local settings take precedence over project and user settings, so an operator with a user-level status line of their own gets this product's line inside this product's checkout and keeps theirs everywhere else |
| D3 | The snapshot carries its own header line: `# asf status <product> ts=<ISO8601Z> stale_after_s=<n>` | Reading the age off the file's mtime, and the horizon off `_record_period_s(product)` at read time | The card's promise is that `--line` "only reads a file". Resolving the horizon at read time means loading and **validating** the product yaml (`env.load_product` raises `ConfigError` on a bad file) and then `scheduler.clocks`, which raises `SchedulerError` on a bad `clocks:` block — so the one command that must never fail loudly would print a traceback into the operator's status line the same minute they mistype a product file. The horizon is the writer's business; the reader does one `open` and one subtraction. mtime is rejected for the same reason plus a second: it is not preserved when a state directory is copied or restored, and the stamp is |
| D4 | `stale_after_s` is `2 * _record_period_s(product)` — the same horizon, from the same function, as the existing `Stale` row | The shortest declared clock interval (every tick writes the snapshot, so the fastest clock is the real cadence) | Two definitions of "stale" in one product is the bug, not the feature. The record period is also the **loose** bound of the two: a product whose wave clock is faster refreshes the snapshot more often than the horizon demands, so this errs towards never crying stale — the right direction for a line that is on screen all day |
| D5 | `rows()` is lifted out of `render()` and both consumers call it | `snapshot_text` parsing `render()`'s markdown back into pairs | A round trip through `\| A \| B \|` has to re-split on a delimiter that any cell may legitimately contain, and it would silently re-encode `? (Err: …)`. One function, two formatters, and `render`'s output does not change by a byte — which is what keeps `tests/test_views.StatusViewTests`' 15 existing assertions meaningful |
| D6 | The compact line is `Name: cell`, one per row, and any newline inside a cell folds to ` · ` | Keeping the markdown table in the snapshot | P16: a pipe table on stdout is redrawn by `asf.tables` into a box, which is 120 columns of box-drawing characters in a session's status line. `Name: cell` has no pipes, passes through untouched, and is what a status line is for. The newline fold is belt-and-braces — P2 says cells are single-line today, and this is what keeps one future cell from turning one row into five |
| D7 | `--line` short-circuits in `main()` before the `resolve_record` block, and returns 0 always | Letting `status` reach `cmd_status` and branching there | P4: `resolve_record` prints `record: <path>` on **stdout** — which would become the first line of every status line — and raises when `backlog_dir` is unset. And a non-zero exit from a status-line command is noise in the session with no reader to act on it: a missing snapshot is already a sentence (`no tick yet`), not an error |
| D8 | `merge_statusline` replaces asf's own entry (the `asf` path may have moved) and leaves a foreign one untouched; `install` then refuses with `NEEDS OPERATOR`, rc 2, after every hook it could write | Overwriting whatever is there; or refusing before writing the rest | The rule the git hooks already set (P9): *no file asf did not write is ever edited*, and *one refusal never skips the others*. The second half matters more than it looks — a foreign status line must never leave a worker account without its `approvals` hook, the guard on human-now actions |
| D9 | The doctor row is `required=True` | `required=False`, since the factory is sound without a status line | P14 is the argument, and it is about legibility, not severity: a non-required false row prints **`skip`**, so `statusline  skip  missing` reads as a check that did not run. The card asks for `ok/missing`, and `RED  missing: … — asf hooks install --product p` says it. Its two siblings, `redaction-hooks` and `approvals-hook`, are `required=True` for the same reason, the fix is one idempotent command, and `install`'s baseline diff (P14) only reports reds it *introduced*, so this cannot make an install look broken |
| D10 | No snapshot is written when there is no record root to render against | Rendering with `root=None` | `record_cell(root)` and `ready_cell(root, …)` read `index.json` under `root`. A rootless render would produce a table of `?` cells and overwrite a good snapshot with it; keeping the old file, with its honest age, is strictly better — and the age is what tells the operator the tick has stopped |
| D11 | The temp file is `status.txt.<pid>.tmp` in the same directory, then `os.replace` | One fixed `status.txt.tmp` | Two clocks of one product can tick concurrently (a command-step clock holds no product lock, `asf/tick/tick.py:376-380`). A shared temp name lets one process's rename publish another's half-written bytes; a per-pid name cannot. `os.replace` is atomic within a filesystem, so a reader sees one whole snapshot or the previous one — never a partial file. Last writer wins, the loser is at most one tick old, and its header says so honestly |
| D12 | Four Stories: the snapshot (writer), the line (reader), the install, the doctor row | One Story per file, or one Story for the lot | The writer and the reader share one format and must land together or the format is unpinned; the install and the doctor row are the two sides of one setting. Four owning test classes, four disjoint sets of writes |

## The design

### 1. The rows, once — `asf/views/status.py`

`render`'s literal tuple of 21 `(name, lambda)` pairs moves into `rows()`, with the `try/except` and
the `None`-drop exactly as they are (P1):

```python
def rows(root, product, cfg=None):
    """``[(name, cell)]`` — every FACTORY STATUS row that has something to say, in table order.
    One unreadable cell becomes ``? (<Error>: …)`` and never loses the rest; a cell that answers
    ``None`` is a row that only speaks up when something is wrong, and is dropped."""
    cfg = env.load_config() if cfg is None else cfg
    out = []
    for name, cell in (('Stale', lambda: stale_cell(root, product)),
                       ...
                       ('Lane pushes', lambda: lane_push_cell(product))):
        try:
            text = cell()
        except Exception as e:  # noqa: BLE001 — one unreadable row never loses the table
            text = f"? ({type(e).__name__}: {e})"
        if text is None:
            continue
        out.append((name, text))
    return out


def render(root, product, cfg=None):
    now = datetime.datetime.now().strftime('%H:%M')
    out = [f"**FACTORY STATUS {now}**", "", "| Metric | Now |", "|---|---|"]
    out += [f"| {name} | {text} |" for name, text in rows(root, product, cfg)]
    return "\n".join(out) + "\n"
```

`render`'s output is unchanged, byte for byte.

### 2. The snapshot — written by the tick, read by nothing else

```python
SNAPSHOT = 'status.txt'
STAMP_FORMAT = '%Y-%m-%dT%H:%M:%SZ'

#: The snapshot's first line. ``ts`` is when the tick rendered it; ``stale_after_s`` is the
#: horizon *it* resolved (D3) — the reader never recomputes either.
_HEADER_RE = re.compile(r'^# asf status (?P<product>\S+) ts=(?P<ts>\S+) stale_after_s=(?P<horizon>\d+)$')


def snapshot_path(product):
    return os.path.join(env.state_dir(product), SNAPSHOT)


def snapshot_text(root, product, cfg=None, now=None, stale_after_s=None):
    """The compact form of the FACTORY STATUS table: a header line (D3) and one ``Name: cell``
    line per row, no markdown — a status line is not a table (D6)."""
    now = now or datetime.datetime.now(datetime.timezone.utc)
    horizon = int(stale_after_s if stale_after_s is not None else 2 * _record_period_s(product))
    head = (f"# asf status {product.name} ts={now.strftime(STAMP_FORMAT)} "
            f"stale_after_s={horizon}")
    body = [f"{name}: {' · '.join(text.splitlines())}" for name, text in rows(root, product, cfg)]
    return "\n".join([head] + body) + "\n"


def write_snapshot(root, product, cfg=None, now=None):
    """Write the snapshot atomically (D11): a per-process temp file beside it, then ``os.replace``
    — a reader sees one whole snapshot or the previous one, never a partial file. Returns the
    path."""
    path = snapshot_path(product)
    tmp = f'{path}.{os.getpid()}.tmp'
    with open(tmp, 'w', encoding='utf-8') as f:
        f.write(snapshot_text(root, product, cfg, now))
    os.replace(tmp, path)
    return path
```

A failed write leaves the temp file behind rather than a truncated snapshot; the caller (§3) removes
it and reports.

### 3. The tick's last act — `asf/tick/tick.py`

At the end of `_run_steps`, after `summary.run` (P6), on the same best-effort contract:

```python
    summary.run(ctx, chosen, ran=ran)
    write_status_snapshot(ctx)
    return rc


def write_status_snapshot(ctx):
    """The tick's last act: ``state/<product>/status.txt``, for every session's status line
    (``asf status --line``). At the end, not in the ``record`` step, because the two rows a
    session watches are the two the ``wave`` changed (D1). Best-effort, like the summary above
    it: one line and nothing else when it fails, never the tick's exit code."""
    from asf.views import status
    product = ctx.product
    root = ctx.record_root() if ctx.has_record else (product.backlog_dir or None)
    if not root or not os.path.isdir(root):
        print('tick: status snapshot not written (no record to render)')
        return
    try:
        status.write_snapshot(root, product)
    except Exception as e:  # noqa: BLE001 — a status line is never worth a failed tick
        print(f'tick: status snapshot not written ({type(e).__name__}: {e})')
```

`ctx.record_root()` is called only when the clone already exists (`ctx.has_record`), so a
`--steps wave` tick never clones the record just to draw a status line; it renders against the
operator's checkout, which the last record tick left current (`shadow.sync_operator_checkout`).
When there is no root at all, the previous snapshot stands and its age tells the truth (D10).

### 4. The line — `asf status --line`

```python
def line_text(product_name, now=None):
    """The status line's whole output: the age line, then the snapshot body. One file read, one
    subtraction — no config, no record, no subprocess (D3, D7)."""
    now = now or datetime.datetime.now(datetime.timezone.utc)
    try:
        with open(snapshot_path(product_name), encoding='utf-8') as f:
            lines = f.read().splitlines()
    except OSError:
        lines = []
    m = _HEADER_RE.match(lines[0]) if lines else None
    if not m:
        return f"ASF {product_name} · no tick yet\n"
    when = datetime.datetime.strptime(m.group('ts'), STAMP_FORMAT).replace(
        tzinfo=datetime.timezone.utc)
    age_s = max((now - when).total_seconds(), 0)
    stale = ' · STALE' if age_s > int(m.group('horizon')) else ''
    head = f"ASF {m.group('product')} · tick {_age(age_s)}{stale}"
    return "\n".join([head] + lines[1:]) + "\n"


def cmd_status_line(args):
    """``asf status --line`` — always 0: a non-zero exit from a status-line command is noise in
    a session with no reader to act on it (D7)."""
    name = getattr(args, 'product', None) or env.default_product_name()
    sys.stdout.write(line_text(name))
    return 0
```

A malformed stamp is one more `no tick yet`: the `strptime` sits inside the same guard as the
`open` in the implementation, so no snapshot anyone has hand-edited can raise into a session.

### 5. The setting — `asf/hooks.py`

```python
#: How often the runtime re-runs the status-line command, in seconds (F-0118 §3 of the card).
STATUSLINE_REFRESH_S = 60


def statusline_command(asf_path, product_name):
    return f'{asf_path} status --line --product {product_name}'


def is_statusline_ours(command, product_name):
    """asf's own status-line command for ``product_name`` — the same recognition the hook entries
    use (:func:`_is_ours`, P10): an entry-point basename bare or after a ``/``, any pipx
    ``--suffix`` included, or ``-m asf.cli``, then ``status --line --product <p>`` and nothing
    after it."""
    return bool(re.search(
        rf'(?:(^|/)asf{_SUFFIX}|-m asf\.cli) status --line --product {re.escape(product_name)}$',
        command or ''))


def merge_statusline(settings, asf_path, product_name):
    """``(settings, refusal)``. asf's own entry is replaced (the ``asf`` path may have moved, or
    the refresh changed); a ``statusLine`` that is not asf's is left exactly as it is and named in
    the refusal (D8) — no setting asf did not write is ever edited."""
    current = settings.get('statusLine')
    if isinstance(current, dict) and current.get('command') is not None \
            and not is_statusline_ours(current.get('command'), product_name):
```

```python
def check_statusline(product):
    """(ok, detail) — the session status line (F-0118): the product repo's
    ``.claude/settings.local.json`` carries asf's own ``statusLine`` for this product. Read-only,
    like :func:`check_redaction_hooks` — this never writes the setting; `asf hooks install` does,
    and a missing or foreign one stays red until the operator runs it."""
    if not product.repo_dir:
        return True, 'no repo_dir configured'
    path = os.path.join(product.repo_dir, '.claude', 'settings.local.json')
    fix = f' — asf hooks install --product {product.name}'
    try:
        with open(path, encoding='utf-8') as f:
            data = json.load(f)
    except (OSError, ValueError):
        return False, f'missing: no statusLine in {path}{fix}'
    entry = (data if isinstance(data, dict) else {}).get('statusLine') or {}
    command = entry.get('command') if isinstance(entry, dict) else None
    if not command:
        return False, f'missing: no statusLine in {path}{fix}'
    if not hooks.is_statusline_ours(command, product.name):
        return False, f'{path} has a statusLine that is not asf\'s{fix}'
    return True, f'{path} · every {entry.get("refreshInterval", "?")}s'
```

## Records

- **`~/.ASF/state/<product>/status.txt`** — new, host state, untracked, one per product, beside the
  `summary-<clock>.stamp` files already there (P7). Rewritten whole at the end of every tick,
  through a per-pid temp file and `os.replace`. First line
  `# asf status <product> ts=<ISO8601Z> stale_after_s=<n>`; then one `Name: cell` line per
  FACTORY STATUS row that had something to say, in table order. Never committed, never read by
  anything but `asf status --line` and never by the record.
- **`<repo_dir>/.claude/settings.local.json`** — one new key, `statusLine`, with `type`, `command`
  and `refreshInterval`. Every other key in the file is preserved. Untracked by convention (P13);
  written by `asf hooks install`, which `asf install` step 7 runs (P15).
- **One new doctor row**, `statusline`, in `asf doctor --product <p>`'s DOCTOR table.
- **Nothing in the record.** No card, no Story, no `metrics/` event, no `index.json` field, no
  product-config key, no schema version. A status line is a view of state that already exists;
  giving it a ledger row would be a commit per tick for a picture nobody reads twice.
