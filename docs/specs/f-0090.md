# F-0090 — Adjudication is the last resort: the cheap causes are ruled out before the heavy model is spent

Epic: E-0001 — ASF 0.1 — a working factory. Branch: `spec/F-0090`.

Measured 2026-09-23: 32 adjudicate runs, 23.7 hours, every one of them on the heavy model — a
fifth of all session hours spent on the factory arguing with itself. Read back, most of those
rulings were not rulings. T-0026's was *"Task 8353 must land first"* — a dependency, which the
record already carries as one `after:` line. Two more were launched for T-0026 and T-0027 after
that line was on the cards, and had to be killed by hand.

Today the factory has four places that produce an adjudicate row, and none of them asks a single
question before it does:

| Producer | Where | The test it makes |
| --- | --- | --- |
| a Bug at the attempt limit | `asf/feeder/rows.py:209-215` | `attempts[id] == attempt_limit` |
| a branch held at the round cap | `asf/feeder/rows.py:240-245` | `corrections[id]['rounds'] >= 3` |
| a spec/plan review at the round limit | `asf/feeder/rows.py:298-304` | `spec-review r4` |
| the groom day's open questions | `asf/feeder/rows.py:381-410` | §2.5 of F-0085 |

Each one counts something and launches the most expensive brief in the pool on the strength of
that count alone. A count is not a disagreement. An item whose predecessor has not landed is
waiting; an item whose brief is stale is misinformed; a branch red for a failure in a file it
never touched is innocent. Only two rounds that changed *the same file of this item* in
incompatible ways are in dispute.

This spec puts three cheap tests in front of every adjudicate row, in order; makes a ruling
something the record can act on rather than a paragraph a human must read and retype; makes the
tick say, in one line, which two rounds it is adjudicating between; and adds the weekly measure
the card's target is read off.

## 1. Decisions

### What already holds (verified in this worktree at `9790fdb`)

- **A count that is not a round no longer feeds adjudication.** B-0082 (`5b5055f`): a timed-out
  gate returns `timed-out` from `hold_with_correction` (`asf/harvest/harvest.py:862-864`) — no
  round, no correction, eligible again next tick. This spec's third cause is shaped after it.
- **A question the factory already acts on is not put to an adjudicator.** `c8dff94` and
  `a20773b`: `groom_policy.suppress` takes the feeder's own rows off the groom's open list
  before `groom_row` counts them (`asf/tick/step_wave.py:88-92`).
- **A held branch below the cap is owned by the round to come, not by the gate** (D-0048,
  `harvest.is_eligible:179-189`). At the cap the same branch becomes eligible again every tick,
  so a hold there is not a dead end: harvest keeps re-gating it, and it lands by itself the
  moment the trunk's own problem goes away. That is what makes "hold" a real answer for causes
  1 and 3 rather than a way of dropping an item on the floor.
- **`after:` is already a lane dependency the feeder honours** for a `New` Task
  (`asf/feeder/rows.py:335-341`) — but only there. No adjudicate producer looks at it.
- **A ruling is already the factory's to file, never the session's** (B-0064): the session
  writes `ruling:` in its REPORT and `step_health.file_rulings:99-137` appends it to the card's
  `## History`. It writes prose and nothing else.
- **A typed field written by a machine round-trips through the parser before it is kept**
  (B-0084, `9790fdb`, `asf/record/setfield.py:34-56`). The ruling's typed fields reuse that path
  rather than inventing a second writer.

### In / out

| In | Out |
| --- | --- |
| Three cheap causes, tested in the card's order, in front of the three *item* adjudicate rows (Bug at the attempt limit, branch at the round cap, review at the round limit) | The `GROOM → ADJUDICATE` row — it is not about one item's code, and F-0085 §2.5 already suppresses every question the factory acts on |
| A `hold` outcome (the row waits, no session, no slot) and a `rerun` outcome (the same brief kind again, rebuilt) | A fourth outcome, a queue, or any retry the operator has to release |
| The gate naming the files its red is about, and a foreign red costing no round (harvest side, B-0082-shaped) | Parsing a test framework's output beyond file paths — no failure classification, no owner guessing |
| `blocked_on`, `writes` and `superseded_by` as typed REPORT fields an adjudication may set, applied to the card by the tick | A new card type for rulings, a `D-nnnn` minted by a session (B-0054), or any ruling committed to the product repo |
| One tick line per adjudicate row, naming the two rounds it is between | A report, a dashboard, or a view of past adjudications |
| A weekly scorecard row: adjudicate hours as a share of heavy-model hours, against the 10 % target, and a `triage` event per cheap cause | Failing a tick, filing a Bug, or refusing to adjudicate when the share is over target |

### Preconditions

- `9790fdb` is the base: `setfield`'s round-trip write, B-0082's timed-out gate, B-0084's record
  hook. Every design point below builds on them.
- The card's measurement names this operator's heavy model. This repository names no vendor's
  model (`asf/briefs/build.py:38-40`: the two labels are `heavy` and `light`), so the target is
  specified and measured as **the heavy model's hours**, resolved from `worker_pool.models`. The
  card's number is the same number.
- No schema migration: every fact this spec needs is already in `index.json` (the typed fields
  and the machine block) or in `sessions.jsonl` (the runs, their corrections, their rounds).

### Choices

| --- | --- | --- | --- |
| D1 | One new pure module `asf/feeder/triage.py` with one entry point, `cause(item, items, facts)` → `Cause \| None`, called by each of the three producers just before it appends its adjudicate row | Three inline checks, one per producer | The card's rule is one rule ("everything else has a cheaper answer, and the cheaper answer has to be tried first"). One function is one place to test the *order* in, and one place a fourth cause is added to. |
| D2 | The order is fixed and short-circuiting: predecessor → stale brief → foreign red. | D8 | A red gate whose files overlap none of the branch item's `writes:` costs **no round and writes no correction**: `hold_with_correction` returns `foreign` and prints `foreign <branch>: gate red outside its writes: <path> — re-gated next tick`, exactly as B-0082 does for a timed-out gate. | D11 | A ruling field the record cannot act on (an unknown id, a self-reference, a glob list that does not round-trip) is refused: the prose ruling is still filed, the field is not written, and the tick prints one `NEEDS OPERATOR:` line naming the field and the value | Write it and let `asf check` fail on the next tick | A ruling ends the loop; a ruling that corrupts the card starts a worse one. | D13 | The measure is one `scorecard_rows` row, `adjudication`, computed over the 7-day `sessions` stream: adjudicate minutes / heavy-model minutes, the percentage, the target, and the count of adjudications the triage prevented (from the `triage` events) | A new metrics stream | The stream already carries `kind`, `model` and `minutes` per session (`asf/metrics/metrics.py:120-124`). Nothing new has to be recorded to measure the target; only the prevented-count is new, and it is an event, not a stream. |

## 2. The design

### 2.1 `asf/feeder/triage.py` — the three cheap causes, in order

```python
Cause = collections.namedtuple('Cause', 'name action reason brief_kind waits_on')

HOLD, RERUN = 'hold', 'rerun'
PREDECESSOR, STALE_BRIEF, FOREIGN_GATE = 'predecessor', 'stale-brief', 'foreign-gate'

def cause(item, items, facts):
    """The cheapest cause that explains this item's stalemate, or None — then it is a dispute.

    ``facts``: {'corrections': {...}, 'stale_briefs': {item: brief_kind}, 'rounds': {item: [...]}}
    Pure: no git, no filesystem, no clock (P5)."""
```

1. **`predecessor`** — `[a for a in item.get('after') or [] if items.get(a, {}).get('state') not in
   ('Resolved', 'Closed')]`, plus any open id in `blocked_by_open`. Non-empty →
   `Cause(PREDECESSOR, HOLD, 'after: <id> has not landed — waiting, not disputed', '', '<id>')`.
2. **`stale-brief`** — `facts['stale_briefs'].get(item['id'])` →
   `Cause(STALE_BRIEF, RERUN, "the brief predates the card's last change — rebuilt, not disputed",
   <that kind>, '')`.
3. **`foreign-gate`** — the newest correction, when `kind == 'gate'`, `item['writes']` is non-empty
   and `correction['files']` is non-empty, and `footprint.overlaps(writes, files)` is `None` →
   `Cause(FOREIGN_GATE, HOLD, 'gate red outside writes: <first file> — not this item's', '', 'gate')`.

Each cause is one small function (`_predecessor`, `_stale_brief`, `_foreign_gate`) so a test can
name it; `cause()` is their ordered `or` chain.

### 2.2 The rows

`rows.Row` gains three fields, all defaulted so every existing construction is unchanged:

```python
cause: str = ''          # which cheap cause spoke, '' when the row is a genuine dispute
between: tuple = ()      # ((label, text), (label, text)) — the two rounds, adjudicate rows only
common: str = ''         # the file both rounds changed, when they share one
```

Each of the three producers wraps its adjudicate row:

```python
c = triage.cause(item, items, facts)
if c is None:
    out.append(Row(..., kind=STALEMATE, brief_kind='adjudicate', between=between, common=common,
                   reason=f'{a_label} ↔ {b_label}: the same file, two rounds — adjudicate'))
elif c.action == triage.HOLD:
    out.append(Row(..., action=f'WAITS ON {c.waits_on}', brief_kind='', cause=c.name,
                   reason=c.reason, waits_on=c.waits_on))       # launches nothing
else:  # RERUN
    out.append(Row(..., action=LAUNCH, brief_kind=c.brief_kind, cause=c.name, reason=c.reason))
```

A `HOLD` row is a non-launching row: `Row.launches` is already `action.startswith('would launch')`,
so it takes no slot, needs no brief and prints through the `waits` branch of `step_wave.run:167`.
The row is still emitted — a held item that produced no row at all would be invisible.

The `between` pair per producer:

| Producer | round A | round B |
| --- | --- | --- |
| branch at the round cap | `rounds[-2]` — `r<n> <kind>: <text>` | `rounds[-1]` |
| Bug at the attempt limit | the last-but-one run — `attempt <n>: <end_reason>` | the last run |
| review at the round limit | `conventions.review_path(slug, n-1)` | `conventions.review_path(slug, n)` |

`common` is the first path in `round_a.files ∩ round_b.files`, `''` when they share none. A
dispute with no common file is still a dispute (the two rounds may disagree about a document),
but the line says so, and that is the first thing to read when the ruling turns out to be cheap.

### 2.3 The facts the tick supplies

`asf/workers/lifecycle.py`:

```python
Round = collections.namedtuple('Round', 'n kind text files at job brief_kind')

def round_log(path):
    """{item: [Round, ...]} in `started` order — every correction ever written on the item's
    runs. A run holds its newest correction; earlier rounds live on earlier runs."""

def hold(path, run, kind, text, now, files=()):   # `files` joins the correction dict
```

`corrections()` already passes the whole correction dict through (`dict(corr, rounds=…,
branch=…)`), so `files` reaches the feeder with no change there.

`asf/briefs/build.py`:

```python
DIGEST_FIELDS = ('title', 'writes', 'tests', 'after', 'blockedBy', 'decided', 'severity')

def card_digest(product, item_id, index):
    """sha256, first 16 hex: what a brief states about this card — DIGEST_FIELDS, links.spec,
    links.plan, the Feature's Story ids, and the card's Description/Acceptance/Fix/Links text
    (`preamble.card_sections`). `## History` is excluded: filing a ruling must not stale a brief."""
```

`Brief` gains `card_digest: str`; `step_wave.worker_row` copies it onto `pool.Row`; `spawn`
writes it into the ledger record; `pool.SESSION_FIELDS` gains `card_digest`.

`asf/tick/step_wave.py`:

```python
def stale_briefs(product, root, index):
    """{item: the brief kind to re-run} — the latest ended run of each item whose recorded
    `card_digest` differs from today's. A run with no `card_digest` (launched before this
    change) claims nothing and is never stale."""

def plan_inputs(product, root):
    return {..., 'stale_briefs': stale_briefs(product, root, index),
            'rounds': lifecycle.round_log(pool_mod.sessions_path(product))}
```

`rows.candidates()` / `plan_rows()` take `stale_briefs=None, rounds=None` and default both to
`{}`, so `asf next` with no ledger, the status cell and every existing test plan exactly the
rows they plan today.


`land_ff` and `land_combined`'s `hold` pass `files` to `hold_with_correction`, which passes them
to `lifecycle.hold`. Before it holds, `hold_with_correction` applies D8:

```python
if kind == 'gate' and files and item_writes and footprint.overlaps(item_writes, files) is None:
    out(f'foreign {branch}: gate red outside its writes: {files[0]} — re-gated next tick')
```

`item_writes` comes from the index the harvest step already loads; when it has none, the branch
is held as today. Every caller of `product_gate` / `run_gate` inside this package is updated;

kind of breakage the suite catches at once.

### 2.5 The tick's line

In `step_wave.run`, before the brief is built:

```python
if row.brief_kind == 'adjudicate' and row.between:
    (la, ta), (lb, tb) = row.between
    common = f' · both touch {row.common}' if row.common else ' · no file in common'
    out(f'adjudicate {job:<24} {row.item_id:<10} — {la}: {ta[:60]} ↔ {lb}: {tb[:60]}{common}')
if row.cause:
    ctx.event('triage', item=row.item_id, cause=row.cause, row=row.kind, action=row.action)
    out(f'triage   {row.item_id:<10} — {row.cause}: {row.reason}')
```

A held cheap cause then falls through to the existing `waits` line; a `rerun` cause launches its
kind with a brief built from today's index, which is what makes the digest match at launch (D6).

### 2.6 The ruling, typed

`asf/briefs/build.py` `TAIL`, replacing the single `ruling:` line:

```
ruling: <adjudicate only — one paragraph: what was disputed, what now holds, what changes; else omit>
blocked_on: <adjudicate only — the id this item must wait for, or none>
writes: <adjudicate only — the corrected footprint, space-separated globs, or none>
superseded_by: <adjudicate only — the id that replaces this item, or none>
```

`asf/briefs/templates/adjudicate.md` gains one paragraph under the existing "THE RULING GOES TO
THE RECORD" block:

> Your ruling's *mechanism* is those three fields; the paragraph is its *explanation*. If the
> answer is "this waits for T-0025", the answer is `blocked_on: T-0025` — not a sentence saying
> so. If the answer is "its footprint was wrong", the answer is the corrected `writes:` line. A
> paragraph with no field behind it changes nothing, and the loop you were asked to end restarts
> on the next tick.

`asf/workers/report.py`: `FIELDS` and `FIELD_RE` gain the three names;

```python
NONE_RE = re.compile(r'^(none|n/a|-|—)$', re.I)

def ruling_fields(text):
    """{'blocked_on': 'T-0025'|None, 'writes': ['a/b.py', ...]|None, 'superseded_by': ...} —
    an absent field and a `none` value are both None (no claim)."""
```

`asf/record/setfield.py` grows the writer both `asf set` and the tick use:

```python
def apply(path, relpath, updates):
    """(ok, why): render `updates` onto the card, parse the result back, and keep it only when
    every key round-trips to exactly what was asked (B-0084). `cmd_set` becomes a thin caller."""
```

`asf/tick/step_health.file_rulings` applies the fields before it files the prose:

| field | item type | written | refused when |
| --- | --- | --- | --- |
| `blocked_on: <id>` | task | `after:` gains `<id>` (kept sorted, de-duplicated) | no such card in the record, or `<id>` is the item itself |
| `blocked_on: <id>` | anything else | `blockedBy:` gains `<id>` | as above |
| `writes: <globs>` | task, bug | `writes:` replaced | the value does not round-trip as a list |
| `superseded_by: <id>` | any | `removed: superseded by <id> (adjudicate <job>)` | no such card, or `<id>` is the item itself |

Each applied field adds one `## History` line beside the prose ruling's, and the `ruling` event
gains `fields: {...}`. A refusal prints
`NEEDS OPERATOR: adjudicate <job> set <field>=<value> on <item>, which the record refuses — <why>`
and leaves the card's typed block untouched.

### 2.7 The measure

`metrics.scorecard_rows` gains, after the `agents` row:

```python
heavy = heavy_model(conv)            # worker_pool.models['heavy'], lowercased; None → every model
adj = sum(s['minutes'] or 0 for s in sessions if s['kind'] == 'adjudicate')
hvy = sum(s['minutes'] or 0 for s in sessions if is_heavy(s, heavy))
rows.append(('adjudication',
             f"{adj/60:.1f} h of {hvy/60:.1f} heavy-model h ({_pct(adj, hvy)} %)",
             f"target < {ADJUDICATION_TARGET_PCT} % — {n_runs} runs, {n_triaged} ruled out cheaply"))
```

`n_triaged` counts `triage` events in the same window. The row is printed by `render_daily:501`
with every other scorecard row; nothing fails on a miss (D13, and the In/Out table).

## 3. Acceptance tests

All from the repository root, stdlib only. The whole suite must stay green:

```bash
cd "$(git rev-parse --show-toplevel)"
python3 -m unittest discover -s tests
```

**T1 — the predecessor is not a dispute.** A Bug at the attempt limit and a Task held at the
round cap, each with `after: [T-0001]` where `T-0001` is `New`: one non-launching row,
`cause == 'predecessor'`, `waits_on == 'T-0001'`, and no `adjudicate` brief kind anywhere in the
plan. With `T-0001` `Closed`, the same fixture produces the adjudicate row.

```bash
python3 -m unittest -v tests.test_feeder.TriagePredecessorTests
```

**T2 — a stale brief is re-run, not adjudicated.** With `stale_briefs={'T-0026': 'correct'}`, the
row at the round cap launches `correct`, carries `cause == 'stale-brief'`, and its `rounds` are
unchanged. `briefs.card_digest` is stable across two calls on an unchanged card, changes when
`writes:`/`after:`/the `## Description` text changes, and does **not** change when a `## History`
line is appended or the machine block's `evidence`/`state` changes.

```bash
python3 -m unittest -v tests.test_feeder.TriageStaleBriefTests tests.test_briefs.CardDigestTests
```

**T3 — a red gate outside the footprint is not a dispute.** An item with `writes: ['asf/groom/**']`
whose newest correction is `{'kind': 'gate', 'files': ['asf/feeder/rows.py']}` at the cap: one
non-launching row, `cause == 'foreign-gate'`, the reason naming `asf/feeder/rows.py`. With

**T4 — the order, and what survives it.** A fixture that satisfies all three causes yields
`predecessor`; removing the `after:` line yields `stale-brief`; removing the stale digest yields
`foreign-gate`; removing the foreign files yields the adjudicate row, with `between` naming
rounds 2 and 3 and `common` naming the file both changed. Called with no `stale_briefs` and no
`rounds` (the defaults), `candidates()` returns exactly the rows it returns today for every
existing fixture.

```bash
python3 -m unittest -v tests.test_feeder.TriageOrderTests tests.test_feeder.RowsTest tests.test_feeder.CorrectionRowTest tests.test_feeder.AttemptOrderTest
```

**T5 — the round history and the files on a correction.** `lifecycle.round_log` over a registry

## 4. Records

**Cards (in the product's record).** Only an adjudication's typed fields write a card, through
`setfield.apply`; one `## History` line per applied field, beside the prose ruling's existing one:

```
- 2026-09-24 12:10 adjudicate (adjudicate-t-0026): <the ruling paragraph>
- 2026-09-24 12:10 adjudicate (adjudicate-t-0026): after → T-0001
- 2026-09-24 12:10 adjudicate (adjudicate-t-0026): removed → superseded by T-0031 (adjudicate-t-0026)
```

**Files.**

| Path | Written by | Shape |
| --- | --- | --- |
| `~/.ASF/state/<product>/sessions.jsonl` | `spawn` | the launch line gains `card_digest: <16 hex>` |
| `~/.ASF/state/<product>/sessions.jsonl` | `lifecycle.hold` | `correction` gains `files: [<path>, …]` |
| `<record>/<folder>/<id>.md` | `step_health.file_rulings` | the typed field, then the `## History` lines above |

**Events** — `<record>/metrics/events/<day>.jsonl`:

```json
{"kind": "triage", "item": "T-0026", "cause": "predecessor", "row": "STALEMATE → ADJUDICATE",
 "action": "WAITS ON T-0001"}
{"kind": "ruling", "job": "adjudicate-t-0026", "item": "T-0026", "text": "…",
 "fields": {"blocked_on": "T-0001"}}
```

**Printed** (the tick log, one line each):

```
triage   T-0026     — predecessor: after: T-0001 has not landed — waiting, not disputed

NEEDS OPERATOR: adjudicate adjudicate-t-0026 set blocked_on=T-9999 on T-0026, which the record refuses — no such card
```
